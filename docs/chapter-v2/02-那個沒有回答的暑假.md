# 第一部｜我們怎麼走到一起，又失去彼此

## 第二章｜那個沒有回答的暑假

**核心困境**：沒有新資訊時，他怎麼理解沉默，又該等多久。

**處境與入口**：主角告白，她希望等暑假過完再說；他把這句話當成值得守住的約定。

**本章要成立的理解**：第一章日久生情的依戀，在突然失聯後變成不安全感與匱乏；他照常生活，仍被每次手機震動拉回等待。她請他等暑假過完，因此等到九月不能自動算逃避求證；她沒有交代的影響，也不能全部算成他想太多。

**素材起點（可改編）**：高二告白；她希望等暑假過完再說；隔天失聯；九月打電話聽到「你是誰」；從妹妹得知她已有對象。

**場次**：原有聯繫突然中斷 → 主角為沉默找理由，等到九月打電話卻聽見「你是誰」 → 從妹妹得知她在暑假開始前幾天與班上男生交往。等待壓縮在會改變他判斷的時刻；他沒有再撥那個號碼。

**停點與交接**：主角只知道她在暑假開始前幾天收到班上男生的告白，並和他在一起，仍不知道失聯與「你是誰」的原因。他沒有再撥那個號碼；Facebook 重聯留到第三章開場。
