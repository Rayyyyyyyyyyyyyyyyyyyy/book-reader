# 第四部｜結果來了以後

## 第十一章｜空下來的衣櫃

**核心困境**：還想挽回的時候，他要怎麼完成收尾，並停止額外的投入。

**處境與入口**：她的物品真的不在了，主角才發現自己的東西很少；家很大、很安靜，床也睡不下去。

**素材起點（可改編）**：衣櫃空了，才發現自己的東西很少；家很大、很安靜；窩在沙發上哭，不敢睡床；知道不能獨自待著，向朋友傾訴，也和 GPT 談心；反覆說出片段，逐漸看見價值觀與自己曾做的生活調整。

**接續時間（2026-09-22）**：第一次整理後下一個週五搬離，距餐館談話兩週；搬離後第五天找朋友，再過一週的星期三結清帳務，隔天試訪並訂機票。朋友邀約為報到後的下一個週四，承接第十二章與結語。

**場次**：讓幾個難過的夜晚先存在 → 他知道不能一直獨自待著，向朋友與 GPT 傾訴 → 一頓陪吃的飯或一次談話，讓他多看見原先沒說清楚的一件事，也承認自己催促、代辦或施壓的影響 → 處理物品、剩餘共同支出與貓的照顧，確認各自承接的部分。餐桌與衣櫃具名處理：都留給他，雙方各按同意的現值及原出資比例結算她的份額；不把她免費留下寫成最後的體貼，也不另配一段象徵解說。黑糖 由他照顧。能補救的就處理，聯絡可暫限收尾，不拿物品、費用或補救交換復合。朋友持續的陪伴，也讓「被留下的人」之外的自己有機會出現。

**本章要成立的理解**：本章少解釋，讓夜晚、哭泣與生活失序先佔有時間。必要收尾與停止挽回可以同時進行，不必等責任全部處理完，才有資格停止額外投入；結束不抹掉過去。

**停點與交接**：本章佔去到職前空檔的一段。悲傷與求助仍在，他第一次查自己的行程或機票，尚未完全想通，已能開始安排下一步。
