# 〈第七章｜住在一起以後〉結構修改提案編輯判讀

## 總判斷

**建議採用，但要連同章卡、第七章後半的支出連續性，以及第八章的共同費用場景一起重設。**

作者更正 A–D 使現稿的「麵包店臨時改班 → 六週定額支持 → 減班完成課程」不再成立，這一整條因果必須移除，不能只換掉職業名稱或刪除金額。新提案能保住本章最重要的功能：她原本因現實壓力無法把課上完，兩人談開後，她得到一段可用的時間，最後完成課程與成果展。它也讓第八章的內心帳本更尖銳：第七章沒有談出一筆日後可追討的數字，主角卻在失望時把自己曾付過的生活費、後來多做的照顧與未受託的代辦放進同一本帳。

但「他真正的介入不是出錢，而是替她把時間買下來」需要改得更準確。錢仍是她能留在課程裡的物質前提，只是不是談開當下新增的資源。真正的轉折應寫成：**他不再只說「生活費我付」，而是同意承受她暫時沒有收入的未知，並請她把求職延到成果展之後；她則親自決定暫停求職、守住材料與交通的支出，以及把雙方負擔留下紀錄。** 這樣既不否定他的金錢支持，也不把她寫成被他安排人生。

## 與章卡的相容程度

| 章卡項目 | 判斷 | 需要調整之處 |
|---|---|---|
| 核心困境 | **方向一致，文字必須改** | 現行「協商過的支持要怎麼運作」預設支持已有範圍與期限，與新設定不符。可改為：「一方暫時沒有收入時，支持怎麼真正變成她能使用的時間；工時錯位之後，兩人要怎麼保住相處。」不要把核心寫成誰養誰，也不要在章卡先判定這是債或控制。 |
| 處境與入口 | **一致，需補準確事實** | 第 14 行「他願意先多承擔一些」應改成房租與生活費一開始全由他負擔；她仍以待業存款支付材料、交通及自己的選擇。她離開原工作、城市與熟悉生活的代價，以及同居也是她自己的轉職選擇，都應保留。 |
| 採用設定 | **必須改** | 第 18 行的「階段性支持」容易讓人理解成事前約好期限。應記成：同居起由他負擔房租與生活費，沒有金額上限，也沒有談定期限；實際到她找到正職並領到第一份薪水為止。這是後來發生的結束點，不要倒寫成兩人一開始就訂好的條款。 |
| 場次 | **中段必須整段替換** | 第 20 行的兼職、改班、六週、一萬元、減班，以及「領第一份完整薪水後重談」均不再成立。開場租屋與衣櫃、後段行政職工時錯位、週五晚餐及黑糖仍可保留。中段改成待業存款下降、邊上課邊求職、作業與成果展準備延誤、誤判、談開、暫停求職、完成課程。 |
| 本章要成立的理解 | **一致，而且可更扎實** | 「支持確實有用」仍成立，且不需在第七章提醒它日後會變成帳。第七章只讓讀者看到這次支持帶來真實改善；第八章再讓同一段經驗被主角重新計價。 |
| 停點與交接 | **現行停點不一致，最後一句可保留** | 第 24 行以「第一份完整薪水後重談卻一再延期」「暫時的安排逐漸變久」收束，直接違反負擔在第一份薪水時結束的更正。應改成：她領到第一份薪水後，全額負擔的狀態結束，兩人進入新的共同費用安排；週五晚餐與黑糖讓生活看起來能協商、能運作；他仍未說出買房存款。章末「仍以為生活穩定後會自然走到同一個未來」可以保留。 |

章卡第 8 行也要複檢。「薪資、存款、預算的具體數字，主要在第七、九章」未必需要整句刪除，但第七章不應再用精確金額製造一份不存在的約定。若保留數字，只能用來呈現她的存款正在減少或兩人的資源落差，不能重新包裝成上限、月額或期限。

## 對第八章的影響

整體是**主題變強、事實連續性先變弱**。把第八章的財務基線補齊後，淨效果會是變強。

### 變強的部分

1. **「付出變成帳」更有力量。** 第八章第 263–267 行寫：「我卻把那個晚上留了下來，和買飼料、清貓砂、付掉比較多的房租放在一起」「那些事當下都不是交換／到了失望的時候，卻一起變成了帳。」若第七章中她曾把房租重新寫回備忘錄，而他又刪掉，讀者會知道她沒有假裝成本不存在；反而是他當時拒絕把支持標成債，後來才在情緒裡重新計價。這比「有期限的一萬元後來沿用」更符合第八章的核心。

2. **「我已經付這麼多了」會從金額爭議變成關係中的追溯計價。** 第 429 行這句因沒有事前約定的總額、上限或交換條件而更刺。第 435 行「所以妳不能也少花一次嗎」也更清楚顯示：他把自己曾自願承擔的支出，轉換成她此刻應取消私人行程的理由。

3. **她的反問更站得住。** 第 451–465 行的「你做的哪些，是我叫你做的」「路線是你自己查的」「你不要每次先做完，後來才拿出來問我為什麼沒有一起付」，不再像她否認一份清楚談過的支援。第七章若寫出她堅持記錄房租、材料與交通，讀者會知道她不是沒看見他的負擔；她反對的是他把不同性質的付出事後合併，拿來要求她服從。

4. **第七章的有效支持與第八章的未受託接手能真正分開。** 第七章那次不是錯：兩人談開，她同意暫停求職，也提出自己的條件，最後完成課程。第八章的查路線、提前餵罐頭與替她決定私人支出，才是沒有逐項受託或沒有重談的接手。如此才符合總則所要求的「第七章的協商」與「第八章的未受託接手」不能最後都只得到同一結論。

5. **取消聚餐的傷害更清楚。** 第 447 行「是我做了這麼多，妳還是只想到妳自己要不要去」會暴露他把一段曾有效的支持當成長期道德餘額；第 493 行她說「我不去了」、第 585 行「可是我已經取消了」，便不只是一次省錢爭執，而是她發現過去接受的支持會在未預告的時刻被拿回來定價。

### 會變弱或必須重寫的部分

1. **第一份薪水後的共同費用基線消失。** 第 131 行「她領薪後會先把說好的共同費用留起來」需要一份新的、已發生的約定支撐。作者更正只確定主角全額負擔到第一份薪水為止，尚未說明此後房租、水電、伙食如何分。若不補，讀者無法判斷她的聚餐是否真的是「付完該付的以後剩下的錢」。

2. **第 287、341–371 行的支出談判目前整段失效。** 「共同支出的備忘錄停在好幾個月前，只記到那場沒有算完的分攤」「金額仍沿用她上課時的安排」「我們不是說領到第一份完整薪水就要重談」都建立在舊版六週協議和兩次延期上。新版本應把這場改為：第一份薪水後已有某種現行分法，演唱會當晚他認為現行比例加上照顧已經失衡，兩人才約定在換租約時重談新房租、搬家與黑糖支出。不能留下「沿用她上課時的安排」，因上課時沒有約定金額。

3. **「付掉比較多的房租」能否保留，取決於第一份薪水後的分法。** 第 263 行與第 341 行目前都說他仍負擔較多。這並不必然違反「全額負擔在第一份薪水結束」，但需要明確區分「不再全額負擔」和「仍負擔較高比例」。若作者決定薪水後改成平均分，這兩處都要改；若仍由他付較多，則要讓第七章先演出新分法已開始，而不是把上課期安排拖長。

4. **備忘錄的用途要統一。** 第八章目前把它叫作「共同支出的備忘錄」。提案卻要把她自行支付的材料與交通也記進去。可以改成記錄共同生活期間各自負擔的帳目，或在同一份備忘錄分欄；否則讀者會誤以為材料與交通也是要向他請款的共同費用。第七、八章必須使用同一套名稱與規則。

5. **第 655–677 行的結尾大致可留，但前因要換。** 「共同費用有了重談日期」可改成第八章當晚新訂的換租約討論日；第 677 行「前面那些沒有說明的付出」則因第七章未曾定價而更準。不能再讓讀者以為這個日期只是補上第七章漏掉的「第一份薪水後重談」。

## 人物平衡與閱讀風險

### 她會不會顯得理所當然

提案中的三個動作有用，但**單獨使用仍不夠**。

- 材料與交通由待業存款支付，能證明她沒有把所有個人選擇交給他買單。
- 刪花材、換便宜品項，能讓存款下降變得可見，但這主要呈現她焦慮與節制，還不是主動承擔。
- 把房租寫回備忘錄，是三個動作中最重要的一個。它表示她拒絕讓他的負擔變成沒有名字、日後也無從核對的恩情。

仍應補上兩種既有、且不與 A–D 衝突的主動性。第一，保留她在搬入第一晚主動提出不換大房、安排家務、自己熟悉交通的動作；這些不是用來折抵房租，而是證明她確實參與共同生活。第二，談開時必須由她說出「存款一直少，所以才提早找工作」的因果，並由她親自決定暫停投履歷、取消或延後後續面試、重新排回作業與成果展準備。她不能只對他的「先把課上完」回答好。

成果展後，她也要自己恢復求職，最後接受正職並在第一份薪水入帳後開始承擔新的共同支出。這些連續動作比再加一個省錢細節更能避免「她被養著完成夢想」的讀法。不可用兼職、代班或接案補平衡。

### 他會不會被寫成好人

他在第七章確實做對一件事，不是問題；本章本來就需要讓支持真實有效。風險在於把全額負擔寫成他的道德免責，或用旁白稱讚他的無私。避免方式不是削弱他的付出，而是保留三個事實：他先誤把求職造成的延誤看成她不想做這一行；他起初只處理「錢由我付」而沒有理解她對存款持續減少、支持又沒有邊界的不安；最後的安排是兩人談出的選擇，她有條件，也負責執行。

房租「她寫、他刪、她再寫」可以保留張力，但第七章不要替讀者解釋成他已開始記帳或控制。當下可以只是他認為既然本來就由自己負擔，沒有必要列；她則堅持要看得見。第八章再讓這個動作改變意義。

## 「支持確實有用」如何具體成立

不能只用「她比較安心」或「她終於能專心」下結論，應以談話前後可比較的結果成立：

1. 談話前，她在上課之外持續投履歷、準備面試、跑面試，配置圖與成果展準備一再延誤。
2. 談話後，她停止這一輪求職，把已答應的材料與交通繼續由待業存款支付，親自重新安排作業與展覽準備。
3. 她補完延誤的作業，後段不再因面試缺課或中斷準備，完成課程並把配置圖做成成果展上的作品。
4. 成果展現場，她能回答花材與用途、依講師意見自行判斷取捨，並堅持自己搬作品。現稿第 279–303 行已有這些可見結果，應保留。
5. 成果展後，她重新開始找正職；即使最後進入行政職，也不抹掉她已完成一次自己選擇的學習。支持的成果是她真正走完課程並取得判斷與作品，不是保證她靠花藝就業。

本章還有第二個較小的驗證：週五晚餐沒有消除加班，卻確實維持數月並恢復靠近。兩次有效協商共同構成主角第 359 行「只要我現在有能力多做一點，生活就會變好一點」的經驗來源；不需在本章補一句這個信念日後會出錯。

## 現稿保留與改寫範圍

### 可原樣保留或只需銜接微調

- 第 3–42 行：紙箱、衣櫃、行李箱與她拒絕立刻換大房的開場。這已同時寫出她的搬遷代價、節制與主動提案。
- 第 55–60、63–101 行：家務協商、整理紙箱、妹妹問吹風機、隔天她自己認路。第 61 行含「找到兼職以後」，必須單獨改成課程、求職與面試的時間安排；第 63 行的家務分配本身可留。
- 第 117–143 行：「趴在書桌上睡著」「配置圖逾時寄出」的場景可以原樣保留，因它只演出延誤結果，尚未指定原因。第 145 行起才需要改成求職與面試如何占掉時間。
- 第 233–247 行：「重新畫配置圖」「沒有叫我替她查花材」「完整檔案重新寄出去」可移到新談話之後，保留她自己完成作業的功能；飯糰若前段仍有同一晚的鋪墊，也可留。
- 第 265–274、279–315 行：成果展的作品、她回答問題、自己判斷取捨、自己拿作品，以及計算材料的意識，都是「支持有效」的主要證據。第 275–277 行提到「固定兩個班」必須改。
- 第 357–459 行：主角從結果形成「多做一點有用」的信念、兩人進入不同工時、十點晚餐及週五晚餐協商，結構可保留。前提是第 357 行前先交代她如何找到正職，以及全額負擔已在第一份薪水時結束。
- 第 485–589 行：第一次週五晚餐、安排持續、黑糖加入及最初照顧分工，原則上可保留。第 517 行「共同生活費」需等第一份薪水後的新分法確定，再核對用詞。
- 第 601–607 行：他私下存頭期款、想像更大的家、沒有問她的意願，仍是第八章的重要前因。第 611 行「我仍然相信……」也可繼續作為停點。

### 必須改寫或刪除

- 第 43–53 行：原本的支出表與「我本來想說」不再符合第一天即全額負擔。這裡應改寫成他明說「我來付」、她把房租寫入備忘錄、他刪除、她再寫一次；同時保留她搬遷與待業存款不是零成本的資訊。
- 第 61 行，以及第 103–116 行：「找到兼職」「麵包店」「排班」整條線全部移除。
- 第 145–233 行：排班對話、缺課原因、一天工資、六週、一萬元、結束日期、減到兩班的談判全部失效。可以沿用「他先誤判、她拿出證據、兩人談開、她回到配置圖」的戲劇功能，但證據要改成履歷、面試通知、作業與成果展時程。
- 第 191–197 行：「她兼職排滿時一個月大約一萬八」及「六週，每月生活費一萬元」必須刪除，不可換成另一組數字。
- 第 249–263 行：拒絕代班、擔心不再排班、接下來六週都屬舊因果。材料超支後刪購物車的動作可以改編成提案中的花材清單，但要放在談開之前，成為他看見卻尚未理解的訊號。
- 第 263、275–277、317 行：「六週走完」「固定兩個班」「那六週不是白撐的」都要改成不帶約定期限的時間推進。
- 第 319–355 行：目前寫成成果展後才開始找工作，且包含小型花禮、週末代班、花店四天班與「課程期間那一萬元會停」，均與新設定衝突。此段要改成她在課中曾求職、談開後暫停、成果展後恢復找正職，最後找到行政職；同居期間不能再安排任何兼職或接案。
- 第 461–483 行：第一份完整薪水後的分攤討論一再延期，違反負擔在第一份薪水時結束。應改成薪水入帳後新分法實際開始，或另寫當時如何完成第一次分攤。
- 第 587 行「那段有期限的生活費」必須刪改。第 591–599 行把課程期間方式延長數月、把重談延後，也必須整段重寫。
- 第 609 行「卻沒有替那場延期的討論補上一個日期」不再成立。可改用沒有說出口的買房計畫或未曾說清楚的支持總量來銜接最後一句，但不要預告它將成為代辦或債。

## 修改後的場次順序

**場次**：她主動提出維持低固定支出的套房與工時容許的家務；衣櫃不夠放，她提出收納需求，兩人重新分配。主角明說房租與生活費由自己負擔，她把房租寫進共同備忘錄；他刪掉，她再寫一次。她另以待業存款負擔課程材料與交通 → 她一邊上課一邊投履歷、準備及奔赴面試，待業存款仍持續下降；她在花材清單刪項目、把較貴的材料換成便宜品項，主角看見卻沒有問。求職使作業與成果展準備一再延誤 → 主角先以為她並不想做這一行；談開後才知道她急著找工作，是因為沒有收入、存款持續減少，又不知道目前的支持會維持到何時 → 主角不是再增加一筆錢，而是請她先把課上完，工作等成果展後再找；她同意暫停求職，條件是材料與交通仍由自己支付，雙方實際負擔都記在備忘錄上。兩人不訂金額上限、月額或結束日期 → 她重新安排作業與展覽準備，補完延誤內容，完成課程與成果展；她能在現場說明作品、自己判斷取捨，支持確實產生結果 → 成果展後她恢復找正職，最後進入行政職；領到第一份薪水時，主角全額負擔房租與生活費的狀態結束，兩人開始按新方式處理共同支出 → 主角轉為遠端，她的行政職常加班；他等到十點，她只想洗澡睡覺。疲憊此時就是疲憊，不等於不愛 → 兩人協商出週五晚餐，這項安排確實持續並恢復親密 → 黑糖加入，兩人談妥最初照顧與費用安排 → 主角私下開始存頭期款，沒有和她談買房、地點、時間或分擔；他仍相信生活穩定後，兩人會自然走向同一個未來。

## 仍要留給作者決定的問題

1. **第一份薪水後的共同費用怎麼分。** 這是目前唯一不能由提案自行推出、卻會直接決定第八章是否成立的資訊。需要決定她從第一份薪水起實際負擔哪些項目或比例、主角是否仍付較多，以及第八章聚餐前她所謂「該付的」究竟是什麼。不必使用精確金額，但規則必須讓讀者可判斷。
2. **備忘錄到底記什麼。** 是只記共同支出，還是記同居期間雙方各自支付的相關成本？房租、材料、交通要用什麼欄位區分？她寫回房租是單純留下紀錄、預計日後分攤，還是表示不願把它當贈與？正文不必解釋動機，但作者需先定義物件規則，才能與第八章一致。
3. **他刪除房租欄時說什麼。** 若說成「不用還」，第八章事後計價的反差最強；若只說「這本只記共同支出」，則重點在帳目分類。兩者對人物的承諾程度不同，不能含混混用。
4. **她在課程中找的是哪類正職。** 可以是花藝相關職缺，也可以同時包含穩定行政職，但要決定主角為何會從她一直跑面試誤讀成「不想做這一行」。若面試全是花藝相關，他的誤判不成立；若全是行政職，又要讓讀者明白她不是已放棄課程。
5. **談開前究竟延誤了哪些可見任務。** 建議只選一份配置圖和一項成果展準備，不要用多個作業重複證明忙亂。談後再逐一回收，讀者才看得出支持帶來的前後差異。
6. **第一份薪水與主角轉職、週五晚餐、認養黑糖的時間距離。** 新版本不能再用「暫時安排多留一個月」帶過，需要確定新分攤已運作多久，才知道第八章所稱「長期多付」是課程期的回溯，還是也包含她就業後的現行比例。

修訂優先順序應是：先定第一份薪水後的費用規則與備忘錄用途，再改章卡和第七章中段，最後同步重寫第八章第 131、263、287、341–371、655 行附近的財務連續性。若這兩項基線未先決定，直接改第七章會把第八章最重要的爭執寫成讀者無法核對的情緒帳。
