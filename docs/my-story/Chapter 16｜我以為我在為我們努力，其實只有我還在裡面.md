# Chapter 16｜我以為我在為我們努力，其實只有我還在裡面

終於，有一天她說出口了。

「我對你，已經沒感覺了。」

不是吵架，不是冷戰，也不是誰做錯了什麼。
只是她輕輕地說，那種心動、那種戀愛的感覺，沒了。
她說我們現在的關係，已經只剩下習慣的陪伴，沒有了情人的濾鏡。

其實在那之前，我們早就不像戀人了。
更像室友。

同住一個家，卻各自孤單。
吃飯像例行公事，聊天像交代事項。
我想靠近，她很累。
她想安靜，我覺得被丟下。

「我想搬回家住。」

我沒馬上說話，只是點了點頭。
但心裡像有什麼整塊垮下來。

過去這段時間，我一直在存錢。
不是為了自己，而是為了「我們」的家。
那個有小貓、有沙發、有兩人餐桌的家。
那個我以為只要慢慢添購家具，就會越來越像未來的地方。

結果，這個未來裡突然少了一個人。

那時我正面對人生的另一場轉折。
工作即將結束，準備離職找新工作。
白天我奔波面試、重整履歷、試圖為自己鋪出一條新路。
晚上回到家，還要試圖挽回一段正在悄悄結束的感情。

很可惜，那段時間裡，只有白天有好消息。
晚上的，都是壞的。

我試著談。
試著改。
試著把問題拆開來解決。

但感情不是履歷，也不是面試題。
不是我準備得更完整，就一定能得到想要的結果。

她越來越沉默，越來越淡。
我再努力，也沒辦法讓她留下。

後來我才明白，我一直以為自己是在為我們努力。
存錢、規劃、負擔比較大的支出、想把房子變成家。
可是如果那個「我們」裡，只有我還在想像未來，那再努力也只是我一個人在裝潢空房間。

我們曾經說好要一起打造的生活，
最後，只剩我一個人在裡面。
