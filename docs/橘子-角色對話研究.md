# 橘子角色對話研究：從可驗證訪談觀察說話方式

> 查核日期：2026-09-23  
> 用途：供改編敘事書稿修訂時參考；不是橘子小說對白的風格定論，也不是仿寫指南

## 研究界線先說明

本次不追小說試閱，也不使用任何金石堂「好書試閱」連結。可驗證材料以橘子本人的公開訪談、對談與問答為主，因此能直接觀察的是：她在受訪情境裡怎麼接話、逗人、短暫岔題、自嘲，以及刊出文字如何保留未完句。

**受訪談話不等於小說對白。** 訪談裡說話的是橘子本人；小說角色則受人物設定、情節功能、敘事視角與編修控制。下文凡談「她筆下人物可以怎麼參考」，都只標為修稿方向或推論，不把受訪語氣直接宣稱為角色寫法。此外，公開訪談可能經過整理，標點、分段與省略號未必逐字保留現場聲音，不能單靠版面符號推論穩定口語習慣。

另一個更直接的限制是：橘子在 2024 年對談中明說「其實我的創作從來沒有出現過婚姻」，並說下一本「我打算來寫問題重重的婚姻」。因此，至少截至該場對談，她過去的創作沒有婚姻樣本；本次可驗證材料也沒有足以對應本書題目的「穩定同居／婚後日常」文本。本研究不會假裝能從她過去作品找出一套成熟的同居對白公式。

## 一、可驗證的材料與各自能支持什麼

### 1. 誠品《提案》：橘子 X 肆一對談

來源：[〈面對愛情，我所需要的、想要的......？《提案》5月號｜作家橘子X肆一對談〉](https://meet.eslite.com/tw/tc/article/202404100002)

可核對的逐字引文：

- 「原來你有缺點喔？」
- 「突然有種要被求婚的感覺！？」
- 「其實我的創作從來沒有出現過婚姻」
- 「我打算來寫問題重重的婚姻」
- 「咦？不小心爆了自己的料。」

前兩句發生在肆一認真回答缺點與婚姻問題之後。橘子沒有離開原題，而是先把對方上一句往誇張或曖昧的方向扭半步，再回到真正的追問。最後一句則把一個普通的檔名細節變成自我揭露的小插曲。

這頁能直接支持的是橘子在這場對談裡的接話方式：抓住對方剛說過的詞、故意理解歪一點、短暫岔開，再回題。它也直接支持本研究的婚姻樣本限制。它不能證明她的小說角色都採用同一種節奏。

### 2. Readmoo：橘子與藤井樹受訪

來源：[〈寫不下去的時候，就找好友一起裸奔啊——專訪《今天不寫小說》作者藤井樹、橘子〉](https://news.readmoo.com/2023/04/20/tsao-orange-and-neal-wu-interview/)

可核對的逐字引文：

- 「因為我斷稿了，需要技術性支援啊。」
- 「欸你一開始好像沒跟我說這部分喔？」

這兩句是少數可驗證的雙人往返。橘子用「技術性支援」包裝請朋友一起寫書的實際原因，藤井樹立刻拆穿資訊沒有事先說清楚。笑點不是兩人輪流說金句，而是第一句把私人的狼狽假裝成公事，第二句把包裝戳破。

這頁能直接支持的是：熟人之間的玩笑可以靠「假正經命名」與「對方當場拆台」成立。它仍是受訪刊出的片段，不是小說場景。

### 3. BIOS monthly：長篇專訪

來源：[〈不純的愛情，不純的文學──專訪橘子・曹筱如：為什麼我的小說是一個弱勢的東西？〉](https://www.biosmonthly.com/article/11601)

可核對的逐字引文：

- 「我覺得寫生活化的東西，對我來講比較舒服。」
- 「對我來講，我就是把日常生活小說化、故事化，這樣而已。」
- 「我是不這麼覺得啦，因為我們版稅確實收得比較多，哈！」

前兩句是她對創作材料的直接自述，只能支持她偏好生活化材料，不能進一步證明角色的句長、稱呼或玩笑結構。第三句出現在嚴肅討論大眾文學的弱勢位置之後：她先表明不同意，再以版稅與一聲「哈」突然卸重。

這頁能直接支持的是：她受訪時會在嚴肅論點後補一個現實而自嘲的轉折；也能支持她自述的創作材料與日常生活有關。從此推到小說對白，只能算方向，不能算文本證據。

### 4. 妞新聞：完整 Q&A

來源：[〈妞專訪：女孩的青春書櫃上都有她！跟著橘子一同回顧過往美好與遺憾〉](https://www.niusnews.com/=P2jssfj9)

可核對的逐字引文：

- 「那個，就，散文跟小說的差別是什麼？字數嗎？還？」
- 「好像滿丟臉的喔？」

第一句保留填充詞、連續補問與沒有補完的「還？」；下一句則立刻把自己的不確定變成自嘲。這是目前公開材料中最接近「沒有把話說完」的單一例子。

能直接確認的只有：這則刊出的 Q&A 確實如此呈現。由於訪談可能經過文字整理，不能據此宣稱橘子平常總用未完句，也不能把頁面標點當成現場錄音的逐字節奏。

### 5. 中央社「文化+」：實地專訪

來源：[〈橘子的大情小愛 vs. 敷米漿的洗車日常〉](https://www.cna.com.tw/culture/article/20190921w002)

可核對的逐字引文：

- 「這手機還真先進，會講話。」

報導交代的情境是：她半睡半醒，把來電誤認成鬧鐘，接著把電話裡有人聲這件事說成手機「會講話」。這個笑點不靠完整笑話，而是把一個日常誤認再往荒謬處推一小步。

這頁能直接支持的是這一次生活敘事中的小幅錯位。它是記者轉述採訪情境，不足以單獨證明穩定、普遍的說話習慣。

## 二、從這些材料能推出的說話方式特徵

### 1. 先抓住上一句最好玩的部分，再問真正的問題

**證據層級：直接證據，限誠品這一場對談。**

「原來你有缺點喔？」接的是肆一自述缺點；「突然有種要被求婚的感覺！？」接的是對理想婚姻的追問。兩次都沒有真的換題，而是先借對方的用詞逗一下，再繼續原題。可觀察的節奏是「接詞—扭半步—回題」，不是長篇鋪陳笑話。

### 2. 岔題幅度小，笑點過後仍把談話交還原題

**證據層級：直接證據，限誠品對談的前後文。**

求婚的玩笑後面緊接著是她對理想婚姻的回答；檔名的自曝之後也立刻回到書名怎麼產生。公開片段顯示的不是漫無目的跳題，而是短暫側身一下，隨即回到共同話題。

### 3. 用假正經的名稱包住狼狽，讓熟人負責拆穿

**證據層級：直接證據，限 Readmoo 刊出的雙人片段。**

「技術性支援」把斷稿與求助說得像工作分工；藤井樹的回應則指出關鍵資訊原先沒說。這種往返的親密感來自彼此知道真正狀況，不是兩個人都必須同樣機智。

### 4. 幽默常從生活細節偏移一小格

**證據層級：直接證據有兩個單例；「常」仍是跨材料推論。**

把普通追問聽成求婚、把電話人聲說成手機會講話，都保留原情境，只故意歪讀一點。較穩妥的推論是：這批材料裡的幽默不是華麗對仗，而是從眼前情況長出一個小錯位。樣本數不足以宣稱這是她所有談話或小說的主導手法。

### 5. 自嘲用來卸重，不一定用來否定自己

**證據層級：直接證據；功能判讀是推論。**

談文類地位時提版稅，談寫作資歷時問「好像滿丟臉的喔？」，都把原本可能沉重或權威的說法降回可接近的語氣。從前後文看，自嘲沒有取消她原來的立場，而是讓話不必以結論式金句收尾。

### 6. 未完句可以保留思考正在發生，但目前只有單例

**證據層級：直接證據只有一則刊出文字；穩定習慣無法證明。**

「字數嗎？還？」讓讀者聽見說話者仍在找下一個可能答案。可供修稿參考的是「在低風險、對方能接住的時候，未完句可以保留現場感」；不能據此替所有角色大量加入省略號、填充詞或半句話。

## 三、明確不能主張的事

1. **不能主張這就是橘子小說對白的具體寫法。** 本次沒有採用小說正文或有效試閱，無法證明她筆下角色的句長、稱呼、搶話頻率、動作搭配、沉默位置或男女角色差異。
2. **不能主張她已寫過穩定同居或婚姻日常。** 她本人明說此前創作沒有出現婚姻，下一本才打算寫；本書的同居段落沒有一組可直接對照的橘子作品樣本。
3. **不能把作者本人等同於所有角色。** 作者能在訪談中自嘲、岔題，不代表每個角色都應該活潑、好笑或擅長接梗。
4. **不能把訪談標點當成未經編輯的聲音紀錄。** 問答文字可能經刪節與整理；本研究只能確認頁面上刊出了哪些字串。
5. **不能把「生活化」解讀成不必處理敘事功能。** 那是作者對材料偏好的自述，不是「日常對話寫得越多越好」的規則。
6. **不能用留白取代必要協商。** 金錢、家務、身體界線、工作安排與共同未來仍需說清楚；未完句只適合對方已有足夠脈絡、而且不影響知情選擇的時刻。

## 四、對照本書現況的建議方向

以下以使用者指出的現況為前提：兩人同居後的對白多在協商生活安排，關係好時少有純粹在玩的往返。這些是修訂方向，不是代寫句子。

### 方向一：在任務完成之後，保留一小段沒有決策結果的對話

不要刪除必要的生活協商；改在協商告一段落、等待某件事、一起移動或做完家務的空檔，留出兩三個回合。這段話不必新增資訊、承諾或衝突，只要讓讀者看到兩人除了能把事情談妥，也願意把注意力花在彼此身上。

驗收時可問：刪掉這幾句是否不影響事件因果，卻會讓兩人的相處少一點辨識度？若兩者皆是，才算補到了「純粹在玩」的功能。

### 方向二：從對方剛說的詞或眼前小事偏移半步，再迅速回題

玩笑不必另造段子。可先找每場裡原本就有的物件、措辭、失誤或習慣，讓其中一人故意作字面化、過度正式或略為誇張的理解；一兩拍後回到原來的事情。這對應可驗證材料中的「小幅錯位」，同時避免把角色突然改造成句句接梗的喜劇搭檔。

### 方向三：不要要求兩人平均機智，替他們分配不同的玩笑角色

一人可以比較常發起歪讀、假正經命名或自曝；另一人可以拆穿、順勢補一刀、只用動作回應，或乾脆把話拉回來。固定但不僵硬的不對稱，比兩人輪流說漂亮句子更能形成關係辨識度。角色分工應從本書既有性格與共同經歷長出來，不照搬橘子與受訪者的表面語氣。

### 方向四：只在低風險且共享脈絡充分時使用未完句

可把未完句放在舊梗、彼此都看到的狼狽、已重複多次的習慣，讓另一人能自然接住；不要放在房租、家務分配、工作界線、身體同意或共同未來等需要明確回答的內容。這樣能讓輕鬆段落與協商段落產生節奏差，又不把「默契」寫成逃避溝通。

### 方向五：讓玩笑承擔卸重與陪伴，不承擔證明「他們很甜」

玩笑最適合出現在一方剛有點狼狽、過度認真或自我要求的時候，用來把氣氛放回兩人可呼吸的範圍；不必每次上升成愛情宣言。若一句話只是在向讀者展示恩愛，卻沒有接住眼前情境或對方狀態，就仍會像安排好的功能句。
