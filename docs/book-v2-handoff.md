## 待辦二：第五章加厚

作者的判斷：這一章對「他為什麼非她不可」著墨太少，讀者看到的只有知三當三的過程。素材在 `docs/my-story/Chapter 13｜我不想再放開.md`，關鍵是「營區不像家，家也不像家」「哪裡都不是岸」「她成了我的綠洲」「把一點點被需要當成整片水源」。**這些不可以寫成旁白，要由場景與動作演出來。**

擴寫集中在服役倒敘段（從「我為什麼會把整個晚上空給她」到「漸漸地她從只會按讚的人變成我放假後要去見的人」），600 → 約 1,800 字，全章約 7,500。生日、花燈、流星、螢火蟲四場一字不動。

四件事：

1. **哪裡都不是岸**：保留「第一次休假開車回台北，天還沒亮就醒」，後接兩個動作——家人問他要不要留下來吃晚飯，他說要收假；同梯的群組約去哪裡，他沒有回。
2. **岸是她身邊那個位置**：現稿「營區剛好在她住的城市，後來我便在附近租了一間小房間」太順，改成看得見的決定——他算過從台北開回營區要多久，也算過她下班的時間；那間房走路到營區二十分鐘，開車到她上班的百貨十五分鐘，他選的是後者。不要說明理由。
3. **她也依賴他**（本章目前完全沒有）：她開始在深夜打電話給他，講她和男友的爭執，講到一半自己先睡著；掛斷以前說一句「還好有你」。隔天他站哨時還在想那句話。
4. **被需要當成整片水源**：不寫出來，用行動演——她某天問今天能不能見面，他把原本排好的休假整個換掉。

另外一處：「情人節當天也是一樣的順位，要等她和另一個人的行程結束，才會輪到我」這句把台北的聖誕樹併進去，不另開場景。
