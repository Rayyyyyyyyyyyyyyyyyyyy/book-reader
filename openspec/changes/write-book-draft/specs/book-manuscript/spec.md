# book-manuscript

> 本 spec 刻意薄：內容標準的單一事實來源是 `docs/chapter.md`，此處只定義驗收行為，不複製架構細節。

## ADDED Requirements

### Requirement: 每章符合寫書依據
每章新稿 MUST 對照 `docs/chapter.md` 的現行腳本，承接前章處境，以符合改編設定且有前因後果的事件、資訊、選擇增加理解。篇幅與觀念配置依敘事需要決定，不要求每章固定安排核心句、分類、反例或行動問題。

#### Scenario: 一章初稿完成時的驗收
- **WHEN** 任一章初稿寫完
- **THEN** 核對改編設定、當章進展、相鄰章交接與必要的判斷條件；沒有新進展時創作必要事件或調整結構，不以換例子或補金句填滿章卡

### Requirement: 單一故事的改編與進程
新稿 MUST 依使用者授權，繼承所提供故事的整體脈絡，允許創作、合併或重排人物、對話、時間與事件，不要求忠實還原每件現實經歷。MUST 維持角色、視角、約定與後果的連續性，交代作品的改編性質；MUST NOT 將新增情節回填為作者真實生命素材。

#### Scenario: 整理稿比原始素材多出情節
- **WHEN** 台詞、場景、動機或日期只在衍生稿出現，或各版本衝突
- **THEN** 可依本作品需要取捨與改編，建立一致設定，不把逐項核實真實經歷作為開寫前提；明示引用真實紀錄時仍須核對來源

#### Scenario: 同一組人物跨章出現
- **WHEN** 下一章沿用前章人物
- **THEN** 前章選擇的後果持續存在，本章事件或理解有新進展，不能只讓同一人物輪流示範另一個概念

### Requirement: 初版觀念與 hook 承接
新稿 MUST 對照 `docs/chapter.md` 的初版觀念保留核對，保留核心命題、必要條件與可使用的工具。MUST 保留有作用的 hook 並兌現；不要求相同的舊案例、逐章金句或固定懸念結尾。

#### Scenario: 新稿主題名稱與舊稿一致
- **WHEN** 故事稿已有某項主題或術語
- **THEN** 仍須核對具體事件、反思或部稿是否承接原觀念的必要區別；僅在腳本表格有列名不算正文完成

#### Scenario: 章節使用懸念或反差
- **WHEN** 章節以欲望、問題、物件或反差吸引讀者
- **THEN** 後續事件有實際進展與回收，不以空泛預告或隱藏敘述者已知答案代替推進

### Requirement: 聲音與引用策略一致
全書 MUST 以 `$rui-xuan-book-v2` skill 的正式寫作聲音書寫，並遵守「默默吸收」引用策略：不明引作者與書名、不搬原句與實驗數據當背書，機制用自己的場景與比喻扛。

#### Scenario: 章節中出現吸收來源的觀念
- **WHEN** 章節內容用到讀過的書的觀念（如課題分離、系統一）
- **THEN** 以日常語彙或自己的話重講，不出現「某某作者說」「某書指出」式的明引

### Requirement: 修訂流程包含 humanizer
後續新寫或重寫的稿件 MUST 依 `design.md` 執行初稿、乾淨讀者、獨立編輯、humanizer 潤飾及主 session 驗收，適用於章節、序章、結語及各部引言／練習／小結。humanizer MUST 保留作品已建立的設定與事實、必要限制、章節功能、Rui 聲音與有作用的節奏，不要求逐字保留已失去作用的舊核心句。腳本與 skill 的更新不等於正文完成這套流程。

#### Scenario: 編輯修訂完成後
- **WHEN** 獨立編輯完成修稿
- **THEN** 主 session 使用 humanizer 完整回看稿件並潤飾，再驗收內容、聲音、字數、格式與跨章銜接；通過後才勾選任務，記錄各階段字數並同步最新盤點

### Requirement: 原始現場檔與改編獨白分開
明示為作者原始現場檔的片段 MUST 有可核對來源，且全書至多 3 處，不要求補足。改編角色的即時獨白、碎句與反覆依敘事需要使用，不受原始現場檔數量限制，也不得冒充作者的逐字紀錄。

#### Scenario: 某章想嵌入現場文字
- **WHEN** 撰寫時想使用即時獨白或原始紀錄
- **THEN** 改編獨白按角色視角與敘事功能驗收；明示為真實原始紀錄者核對來源、用途與總數，回憶重建不宣稱逐字現場紀錄

### Requirement: 初稿檔案結構
初稿 MUST 落在 `book-reader/book/` 目錄，一章一檔，檔名含章序與章名（如 `07-知道卻不改，也是他的選擇.md`），與最上層的讀書心得 `.md` 分開。

#### Scenario: 新章初稿建檔
- **WHEN** 開始寫某一章
- **THEN** 在 `book-reader/book/` 建立對應章序與章名的 `.md`，不放進讀書心得所在的最上層目錄
