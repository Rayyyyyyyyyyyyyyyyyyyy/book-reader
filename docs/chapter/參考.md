# 《把自己的部分做完》章節腳本｜既有稿件與腳本層連續性

## 既有稿件與本輪註解怎麼承接

- 序章 1,500–2,000 字的集中方向保留，但主入口改為工作與關係雙重處境；原手機、考卷及「無法對答案」不為回應舊註解而硬塞進新序章。
- 舊第一章「多知道什麼／有什麼新發現」修正自然度時，仍要避免同義重複；能增加資訊與能讓下一步可行，是兩種不同進展。
- 舊第二章「挖」「把害怕收掉」「用報名回答不安」與相機結尾的問題，轉成準確動詞、少包裝、畫面成立就停的判準；攝影課案例退出主線。
- 舊第三章「累積失望」成為新第五、八、九章的事件推進方向。取消「三個人／兩條線／多組例外／再教工具」的固定排列，保留會改變判斷的責任區別。
- 「後設條件」「不可能發生」「預支額度」等候選替換不直接定案；它們可能更抽象、過度絕對或改變原意，需隨新段落重新判斷。
- 手改的引號、分行、自我制止式重複，以及「卸責」「聯絡簿」這類準確用字，是語氣參考。單獨新增的「怕」先不推定為通用招式。
- 家長晚餐、朋友轉職、家庭育兒、朋友淡去、帳戶受限等舊主案例退出本書主線，原稿與原素材保留。可抽取衝突機制融入改編人物，前提是與既有性格和後果連貫，不只換人名，也不為保存每段舊稿而加支線。
- 本輪不變更 `book-reader/book/` 的檔名、正文、SVG、閱讀器與 JSON 註解。新書正文成形後，再依實際稿件整理章序、目錄與適用的註解；舊稿註解須按引文重新定位，避免現在產生空的新章檔。

## 連續性紀錄

創作時記下並沿用以下設定；此處只維護事實與約定，不重述章節功能。若設定改變核心脈絡，再回查相關章卡。

| 項目 | 需要記錄與沿用的設定 |
|---|---|
| 時間與相識 | 七月三十一日、學業與服役先後、赴日與回台時間、相識媒介所屬年代；素材中的西元年按作品時間線取捨 |
| 等待與抽離 | 第二章重聯時，她告知前段關係已在重聯前結束，第三章正式交往前他已知她單身；第四章得知她另有伴侶，第五章仍選擇參與。第六章回台後由她先傳訊息，他提議露營；她在這次重聯前已結束前段關係，到澎湖才說，露營時他不知道。沿用每次重新聯絡時各自已知的關係狀態、最後一次見面與赴日的先後 |
| 沒問出口的事 | 第三章知道她已單身，仍沒追問「你是誰」、她那句不完整的回答；第六章先有露營時沒問的感情狀態，後有澎湖親密後終於開口，兩次相處不可合併 |
| 共同生活 | 她為同居離開原有工作搬到台北，也因台北有她想嘗試的學習與工作機會；她的轉職課程、兼職排班、回到行政職的時間；有期限的生活費支持到課程結束為止；約定她領到行政職第一份完整薪水後重談分攤，兩人延後且未另訂日期，第八章承認，第九章換屋時真正重談；雙方工時收入、家務及貓的照顧分配；第七章衣櫃依她的收納需求重新分配過一次 |
| 親密與相處 | 第七章協商出週五晚餐；第八章照常，但她取消聚餐後常說「都可以」，他誤讀成和好；第九章開頭因搬家、加班停了幾週且無人提起，章末由她提議在新餐桌上重新開始、他負責準備，之後持續了幾次；第十章她承認相處改善，仍決定離開；短暫靠近限於一次共同吃飯、談舊事或彼此安慰，雙方都沒撤回分開 |
| 活動與分工 | 第八章他在購票前自行放棄演唱會，以保住自己設定的當月存款額，必要支出仍付得出來；她原定朋友聚餐用履行約定支出後的私人餘額支付，爭執後取消；他先前未受託代排交通的是另一場聚會。她另答應週六早上餵食與清貓砂；他在爭執幾天後平靜說明停止未受託的個人行程代辦，共同照顧仍協調，共同費用照原約定履行，到第九章搬家時重談 |
| 家具與買房 | 第九章選定餐桌，最終採用她提出的較小、圓角、方便清潔且在預算內的款式；記錄價格、各自可負擔金額及同意的分攤。她丈量、整理款式與下單，他依約付款並安排收貨，雙方確認配送。他第七章開始為買房存錢，想等存夠頭期款再給驚喜，第九章仍覺得金額不足而不說；第十章挽回時她才得知，也由她說出自己曾想過買房與結婚。雙方從未談成共同買房計畫，存款與已答應的分攤分開記錄。第九章換屋因他遠端工作需要工作空間，新屋月租小幅增加、她通勤縮短，租金增額由他承擔，家具原約定分批添購；記錄新舊月租。他的支出判準：娛樂可以犧牲，耐用家具是必要投資。第十章存款改列失業與搬遷備用金；第十一章餐桌留給他，按同意的現值結算她的份額；第十二章在確認必要支出與緩衝後拿出有限旅費 |
| 雙重未來與收尾 | 第九章公司縮減專案、他的職位暫未受影響；第十章她先提出分開，幾天後他收到職位月底裁撤的通知；新工作確認時約定三至四週後到職；她在約定的整理時間收走第一格衣櫃的衣物，之後才全部搬走；她搬回原居地、先住家裡；房租、物品、共同費用的承接，ㄤ堆 由他照顧 |
