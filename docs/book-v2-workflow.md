## 執行方式

- 一次一章，依故事順序；整章完成、檢查後 commit 一次
- 每一步都開新的 `codex exec` session，不共用上下文
- 模型 `gpt-5.6-sol`，reasoning effort high（使用者也接受 `gpt-6-astra` high；同一本書盡量維持同一模型）

```bash
docs/book-v2-pipeline.sh full   07 "住在一起以後" "第七章｜住在一起以後" "8,000–9,000"
docs/book-v2-pipeline.sh expand 01 "十一點的電話" "第一章｜十一點的電話" "6,000–7,000"
docs/book-v2-pipeline.sh audit  06 "這一次，我們真的在一起了" "第六章｜這一次，我們真的在一起了"
```

- `full`：新章，寫作→讀者→編輯→潤飾→稽核
- `expand`：既有章擴寫到目標字數，第一步改為以現稿為底展開場景，保留作者手改過的句子，其餘四步相同
- `audit`：只跑一致性稽核

本書定位：故事為主、每章都有可帶走觀念的成長書，觀念由故事本身承接。部稿（2026-09-18）與章末回頭看（2026-09-20）都已取消；是否在書末附錄工具與練習，寫到書末時再討論。規則見 `docs/chapter.md`「章末回看拆解」。

Codex 的即時過程直接輸出在執行腳本的 terminal（由 Claude 在背景執行時，可在 Claude Code 的背景任務輸出中查看）；同時存成 `~/.cache/book-v2-logs/NN-步驟.log`，最後回報在 `NN-步驟.last.md`。

## 每章五步

| 步驟 | Skill | 做什麼 | 產出 |
|---|---|---|---|
| 1 寫作 | rui-xuan-book-v2 | 先寫場景表，再照表寫正文；追加連續性與資訊邊界；量字數 | 正文、scenes、continuity |
| 2 讀者 | ai-reader | 以第一次讀的人回應：閱讀反應、畫面感、人物、時間與前後是否合理、hook、觀念 | reader |
| 3 編輯 | ai-editor | 合併讀者意見並分級；分開「刪同義反覆」與「補場景」；列修訂清單與字數目標 | editor |
| 4 潤飾 | rui-xuan-book-v2 | 執行清單；新增場景前先查場景表與全章相關段落；量字數；寫潤飾紀錄 | 正文、editor 末尾 |
| 5 稽核 | （無） | 逐段建帳本，只抓事實矛盾並最小修正，補資訊邊界 | 正文、audit、continuity |

稽核碰到作者手改或確認過的句子不直接改，列入 `NN-audit.md` 的「留給作者決定」並附建議改法，供作者人工校閱時參考。

之後由 Claude 整章讀過，照下方清單核對並修正，交給作者校閱；回報時列出「留給作者決定」的項目。作者說好後才 commit。

## 篇幅

全書刪去章末回頭看後約 9 萬字，不為湊字數加場景；各章範圍見 `docs/chapter.md`「篇幅、引用與驗收」。字數計法：不含標題行與空白，含標點。長度來自場景完整展開，不靠形容、同義反覆或回看說理。

## 一致性清單

稽核步驟與 commit 前的人工核對都用這份：

- **設定推導**：細節從已建立的設定推出，不從類型預設補上
- **物件歸屬**：照片是誰的手機拍的、東西是誰帶的、誰付的錢
- **時間與狀態延續**：時段、天氣、濕掉或受傷的東西在後面合理延續
- **資訊邊界**：人物只知道自己實際得知的事；他沒說出口的念頭、願望、計畫，她不知道
- **對白呼應**：笑點或回扣讀得出在接哪一句
- **動作可演出**：動作順序在空間裡做得到
- **年代器物**：舊式手機、電腦等器物的操作合乎當年實際
- **擴寫殘留**：舊摘要已被新場景演出時要刪去，不讓同一件事發生兩次；同一問題或玩笑不在同一場對話重複
- **數量相符**：文中說的字數、次數、時長與實際內容一致

## 使用者修稿偏好

持續從作者的手改與明確採納的修訂歸納，寫作與潤飾都要遵守。最初整理自序章到第六章，後續每章校閱完成時依下方「作者校閱完成後」流程迭代；不把尚在討論的候選句當成偏好（第 1、2、4 條也已寫入 `rui-xuan-book-v2` skill 的「語言」一節，適用於所有書稿）：

1. **不用真實店名**：以「小茶坊」這類通稱代替可辨識的店家
2. **不把潛台詞說白**：對白不替人物解釋自己為什麼這樣說；能用動作接上的，就不再補一輪問答
3. **對白口語、直接**：說人真的會說的話，例如「我只是想見妳」「我現在沒有時間」，不用「我是想幫妳」這類較抽象的說法。第十三章作者把被問「你拍這個幹嘛」後的回答「到了就拍了」改成「到此一遊」，用現成的口語成句代替解釋自己的動機
4. **一個時刻只留一個細節**：同一段不堆多個物件或感官描寫，選最有作用的那一個。第十二章進一步取消「每場至少一個身體細節」的配額；雨淋濕外套不必寫成衣料摩擦皮膚，書店不必靠舊車票、報紙與時鐘製造氣氛。細節須符合穿著與場景，也不因具體就必須留下。第八章後續手改將「手卻還放在滑鼠旁邊」收成「手卻還放在桌上」，保留停住的動作，省去無作用的物件定位
5. **用字求準**：時態（「也會去」與「也有去」）、場所（百貨而非商場）、比喻語氣（「好像」）、說法（「感情狀態」）、器物（電磁爐而非兩口爐）、動作結果（照片是糊掉不是晃掉）都要貼合當下。人稱也要符合誰在作決定：第五章作者將「我們就不要再像現在這樣見面」改成「我就不要再像現在這樣見面」，保留他對自己參與方式的選擇，不替雙方宣告共識
6. **對白邏輯**：說話者、代名詞與呼應要接得上前一句或剛發生的動作
7. **動作要合乎實際安排**：例如軍人的休假是刻意安排的，不是把工作排開；志願役的手機自己保管，只有出操、值勤、站哨時不能用；需要定時的是餵罐頭，不是清貓砂
8. **物件要合乎實際使用**：例如按亮手機先看到的是鎖定畫面，不會直接停在備忘錄
9. **用詞貼合事實與行話**：職位被裁撤是「位子不復存在」，不是「椅子不屬於我」；事故處理說「止損」而非「止血」
10. **不為具體而編造過細的數字或規格**：例如「照著筆記上的三個詞」改為「準備好的說辭」；細節要有作用，不是越精確越好
11. **動詞平實**：「反過來放」而非「反扣」，不用偏文學的替代詞
12. **說同一件事的相鄰短段落併成一句**
13. **改編說明不放進正文章節**：交代改編性質留給書前說明，章節正文直接進入故事
14. **能力寫出累積過程**：「到後來已經練到」而非「我練到」，讓讀者感到時間過去
15. **章末不替下一章揭曉**：停在「那句話」而不寫出內容，揭曉只發生一次，交給下一章開頭
16. **短暫回看用人話，不照搬章卡用語**：章卡裡「不能自動算逃避求證」這類分析句是給編輯的判斷，正文要改成人回想自己時會說的話，例如「我沒有再打，不全是因為不敢」
17. **寫出狀態的轉變**：狀態改變的瞬間寫出「突然」「了」，例如「電話那頭突然沒有了聲音」，讓讀者感到前後落差，不只寫結果
18. **不適寫成看得見的物理細節**：不用「磨得不舒服」「等風吹乾」「褲管濕了」這類概括，改寫成鞋墊黏上一層濕沙、鞋子倒過來敲出一小撮沙、水泥地被曬得發燙；仍守第 4 條，每個時刻挑一個
19. **轉述改成直接對白，回嘴短而準**：「她說我回答太快，沒有參考價值」改為她直接說「你根本沒看」
20. **不讓鬥嘴過度機靈**：一來一往的俏皮回合（「妳不是相信我在做作業」「我只是沒有拆穿你」）刪到只剩一句自然的否認
21. **人物的話不說滿**：「我現在連見面都不想排」改為「我現在只想把書念完」，話比需要的輕，誤讀才留給聽的人
22. **問號由作者依情境決定**：「？」要看情境與前後文，目前沒有固定規則。寫作、潤飾與稽核都不為了統一而增刪問號；讀起來可能被誤讀成陳述的問句，列給作者判斷
23. **搭配與在地用詞**：寫作業、寫資料而非「做」；小吃用當地常見的（地瓜球）；避開非台灣慣用的詞，第十一章作者把「樓道傳來電梯到站的提示音」改成「外面的走廊」；「想到」與「發現」依人物本來知不知道區分
24. **修改呼應句時一併改回扣處，回扣要含蓄**：前面的台詞改了，後文回扣它的句子要跟著改；回扣不必複述原句，例如「她什麼都沒說，只是把圍巾往上拉得更高」，讀者自己會連回去。也不要替讀者指認回扣（刪去「這個動作和很多年前的捷運上一模一樣」）
25. **少用分析框架詞**：「把願望縮成一個有限的下一步」改為「變成另一種延續：遊戲之外，我還想繼續聯絡」；寫自己的願望用「我想」，不要把它包裝成兩人的提問或概念名詞
26. **「現在的我」只短暫出現**：一兩句承認當時沒看懂的地方就回到故事，不展開說理。這不限制當時人物的內心反應；第五章「那你回去又要消失了耶」後，作者選擇接男生「她是不是也會等我的訊息」的猜測與期待，不再補一輪回話。內心戲只寫他此刻想到的事，不把猜測當成對方心情已被確認，也不追加事後診斷。第十二章作者要求補候車時的舒服與聽孩子齊唱時的感動；人物當時真的感受到的事可以直接寫，不把「不解說」誤用成只留外在動作。感受停在當時，不接痊癒或人生結論
27. **自問句只問一件事**：「是不是只是自己沒有辦法接受那個答案」，不用「是……還是……」的二選一
28. **自我檢討不下重手，寫出沒做到的具體動作**：「我仍要她」改為「我仍希望她」；「沒有把那份慌留給自己」改為「沒有把自己心中的那份慌安撫下來」
29. **寧可刪贅詞，不為字數補句**：一節讀起來完整就停，略低於目標字數也不硬加；長度只能來自展開場景，不來自多說一遍
30. **例子少而完整**：同一種處境不要用好幾個事件各演一次；一章留少數幾個事件，把親密、身份拉扯、行程取捨分散進這幾場。第五章刪去海邊與第一次晚餐，只留生日、花燈、流星、螢火蟲。第十二章刪掉飛天翼龍、嵐山與刻意找展館，把慢下來的過程集中在宇治；京都只保留隨意逛進書店、讀入迷。不要替每個地點各安排一個心理階段，也不為補篇幅復原已刪場景

31. **不放事後評價與主題句**：故事裡不由旁白先替讀者下判斷，刪去「後來知道的答案，不能回頭替這趟露營變得比較乾淨」「此時的我，不知道自己真正不肯放掉的是什麼」這類句子，改用當下的動作或物件（「備忘錄還停在第一行」）。動作、對白已呈現的誤判或退讓，也不在後面補一句翻譯；第八章已採納刪去談規則後的「我原本以為……我才發現……」反思，以及章末「還有什麼也一起收了回去」，讓人物的回答與前文的變化承擔意思。第十章同理，作者刪去章末的「家也還沒有真的空」只留「衣櫃的第一格空了下來」，也刪掉他結帳前「把銀行頁面的用途看了一次」——不在收尾處替讀者點出那個帳戶的意義。情緒最強的時刻同樣不解說原因：第十一章作者把「我站在冰箱前，忽然知道自己不能再把每個晚上都排成同一個樣子／不是因為已經哭夠了／是因為……」整組收成「我站在冰箱前，失神」
32. **熟悉的感受不再拆解**：對人物來說早就熟悉的氣味、聲音或觸感，用一句帶過即可（「我聞到那熟悉的味道」），不重新描述成分
33. **重複句型按作用減量，不設次數配額**：同章多次出現「我以為」時，先看是否反覆提醒同一個誤判；動作已呈現的非關鍵說明可刪，不只換成同義詞。承擔跨章遞進的信念句保留，例如第七至九章章末那組句子。第八章本輪由七次減為五次是修訂結果，不是其他章的上限
34. **流水帳兩型**：（一）把完成一件事的步驟寫齊——移動、開關、拿取、收納、填表、付款；（二）連著幾段確認同一個狀態或同一份親密。先看「這一段之後，有沒有人知道了新的事，或失去了什麼」，也看人物的感受、興趣與選擇是否推進；沒有推進才刪。序章到第八章本輪共清掉二十餘處。但承載未說出口的話的日常動作要留（反覆摸保冷袋、把房租寫回備忘錄、爭吵後照常餵貓），該收的是它周圍的辦事程序。**道謝、致歉、回應邀請與送客不是辦事程序，是待人**：刪掉看屋、配送、面試、看診這些流程時，不要把剛服務完或剛幫完忙的人一起刪成背景（2026-09-22 由第 37 條的全書掃描補回十餘處）。第十二章補充：心理鬆動、興趣與感動也算推進，不必每段都有新資訊或損失；該刪的是為了證明同一個轉變而排列的細節與流程。刪去取放背包、翻完再找下一期、擦地敲沙、開關筆電與逐步鋪床，保留候車觀察、河邊停留、讀入迷與被齊唱打動的過程。把每段都寫成「遇事、想她、做不同選擇、確認改變」，仍是重複，即使每段換了景點。第十三章作者刪去捷運站口的「他點了一下頭／那你快下去。到家傳訊息／我答應他，刷卡進站」，讓對話直接接到理解；同章也把「我刷卡上船」收成「上船後」。道別與刷卡進站屬於辦事程序，不承載未說出口的話
35. **不替自己的行為命名**：人物不用分析語替自己或對方的行為歸類。第九章刪去或換掉了三句同型的話——「聚餐那次，是我拿以前做的事要妳退」「我沒有想要再拿別的事壓妳」「我上次不該拿那些事叫妳取消」，改成具體的承認與否認：「妳那場聚餐，我不該讓妳取消」「我這次只是在講桌子」。旁白同理，作者把「沒有再看我的臉色」改成「沒有再看我」，不替讀者指出那個眼神在確認什麼。已經道過的歉不在同一場再道一次；對方問「現在呢」時人物可以不回答，沉默由對方的等待承接（「她等了一會兒，沒有再追問」）
36. **一段一件事**：不同的事分段寫，不擠進同一段。第九章作者把飯後那段「沒有重談聚餐／她說公司退件／我說專案檔名／她問我是不是又自己整理」拆成三段，第十章也把衣櫃配送與章末總結各拆出一段，第十一章把衣櫃那一側的觀察與「等她真的把東西拿走」拆開。相鄰短段落說的是同一件事時才合併，見第 12 條
37. **男主角不習慣性反駁**：他的回話容易長成反問或糾正，讀起來像辯論型人格。第十章作者把「妳不是早就找不到」改成「妳常常說找不到」，把「不然呢」改成「嗯」、「回信了」改成「嗯嗯」，把「好，先收掉一條最壞的路」改成「好，至少先上岸了」。**判準（2026-09-22 重訂）**：先看對方這句話把什麼交給他，再看他有沒有接住。「不推回去」是不把對方的話立刻改寫成反問、糾正或辯解，**不是把回應清空**。對方給了時間、勞動、資訊、邀請、風險或關心時，他先用一句人會說的話回應那份付出，之後仍然可以不同意、拒絕或保留缺點。說謝謝、道歉、回答別人的邀請，都不是把潛台詞說白，也不是替自己的行為命名。他真正的反駁留給他真的要爭的那幾場。

**沉默只限四種情況**：他正在消化足以讓人失語的消息；他真的沒有答案，而場景有寫出對方的等待或他的卡住；他一開口就會把已經結束的事重新變成挽回，而那場的重點就是他忍住不說；或那是不等個人答覆的集體通知。**不用在別人剛幫完忙、道歉、邀請、問候或提供具體照顧之後。**

**單音節或極短回答只限三種情況**：封閉式的辦事問句，對方只需要「要／不要」；短答之後立刻有動作或下一句把回應完成；或他在重大消息與關係破裂中只說得出這麼多，而場景的力量正來自那個說不完。第三種必須稀有且有明確情境，不能流遍工作、朋友與服務往來。

**閱讀檢查**：把他的反問全部拿掉後，對話裡是否只剩別人在提供時間、善意與關心，他只接收結果。如果是，那就不是反駁型人格被修好，而是人與人的回合被修掉了。此時依第 40 條以閱讀體驗優先，再用第 2、31、34、35 條檢查新句有沒有說白潛台詞、事後說理、補辦事流程或替行為命名，**不反過來用這些條目否決一句基本的人性回應**。

這一條原本的執行方式造成全書性的過度矯正：作者 2026-09-22 表示「很看不爽男主愛理不理的態度」。查證後全書八萬五千字裡他說謝謝或麻煩你原本只有六次，單音節回覆十九處，而 `book-reader/is-me/` 的素材裡他渴望被需要與被重視、在意別人怎麼看他、和一桌陌生人吃一頓飯會開始相信人有善意。逐處清單與「該留」的十二處見 `book-reader/book-v2/_feedback/全書-對人的態度.md`。作者裁定全部採用，隨後在校閱時改寫或退回 5 處，最終留下 16 處，並給出三條校準：

- **一次性的服務往來不補道謝或道歉**：碼頭人員提醒他不要擋出口、醫生講完檢查結果，補一句反而是禮貌表演。他們把事情做完就離場，動作接得住就夠
- **朋友的關心可以用動作接住**：第十一章他正在消化分手、被問要不要去朋友家睡，作者把「好，我會回有沒有吃，謝謝你」還原成「我笑不太出來，還是點了頭」。那正是上述沉默的第一種情況，補話會把他修得太完整
- **道謝用最簡單的說法**：「謝謝你的幫忙」勝過「謝謝你先幫我說」，也不要「謝了」這種口頭語

問題從來不是他不夠客氣，是別人給了東西他沒有接住。接住可以是一句最簡單的謝謝，也可以是一個動作

38. **保留有根的隱喻**：作者明確表示喜歡隱喻；「不要刻意」「去除 AI 味」不等於只用直白陳述。書名與篇章名優先從既有生命素材、原始敘述與作品中找能承載感受及變化的意象，讓理解隨閱讀形成，不要求標題先解釋主題，也不為候選名字反向加戲。共用原則同步於 `rui-xuan-book-v2` skill「比喻」一節

39. **理解句要有說話的時間與主體，不寫成無主的格言**：第十三章作者把「想有人一起，和今天幾點回家，原來可以是兩件事」改成「這時候才發現想有人一起，和今天幾點回家，其實是兩件事」，也把「真正讓我停下來的，是我常把還沒說出口的未來先放到今天前面」改成「這時才意識到，原來我過去總是把還沒說出口的未來先放到眼前」。兩處都不是刪掉理解，而是把它放回人物當下的意識。判準是：**這句話是誰、在什麼時候發現的**；無主的判斷句讀起來像格言或作者插話，補上「這時候才發現」「這時才意識到」就回到故事時間。與第 26、31 條並用——能由動作承擔的理解仍然刪掉，留下來的那幾句要有主體。同輪作者也把判決語與分析語改成日常說法：「那些記得的事不必被判成錯」改為「那些記得的事沒有對或錯」，「只是那些靠近不能替現在作答」改為「我們都在用自己的方式靠近彼此，卻忘了開口確認方向」；後者把抽象的否定換成兩人各自做過的事

40. **閱讀體驗優先於規則與清單**：作者 2026-09-22 明確說「閱讀體驗才是最重要的」。這份偏好與作者手改保護清單的用途是防止流水線亂改，**不是用來擋作者自己的修改，也不是拿條目替一個讀起來不順的句子背書**。後記那一輪連續三次拉扯都出於此：Claude 以「這句在保護清單裡」為由不動一個讀者與編輯都點名的心理語彙（「身體總是比較先知道」，且該句本來就不是作者手改的），又因為只回復單句而留下失去對照端的「也不能反過來」，還把 v1 的反轉句與它的定義句緊貼在一起，讓反轉被自己解釋掉。判準是整段讀起來順不順，條目其次。**保護清單只放作者真正手改或親自挑選的句子，不放 Claude 自己寫的句子。**

作者同一輪的手改也給出具體做法：

- **密集的判斷段拆成一句一段**：「我後來才比較能看清的兩件事：」領起，兩項各自成段，讀起來有呼吸；不把四個短判斷擠成一段
- **不寫成他擋著對方，寫成他沒有開口**：「沒有讓她參與」改「沒有邀請她參與」，「共同生活裡沒談清楚的安排，要讓對方也在場」改「共同生活裡的安排，要邀請對方也在場」
- **不替自己的行為下判決**：「要對方退讓」改「照著沒有說好的方向前進」
- **為回應讀者顧慮而加的條款式補丁整句拿掉**：「額外的付出可以出於喜歡」之後不再補條件，顧慮由後文自然承接
- **隱喻不要解釋成機制**：「慢慢代謝掉的」一度被擴寫成「大腦透過新陳代謝讓這些經驗變成養分，幫助我吸收與成長」，既是錯的機制主張，也把身體感換成三個抽象詞；收回原句
- **成語會把意思拐回去**：「反求諸己」的傳統用法是檢討自己，放在講內耗的段落會讀成「要更努力檢討自己」，改成「只要答案得由別人給，那份清單就不會有完成的一天」

## 作者校閱完成後

作者明確說「第 N 章改好了」時，視為該章人工校閱完成並同意定稿、commit，不再重問確認；若另有「先不要提交」等限制，以作者當次指示為準。「這句可以」「這幾處照改」只核准局部修改，不代表整章定稿。

1. **核對定稿**：整章讀過並對照本輪修改，確認採納項目已套用、作者手改句保留、刪改處銜接正常。不自行再潤稿，也不重跑寫作流水線；若有實質矛盾，列出具體位置與影響，交作者決定後再提交。
2. **同步事實**：若修稿改動時間、人物、物件、約定或資訊邊界，同步本章相關的 `_continuity.md`、場景表或章卡。歷史回饋保留原貌，必要時附上本輪處理結果，不把舊問題寫成仍待處理。
3. **迭代修稿偏好**：回看本輪作者手改與明確採納的取捨，辨認可供後續章節使用的原則，更新本文件「使用者修稿偏好」。已有相同規則就補充或合併，附必要的前後例子；單一場景的選擇留在該章紀錄，不升格成全書禁令。沒有新原則時不硬加條目。只有涉及跨文體的共用聲音規則時，才同步 `rui-xuan-book-v2` skill。
4. **更新進度**：依既定算法重算字數，在交接文件及相關章節紀錄標示校閱狀態、已處理事項與後續承接事項；不能因正文檔已存在就視為定稿。
5. **精準提交**：逐一指定本章正文、相關回饋及本輪文件；共用檔案若混有其他未核准章節的修改，只暫存本章相關部分。核對 staged diff，不使用 `git add -A`。章節 commit 主旨包含 `hand edit`，不得夾帶其他尚未校閱的章節。
6. **回報**：提供 commit 結果、定稿字數及本輪新增或補充的修稿原則；有尚未解決的項目則如實列出，不宣稱整章已完成。

## Commit 規則

- **書稿內容等作者說好才 commit**：章節正文、該章回饋檔與 `_continuity.md`，跑完流程、Claude 讀過並修正後，先留在工作區，交給作者人工校閱；作者說好之後，才一次 commit
- 作者校閱時的手改一起放進這次 commit，訊息寫成 `Apply the author's hand edits and approve …`（含「hand edit」字樣，腳本才抽得到作者手改句清單）
- 等待校閱期間，同一章不再跑新的 Codex 步驟，免得覆蓋作者的手改
- 流程腳本、文件與規格（`docs/`、skill）的調整照常直接 commit
- 回饋檔與 `_continuity.md` 照常隨流程更新

## 為什麼加入場景表與稽核

第六章完成後，使用者讀出八處前後矛盾：豪華露營後段變成自己煮鍋、在帳篷外刷牙；她知道他沒說出口的流星願望；合照明明是她的手機拍的，卻要他傳原檔；外套隔天還在滴水；對白笑點接不上；坐在駕駛座替副駕開門。追查結果：

1. 其中六處出自寫作初稿。一次寫近萬字時，細節是依類型預設當場生成的；提高字數與細節要求後，錯誤機會跟著增加，卻沒有對應的核對
2. 兩處出自潤飾新寫的場景，只接好相鄰段落，沒有回查全章相關物件
3. 讀者步驟以第一次讀的人回應，看不見資訊邊界越界；編輯步驟的注意力在結構，沒有逐行核對事實
4. `_continuity.md` 只記發生的事，沒記誰不知道什麼
5. commit 前的人工檢查只核對章卡事件是否出現，沒有整章讀過

因此加入寫作前的場景表、潤飾新增場景前的回查、獨立的稽核步驟、連續性的資訊邊界，以及 commit 前整章閱讀。
