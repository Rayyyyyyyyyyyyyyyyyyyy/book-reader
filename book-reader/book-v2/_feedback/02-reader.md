# 第二章〈那個沒有回答的暑假〉讀者回饋

## 逐段閱讀反應

### 告白與延後回答（「我喜歡妳」至「我說好」）

**原始反應**

- 「下一次電話響起時，我沒有再把那句話換掉」立刻接住上一章結尾，我會想看他到底有沒有說出口。第三行便兌現，沒有拖。
- 「我喜歡妳」之後直接落到「電話那頭沒有聲音」，停頓有效。我先跟著緊張，接著在「那些解釋全部擠在喉嚨」感到很像青少年第一次告白時的失控，不像經過整理的漂亮台詞。
- 她第一句不是「喜歡／不喜歡」，而是「可是我們住得那麼遠」，我會把它讀成顧慮，也會立刻懷疑這是不是比較不傷人的拒絕。這個模糊讓我繼續讀。
- 「要怎麼見面，誰可以出門，回家時要怎麼交代」把距離的困難落到當時未成年的生活限制，可信，也避免「跨縣市」在今日讀者眼裡顯得太輕。
- 「你等我想清楚，好不好」是一個很重的承諾。讀到這裡，我和敘事者一樣會認為暑假結束後至少會得到回答，而不是把它聽成婉拒。

**推測原因**

- 這段有效，是因為兩人的話都不成熟但符合年紀：他急著把關係說清楚，她先說現實困難，兩人都沒有能力處理告白之後的後果。
- 目前我看得懂她「有顧慮」，但看不出她對他的感情究竟有沒有動搖。這不是看不懂情節，而是人物立場仍刻意或實際地停在模糊處。

### 電話不再響與整個暑假的等待（「隔天晚上十一點」至「只讓我安心繼續等下去」）

**原始反應**

- 「隔天晚上十一點，電話沒有響」很有力。前一章已把十一點養成兩人的固定時間，所以不需要補一句「我感到不安」，缺席本身就有重量。
- 從十一點、十一點半、第一天、第二天，到「即時通的名字一直是灰的」，等待的擴大很清楚。我沒有在時間上迷路。
- 「看見不是，才回去做原本的事」是這段最貼近身體經驗的一句。它沒有把失戀寫得過度戲劇化，反而讓我更能感到手機震動時那一下希望落空。
- 「她需要時間，我如果一直追著問，好像就是我先沒有做到答應的事」讓我看懂他為什麼不再聯絡，不會只覺得他被動或不合常理。同時我也有一點著急：尊重她需要時間，真的等於兩個月都不能確認她是否平安、約定是否還成立嗎？
- 「每一種猜測都讓等待看起來還有意義」準確點出他在做什麼，我有被說中。但緊接著的「現在回頭看」和「把所有空白都自己補上了理由」再次解釋同一件事，開始從故事聲音轉成反思文章的聲音。
- 我喜歡「我不會把那兩個月全部算成自己不敢求證」這個保留。它沒有用後見之明把少年時的自己判成懦弱，也承認「等到暑假過完」確實是兩人說好的期限。

**推測原因**

- 這段最自然地碰到「界線」：他想尊重對方的空間，卻把尊重理解成完全不求證，於是界線和猜測混在一起。因為前面有具體的未接電話、灰色名字和手機震動，觀念不是憑空講道理。
- 「現在回頭看」以下的判讀是有層次的，但兩次說明相近，讀者已從他的猜測看出他在用理由維持等待，因此我稍微感到作者在替我總結。

### 九月的電話與妹妹的消息（「九月初」至「改變我對那個暑假的理解」）

**原始反應**

- 「你是誰」是全章最刺的一句。我會立刻停住，也會回想到兩人在西門町拿著電話互說「喂」的畫面；下一段直接把這個反差叫回來，情緒有打中。
- 我的第一個疑問是：她是真的沒認出，還是在假裝？文本隨即列出「沒認出聲音／沒存號碼／只能用這種方式停下對話」，有保留不確定性，沒有替她定罪。
- 不過，「你是誰」戲劇性很高，高到我也短暫懷疑真實性：曾每天講到手機發燙、只隔一個暑假，完全認不出聲音並不容易相信。文本提出可能性後，我會傾向認為她在拒絕對話，但這仍只是我的推測。
- 「沒事，我打錯了」很可信。那不是成熟的處理，而是被刺到後立刻保護自己的反應。
- 他直到這通電話後才問妹妹，順序合理；前一章妹妹常在通話中插話，也足以讓我接受他知道怎麼找到妹妹。
- 妹妹說她和班上一個男生在一起時，我的第一反應是替敘事者生氣：她可以選別人，但她曾叫他等，之後又消失。這裡傷人的不只是沒有被選，而是約定被單方面留空。
- 「不是回答，但已經足以改變我對那個暑假的理解」意思清楚，卻也略像作者在替事件下註解。我在上一句已經感到整個暑假被重新解讀，這一句的資訊增量不大。

**推測原因**

- 文本很克制地不替她補動機，這讓未知本身成立；但也使她的責任容易被「我們不知道原因」沖淡。即使不知道她為什麼消失，讀者仍看得見她提出等待、卻沒有回來履行回答。原因未知和行為造成的傷害是兩件事。
- 對敘事者而言，妹妹提供的是事實碎片，不是完整答案。這個區分是可信的，也避免把「她交了男友」簡化成所有問題的答案。

### Facebook 重逢至淡水之約（「後來即時通慢慢少了人」至結尾）

**原始反應**

- 「即時通慢慢少了人，Facebook 開始出現我認識的名字」讓我知道時間已經往後走了一段，但不知道是一年、數年，還是更久。這是本章最明顯的時間卡點。
- 他把滑鼠停在「加入好友」很久才按下去，能看出想靠近和怕再次受傷同時存在。她接受好友邀請後，我也立刻想知道她如何看待當年的事。
- 從接受好友、重新通話兩小時，到答應去淡水，進展很順。我的第一反應不是不相信兩人會重聯，而是覺得中間的尷尬和戒心被壓縮了；尤其「這次沒有問我是誰」叫回最痛的一幕後，兩人很快聊回熟悉感，我還沒完全跟上這個情緒轉換。
- 「幾天後，我又做了一次先開口的人，撥電話給她」有一個具體資訊缺口：他打的是當年那支亞太手機、她後來給的新號碼，還是從 Facebook 取得的聯絡方式？如果已隔多年，舊借用門號仍可直接撥通不太理所當然。這裡讓我短暫出戲。
- 她提到前男友已經分手，卻沒有說當年為什麼叫他等、為什麼消失。敘事者用「這是她對當下的交代，不是對當年的解釋」把兩件事分開，我很認同，也因此更在意他接下來為何仍願意赴約。
- 「七月三十一日」突然非常具體，能把模糊的重逢變成下一個即將發生的場景；但因為前面的年份和經過多久不清楚，我只能知道它又是一個夏天，無法確定它離當年多遠。
- 最後的「我還是決定去」會讓我翻到下一章。吸引我的不是「他們會不會在一起」而已，而是：一個曾被留在等待裡的人，這次能不能不再把未知全部自己補完。

**推測原因**

- 後半段壓縮得比前半段快，可能因此保住了往下一章的推力，但代價是重逢顯得稍微太容易。她為什麼接受、為什麼能自然聊兩小時、為什麼答應淡水，都只能從行動得知，還不足以看見她的立場。
- 結尾把「地點」和「兩個人」放進原本只有等待的夏天，形成清楚對照，因此即使舊問題沒有解決，赴約這個選擇仍有情緒上的成立感。

## 人物可信度、動機與雙方立場

### 「我」

敘事者可信。他告白後把對方的請求當成約定、用各種理由安撫自己、被問「你是誰」便假裝打錯、多年後仍按下好友邀請，這些選擇彼此一致：他很需要這段連結，也很怕自己的靠近變成逼迫。他的需要不是由概念標籤告訴我，而是藏在等電話、看手機、找妹妹和再次先開口的行動裡。

我也看得見他並非純粹受害者。他把「不要催」擴張成不確認，把不確定性自行填滿，因而參與了自己的漫長等待。文本沒有把全部責任丟給他，這點重要。不過到了重逢段，他為什麼願意再次承擔風險，目前主要靠「我還是決定去」表達；我能感到拉力，還不能完全說清他此刻想得到的是答案、關係，還是證明這一次會不同。

### 她

她作為一個受家庭、距離與年紀限制的人是可信的。「我們住得那麼遠」和需要交代行蹤，讓她的顧慮有現實基礎；她也有權不接受告白、選擇和別人交往。

但她在本章主要以沉默和結果存在。我看見她提出距離、要求等待、整個暑假失聯、和別人交往、後來接受好友並答應邀約，卻看不見這些選擇之間的連接。因此我能看見她做了什麼，還看不懂她站在哪裡。她是猶豫後逃避、早已選擇別人、受家庭或其他事情限制，還是根本沒有把「等我」看成承諾，我無法判斷。這種不知道與敘事者的經驗一致，但也讓兩人的立場並不對等：他的內在很完整，她較像留下空白的人。

兩人的選擇都有被呈現，卻不是同樣程度地被理解。他選擇等、掛電話、求證、重新聯絡和赴約；她選擇延後、失聯、與別人交往、重新接受聯絡。讀者可以評價行為，但目前很難理解她的動機。最值得保留的複雜性是：她不欠他一段戀愛，卻仍可能欠那個由她親口約定的回答。

## 情節、時間與 hook

- 情節因果大致清楚：告白後約定等待 → 她失聯 → 暑假結束主動求證 → 從妹妹處得知她與別人交往 → 多年後在 Facebook 重逢 → 約去淡水。
- 前半段時間非常清楚，尤其「隔天」「第二天」「那個暑假」「九月初」讓等待有刻度。
- 「後來即時通慢慢少了人，Facebook 開始出現我認識的名字」之後，時間變得模糊。科技更替能暗示多年，但無法讓我知道人物此時的年齡、相隔多久，也使七月三十一日缺少年份座標。
- 上一章留下的 hook「下一次電話響起來時，我不想再換成別的話」在本章開頭立即兌現，而且告白確實改變了兩人的關係，不是只有把台詞說掉。
- 本章結尾的 hook 有效。「我還是決定去」同時帶著期待與警訊，會讓我想讀下一章，看淡水之約如何面對那個沒有答案的暑假。

## 觀念是否自然

責任、界線、控制和需求都已經出現，但大多由事件帶出，整體不說教。

- **界線**：她要求時間，他決定不催，這是最自然的一組界線情境。文本也呈現一個重要但沒有硬講成道理的問題：尊重對方的空間，不必然等於放棄自己的確認與知情需要。
- **責任**：敘事者承認自己「把所有空白都自己補上了理由」，但又不把兩個月全算成自己的膽怯，這個責任分配有層次。相較之下，她對「等我」之後失聯的責任只被含蓄呈現；若只強調未知動機，可能讓讀者覺得傷害被過度中和。
- **控制**：他沒有控制她的選擇，卻用猜測控制自己對不確定的感受。「每一種猜測都讓等待看起來還有意義」很自然地呈現這個機制，沒有替人物貼標籤。
- **需求**：他的連結需求與想得到答案的需求都很清楚；她需要什麼則只看得到「時間」和現實距離，後來的需要仍不清楚。

較接近說教或過度解釋的地方，是「現在回頭看」後連續幾段的總結，以及「不是回答，但已經足以改變我對那個暑假的理解」。這些判斷本身並不武斷，問題只是前面的場景已經讓我產生相同理解，再被說一次時，故事感稍微退後。全章沒有把人簡化成「會等待的人比較成熟」或「消失的人就是壞人」，這點我願意保留。

## 讀完留下的感受

我留下的是一種比失戀更難收尾的感覺：他不是明確被拒絕，而是被留在一個有期限、最後卻沒有人回來履行的約定裡。前半段的細節讓這份等待很真，「你是誰」則把兩人原本最親密的媒介變成切斷關係的工具，是全章最難忘的反轉。

我也對重逢有戒心。結尾不是單純浪漫，而像他明知道過去的空白不會自己變成答案，仍選擇再次走近。這使我願意讀下一章；同時我希望後續不要只用兩人重新聊得來，沖掉當年沒有回答所留下的責任與不信任。

## 最想問作者的問題

你希望讀者在這一章只和敘事者一起承受「不知道她為什麼消失」，還是也應該看見她當年與重逢時的立場？目前我能接受答案未知，卻還分不清她是一個有自身矛盾、只是敘事者無法知道的人，還是一個主要用來留下空白、推動敘事者成長的人。
