# 《第四章｜每年的七月三十一日》編輯判讀

## 總體判斷

本章的核心任務已成立。它承接第三章落空的淡水之約，把一次缺席變成多年儀式，再以回電、社群動態、牽手與共同記得的日期恢復希望，最後用「交往三年的男友」改寫前面所有線索的意義。章末主角在已知關係現況後仍答應再見，也準確停在章卡要求的選擇上。

讀者並沒有否定這條事件線，反而被前半的浪漫版本帶著走，也和主角一起把「記得」補成「等待」。真正造成閱讀阻力的是收束過滿：畫面已經讓讀者看見主角如何誤讀，旁白又連續分類、解釋與判決，還在「當時的我還不會這樣分」前把成熟結論寫成當場想法。另一個有效警訊是她的主動選擇雖已出現，章末回看卻主要整理「我讀錯了什麼」，容易使她又退成一組供主角判讀的訊號。

本輪只有一份讀者回饋。以下的「共通障礙」不是多位讀者的票數，而是同一問題在逐段反應、人物判讀與整體感受中反覆出現，並可由正文、章卡或聲音規則獨立核對。只出現一次，且需要更多後文才能判斷的意見，列為個人偏好或暫時觀察。

## 讀者未提、編輯另見的問題

### 1. 「當年沒說出口的事」可能誤傷尚未回收的 hook

**判斷：建議處理**

第 137 行寫「我們開始拿當年沒說出口的事互相取笑」。前三章最重要的「沒說出口」正是失聯原因與「你是誰」，而這兩項並未在本章被回收。目前的概括容易讓讀者以為主要舊傷已在場外變成玩笑，也可能解釋讀者為何會在這裡再次追問「你是誰」。

潤飾時可將這個概括改成一項無關主要懸案、且當下可知的具體回憶，或只寫他們對過去的笨拙互動取笑。不要讓讀者以為「你是誰」已私下談過，也不在這裡新增答案。

### 2. 門的比喻與「走了三年的人」將兩位人物壓成主角的位置問題

**判斷：建議處理**

讀者已指出第 183 行的門會使女方像一個可供進入的空間，她的男友則像先佔位的人。編輯另需連同第 189 行「她已經有一個走了三年的人」一起看：兩個句子都從主角能否進入的位置理解另一段關係，後者還不夠自然、不如「交往三年的伴侶」準確。

這一處失落需要保留，但不必由第二個空間比喻承擔。前文已有淡水、電話空檔、手心和線索排列，再增門的意象也會增加轉譯負擔。潤飾時改用主角當下的身體反應、一個沒問出口的問題，或直接寫他知道的關係事實，都比再作物化比喻穩定。

### 3. 事實清單的取樣略過她最明確的主動行動

**判斷：建議處理**

第 171–177 行依序列出她回電、看動態、牽手與記得日期，卻沒有列出她在電話中主動提議見面，以及知道主角仍在意後又提議下次吃飯。這不是要用邀約證明她想復合，而是避免回看只挑出容易被解釋為無害的訊號，然後把模糊完全收成主角的投射。

若收束依「必須處理」項大幅縮短，不必另列更長清單，只要讓第 187 行的新邀約和最後的「好」直接對照即可。若仍保留清單，取樣必須能同時看見他的推論與她的行動。

### 4. 「我知道她牽我是因為怕跌倒」屬有邊界的推論，不構成視角越界

**判斷：不建議修改**

她先扶欄桿、問會不會摔死、要求主角不要放手，後來手心全是汗。主角從這些可見線索推論她怕跌倒，符合第一人稱可擁有的資訊，也為下一句「還是想把她牽回來」清楚分開事實與欲望。

第 167 行「她的語氣沒有閃躲，像在說一件原本以為我已經知道的事」也以「像」限定推論，沒有把她的心裡狀態寫成事實。潤飾時不可將它加寫成她真的以為主角早已知情，或用這一句替她免除交代時機的影響。

### 5. 章卡、前文與連續性核對結果

**判斷：除年數錨定與「沒說出口」的指涉外，事件與設定相容**

- 開頭完整承接第三章行事曆裡仍寫著淡水、但她明確說不會來的停點
- 主角每年獨自走老街、搭渡船去八里與到沙灘，符合 `_continuity.md` 的第四章記錄
- 大學畢業後透過妹妹取得電話、猶豫三天、首通十五分鐘及當晚由她回電，與章卡及連續性紀錄一致
- 重加 Facebook、Instagram 與 Line，她看過公開動態並主動提見面，後續河濱公園直排輪、誤入兒童課程及牽手，均與連續性紀錄相容
- 她在同次見面明確告知有交往三年的男友，之後又提議吃飯；主角在知情後答應，正好停在第五章「知道她有伴侶之後，還要怎麼參與」的前一步
- 第三章的踩水牽手是雙方確認交往前的靠近，本章的直排輪牽手則在她已有伴侶卻尚未說出的條件下發生；兩者的差異足以支撐對照
- 章卡要求第四章壓縮漫長等待，因此不應為回答所有年間細節擴寫多段日常；但壓縮不等於年數可以模糊到與畢業時點互相拉扯
- 第五章已安排主角在知道她有伴侶後仍參與、自己排在節日後面及試著抽離又退回。本章不需提前完成第五章的責任回看，但下一章必須兜現這個停點，不能只繼續曖昧場景

### 6. 同義反覆、過度解釋與技術規則核對

**判斷：收束必須處理；格式不建議修改**

- 明確的同義反覆集中在第 169–195 行：先重列前文線索，再說都不等於重新選擇，接著說她沒有表示會離開現任，最後再說主角沒問自己的位置。後三者都在翻譯「這些不是復合承諾」，只需一次
- 「這些年又像只是一段太長的通話空檔」屬主角當下的感覺，與後面男友的翻轉會互相改寫，不是作者對斷聯歲月的客觀結論，不建議刪除
- 「我不是每天都在等她」與第二章「我不是什麼都沒做」有句法呼應，但兩次分別呈現他如何為有期限與無期限的等待辯護。後一段還新增每年把其他事移開的動作，屬人物模式推進，不是應直接刪掉的字面重複
- 全章未使用破折號
- 正式敘述段落的句尾未留逗號、句號、問號、驚嘆號或分號；引語內的疑問與句點使用符合實際話語規則
- 除第 169–181 行的回看邊界混亂外，未發現將她的內心直接寫成事實。修訂時不可為解決她的動機不明，改用全知視角補答案

## 必須保留的有效段落與句子

- 「那年七月三十一日，我還是去了淡水」與行事曆上的「淡水」：直接兜現上一章的缺席，不需再摘要分手
- 「我不是來散步的／我是來找一個已經說不會來的人」：以動作拆掉主角的自我解釋，是開場最準的翻面
- 老街回頭、渡船靠岸時站慢、先看長髮女生的臉，以及沙灘上反覆抬頭：執著先於解釋，不可改成一段「我放不下」
- 「今年可能只是剛好錯過了」與「只要我還出現，那個原本約好的下一次，就不算完全取消」：不把等待美化成必然有回報，也不急著把它診斷成病態
- 妹妹的「你又要找她幹嘛」，以及主角刪掉兩種作為理由的訊息：同時顯示外部眼光、欲望與他對壓力的自覺。只需釐清號碼取得的知情程度
- 「我對著那串數字看了三天」到「我知道是你」：三種害怕有時間推進，回答也與前文「你是誰」形成有力對照
- 十五分鐘短聊、她當晚真的回電，以及「這些年又像只是一段太長的通話空檔」：重逢的感覺由事件長出，後面的翻轉才有代價
- Facebook 玩笑裡的「你還是一樣／一樣臉皮很厚」：用對話承擔熟悉感，不用旁白宣布默契回來了
- 「我很快地說好，快到沒有問她現在有沒有和誰在一起」：在翻轉前放入可回看的選擇，不把主角寫成純粹被隱瞞
- 直排輪誤入兒童課程、教練吹哨與兩人邊道歉邊笑：這是全章最有生活感的共同場景，也讓後面的曖昧不只靠論述成立
- 「我知道她牽我是因為怕跌倒／可我的手空下來時，還是想把她牽回來」：事實與欲望已經分開，不必在當下加道德評語
- 「我也會去」、擦身而過的想像與「如果她也在等呢」：讓讀者親自經歷從共同記得跳到共同等待的誘惑，是本章核心機制
- 「有時候是跟我男朋友一起去」與「我們在一起三年了」：一句就同時切斷希望、改變日期的意義，也建立下一章的倒數位置
- 她低頭看磨紅的腳踝後說「下次不要溜這個了，去吃飯就好」：不用旁白解釋，她在得知主角每年赴約後仍發起下次靠近的選擇已經可見
- 結尾獨立的「好」：完成的不是成熟頓悟，而是主角為了保留下一次，暫時不處理自己位置的選擇。精簡章末時必須保留

## 修訂清單

以下依影響範圍、問題嚴重度與修改成本排序，供潤飾時直接執行。

1. **重整第 169–197 行的翻轉與收束｜高影響、中低成本**
   先分開當時反應與現在回看，解決「我當場重想一次」卻「當時還不會這樣分」的矛盾。事實清單、「沒有一件事等於」、「從頭到尾沒說要離開他」和「沒問自己還要站在哪裡」只留一個主要理解。保留她的新邀約與最後的「好」，讓動作收尾。

2. **釐清分手後到畢業重聯的年數｜高影響、低成本**
   以第三章已定的就學身分回算，決定主角究竟獨自去了幾個七月三十一日。修正第 27–37 行「下一年／之後幾年／大學畢業後」的關係，不增加無關的年表，也不改掉多年儀式的感覺。

3. **讓女方的參與留在可觀察層次｜高影響、低成本**
   若保留事實清單，檢查它是否只挑了回電、看動態和怕跌倒牽手；改由已有的主動邀約與章末吃飯提議一起承擔雙方共同維持模糊的事實。不新增她的內心、不代她說想復合，也不用一句道德判決代替後續後果。

4. **確定妹妹交出號碼的知情程度｜中高影響、低成本**
   先將作品事實定為「先問過她」或「妹妹直接給」。若前者，只加一個能讓同意鏈成立的動作；若後者，則保留主角以為自己已經尊重拒絕、實際卻仍繞過本人的差距，並在後續讓影響成立。
