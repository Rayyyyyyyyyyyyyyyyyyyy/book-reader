# Chapter 1｜從自由市場的角落開始

故事總是從一個不起眼的角落開始。
因為楓之谷從沒真正退燒過。

那時候公會很熱鬧，頻道裡整天都有人在說話，任務、刷怪、八卦、交換裝備，什麼都聊。
我也在裡面，掛著角色、滑著頻道，順便跟人玩所謂的「網公網婆」——就是在遊戲裡假裝配對，沒什麼意義，但那時覺得很好玩。

她總是坐在自由市場的一個小角落。
不是最活躍的那種，卻偶爾冒出來說兩句，然後又安靜下去。

我已經忘記最初是怎麼注意到她的了。
也許是她那天剛好說了什麼有趣的話，也許是頻道太吵、她反而顯眼，也許只是那天我閒著，剛好滑到她的名字。
總之她就這樣闖進了我的視野——還很巧，她剛好是我「網婆」的學姊。

那時的我，說真的，根本不會跟女生聊天。
遊戲裡叫人一聲「婆」還好，真要開口說話，心裡就開始打鼓，不知道說什麼，不知道說錯了怎麼辦。
所以我私訊了她，用一種有點厚臉皮的方式開口：「學姊，妳可以教我怎麼跟女生相處嗎？」

大概是這個問題太奇怪了，她居然沒有已讀不回，反而回了。

就這樣聊起來了。
一則一則，話題不知道怎麼就一直接著走，根本停不下來。
頻率出奇地合，聊起來比我跟任何「網婆」都自在。

但她每天上線的時間很短，最多一、兩個小時，然後就不見了。
我開始習慣盯著那個密語視窗，等她的 ID 亮起來。
等到她上線，才覺得今天好像完整了一點。

我不確定那算什麼感覺。
只知道，每次她下線之後，那個視窗空掉的樣子，讓我很不習慣。
