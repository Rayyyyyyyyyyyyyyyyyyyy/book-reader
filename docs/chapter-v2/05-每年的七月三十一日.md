# 第二部｜等待曾經有過結果

## 第五章｜每年的七月三十一日

**核心困境**：他始終沒有真正接受那段關係已經結束。多年後，她再次回應他，兩人仍能親近相處，使他以為當年的阻礙終於可以跨過、關係可以重新開始；她已有男友的消息打斷這份希望，她願意當朋友的態度又使他捨不得離開。

**當年分開與希望的來源**：當年的兩人仍有感情，課業、工作、距離與相處壓力卻使關係無法繼續。承接第四章的具體處境與「等妳考完」，讓男主角一直抓著「條件改變後也許就能繼續」的可能。她當年已明確提出分手並取消淡水之約，沒有答應考完會回來；他的盼望不能改寫成兩人的共同約定。重逢後，他想像自己已比當年懂得等待，她也仍願意靠近，於是覺得這一次可能不同。「我剛好成熟，而妳剛好溫柔」是他對重新開始的盼望，不是旁白替兩人認證的成熟或復合意願。

**處境與入口**：分手電話後，他照常上課、上班，仍保留行事曆上的淡水。這幾年要讓讀者感到他一直沒能離開她：生活有往前走，他卻仍為她保留時間、改變安排，也仍帶著找她、等她出現的期待回淡水。不能寫成已接受結束後每年回去紀念。

**執著怎麼落地**：保留少數有重量的情境，把他如何留下可能、如何因此錯過眼前生活寫完整。分手後仍把她的考試結束當成可能的轉機；第一年回到原路線，會為了還可能遇見她而延後離開；第二年從中壢出發，拒絕同學聚餐仍回淡水，提早離開也不等於已經不期待。第三次回訪可由後段簡短交代，毋須重演完整尋人。筆記本維持作者裁定的動作順序：翻開寫新日期，闔上前看見「記得吃飯」，看了看才收起來。不把每句思念翻譯成眼神或手部動作，也不以連續旁白替讀者解說放不下；必要的當下念頭可以出現，須牽動下一個選擇。

**素材起點（可改編）**：分開後每年七月三十一日去淡水，希望碰見她；畢業後透過妹妹拿到電話，猶豫三天才打；更新近況、恢復社群聯繫，她說看過自己的 Facebook；溜直排輪牽手，她說也會回淡水，之後得知她已有交往多年的伴侶（原素材為四年；本作依時間線改為兩年多）。

**場次**：分手後的日常與未取消的淡水之約，先留下他還在等待條件改變的動作與念頭 → 第一個七月三十一日完整走老街、搭船與八里，明知她說不來仍在人群與渡船上找她，讓離開變成困難的決定 → 開學後完成報告、一起吃飯，回家記新日期時看見她寫的「記得吃飯」 → 第二年搬到中壢後婉拒同學聚餐，仍回老街，三年回訪有持續時間與生活取捨 → 畢業合照使他想到她當年關心過的生活；如今不用再遷就上課與考試的時段，他想讓兩人重新有機會說話，透過妹妹徵得她同意，猶豫三天才撥出 → 她認出他、回電、交換近況、重新加回社群並主動邀見面；熟悉的玩笑與他嘗試不再催促的反應，使他覺得這一次或許做得到 → 直排輪牽手、仍收著圍巾與「其實我也有去」把重新開始的希望推高 → 她接著說有時和男友同行、已交往兩年多，打斷他的盼望 → 她仍自然提起下次吃飯，留下朋友往來的空間；他無法立即答應，分開後獨自承受，又捨不得關掉剛找回的聯繫。

**時間與資訊邊界**：她在高三下學期與主角分手，到主角大學畢業後重聯約三年；現任交往兩年多不與當年兩人的交往重疊。她在本次見面才知道他連續三年獨自回淡水。重聯前，他只能回看自己留著的舊訊息，不描寫持續查看她的近況；透過妹妹取得電話、通話後重新加回社群，才恢復觀看她頁面的情境。他可以由回電、公開動態、牽手與共同日期生出希望，讀者也要經過希望抬頭的過程，但不能因此替她確定想復合。她說自己也有去，沒有說曾在等他。

**得知她有男友之後**：要讓讀者承受「重新開始似乎可行，卻已經有另一個人在她身邊」的落差。他可以受傷、嫉妒、難堪，想問既然有男友為何還找他見面；仍記得她牽過的手，也仍希望當年的感情有機會接回來。不要讓他當場把事實與想像整理乾淨、替她免責，或突然接受朋友身分。保留他的怨與捨不得，不把她已有男友寫成背叛他，也不推定她刻意吊住他。

**女主角的朋友入口**：說出男友後，她仍願意聊天、見面，自然把下一次相處延續下去。可由下次吃飯的邀請、具體的日常話題或熟悉的玩笑，讓讀者感到她覺得兩人可以當朋友；不用讓她說教、許諾復合，或解釋完整動機。男主角只說「我再看時間」，她仍為之後聯絡留著空間。女主角沒有關上往來，男主角的感情卻尚未退回朋友的位置。

**可展開的承受場景**：他一個人搭車回中壢，仍記得直排輪場她握住他的手，腦中反覆回到「兩年多」。這幾年等待的日期、如今能見面的條件與剛才的親密撞在一起，讓他既想追問又怕失去聯絡。回家打開對話，輸入質問又刪掉；把她願意下次吃飯的話留在章末，讓讀者看見兩人仍能往來，但他還無法坦然以朋友的心情回應。當晚不約定下一次，隔週重新開口留給第六章。

**本章要成立的閱讀感受**：他沒有接受分手，三年來仍執著於她；重逢讓他以為當年的現實阻礙可以跨過，兩人也許能重新開始，卻被她已有男友的消息打斷。希望與失落都要有份量，章末仍保留他想靠近、她願意當朋友的不同位置。不要求本章得出等待的教訓。

**停點與交接**：他沒有當場爽快答應下一次，也尚未接受朋友身分；她仍自然留下聯絡與見面的空間。第六章從一週遲疑後他再次開口承接：她打開朋友往來的空間，他帶著未退去的感情走進去，之後才逐步形成更深的依賴、親密與界線問題。
