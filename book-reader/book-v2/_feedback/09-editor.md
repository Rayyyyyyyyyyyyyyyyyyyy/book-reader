## 如何看待這份讀者回饋

目前只有一份讀者回饋，不能用票數把每個停頓都稱為共通問題。以下把能由正文、章卡、場景表、連續性與聲音規則共同驗證的問題，視為**共通閱讀障礙**；讀者希望多看某段過程、但章卡並未要求把它升為主場的意見，視為**個人偏好中帶有結構訊號**；作品刻意保留的資訊缺口則不因讀者好奇就補答案。

讀者接收到的核心與章卡一致：這張桌子的成功，不在誰讓步，而在她的負擔能力、使用判斷與他的需求第一次同時進入決定；成功也只限於這一項安排，不能倒推整段關係已經修好。修訂時不能因讀者對主角不耐，就把他想要耐用家具、擔心工作與願意多負擔寫成假的；也不能因協商終於成功，就讓他在第九章提前看穿第十章才要撞上的盲點。

## 兩種相反的修訂工作

### 一、該刪的是同義反覆、過度解釋與提前完成的理解

1. **第 317–325、343–350 行：把完整機制退回當時有限理解**

   這是最高優先。保留他知道自己曾拿過往付出要求她取消聚餐、這次不能再以平均分攤逼她接受，也保留「我沒有想要再拿別的事壓妳」不足以修復的事實。刪除或改寫「要求她為看不見的未來付錢」「計畫是我自己排的／她沒有被問過」這組已完成的洞察。當時的他可以感到話說不下去、知道自己不能把買房當理由講出來，卻不應已經精準看見長期模式。預計減少 **120–180 字**。

2. **第 153–159 行：縮短帳戶用途的自我解說**

   保留公司消息、他想拿出手機、帳戶確實能形成緩衝，以及最後沒有說。把「驚喜／買房開始／失去收入後緩衝」的完整三分法壓成一個尚未決定的念頭，讓風扇、手機與洗盤子的動作承擔不安。預計減少 **40–70 字**。

3. **第 453–471 行：濃縮下單後的重複驗收**

   必須保留她以自己的手機下單並先付款、他當場轉三千八、備忘錄記錄分攤與收貨檢查；可以合併「已經記了／轉畫面／桌腳也要看／知道」這組流程對答。後面的實際收貨會把檢查演出來，不需要在下單時先驗收一次。預計減少 **70–110 字**。

4. **第 475–481 行：場景後的章旨收束只留一層**

   「沒有買其他家具」、床墊、吊衣架與四個紙箱讓空屋狀態成立；「沒有哪一樣因為談完就自動變成家」與「終於不是由一個人先做完」連續替事件下結論。建議保留較貼近人物此刻的一層，另一層交給讀者或章末回看。預計減少 **25–45 字**。

5. **第 547–551 行：刪掉定義式翻譯**

   保留他差點說「不用分這麼清楚」、想起前章那句話，最後只答「好」。刪「同一句話放在不同時候……」的完整定義。讀者已看過前後兩次語境，能自行辨認靠近與施壓的差別。預計減少 **30–45 字**。

6. **第 623 行與第 647–651 行：拿掉作者踩煞車與蒙太奇後的結論重播**

   刪「只到這裡就夠了」後，直接讓兩人談工作與吃紅蘿蔔；後段保留三次晚餐的具體差異，視需要最多留一項晚餐外的持續合作，不再依次說「不是演給誰看」「這些事情確實更好」。第 653 行必須保留，因為它把成功安排推向主角的錯誤信心。預計減少 **85–120 字**。

### 二、該補的是場景質地與摘要帶過的轉折

1. **把第 41–69 行的選屋結果加深成短場景**

   不必回頭補看過幾間房的完整蒙太奇，也不必另造一場大爭吵。現有看屋離場與回程捷運已提供時間、地點和進出點，可在這裡讓兩人實際核對：多出的兩千對應哪一項需求、她少一次轉車值不值得、家具為何不能一次買完，以及最後怎麼把餐桌寫進共同月曆。至少讓一個條件因對方提出而被接受或修改，才能讓「共同決定新住處」不只是一句「談成了」。建議增加 **180–260 字**。

2. **展開第 355–363 行由對峙轉為攤開支出的半拍**

   這不是補一套更完美的溝通話術，而是讓信任的成本可見。可以使用已在場的闔上筆電、她站在折疊桌旁、手機、收納箱與共同備忘錄，讓兩人先停住；她是否坐下、先打開哪一份資料、螢幕何時轉向他，都可以成為選擇。主角只能看見她的動作與聽見她說出的條件，不能寫「她終於相信我」或「她決定再給一次機會」。建議增加 **90–140 字**。

3. **修正第 643–655 行蒙太奇後的時間落點**

   三次晚餐是摘要，接著「週五晚餐結束後」卻沒有指出是哪一次，讀者會不確定鏡頭回到第一頓、停在列舉中的某次，或又往後一晚。可把擦桌與摸圓角放回第一頓、再進蒙太奇；或補一個「幾週後的一個週五」之類的具體錨點。這是 **10–20 字**即可解決的時間問題，不需要另展一場。

4. **不需要展開的摘要**

   從看屋到搬入的幾個星期、三次中斷的週五晚餐，以及餐桌後來承接的數次晚餐，本來就需要時間壓縮，而且每次摘要後都能落回具體物件。不要逐週補搬箱、逐餐補菜色，也不要把公司每次開會寫成場景；那只會重演同一狀態，並擠掉真正需要展開的共同決定與信任轉折。

- 本稿**未見直接寫出女方未說出口內心的明確越界**。她的退讓、警戒與重新參與，大多由對話、沒有立刻笑、再次確認、主動提週五晚餐等可見行為呈現。
