# 第三部｜我們怎麼一起生活

這一部展開共同生活的日常：第八章的支持確實有效，使主角更相信自己多做有用；第九章自行放棄演唱會後，長期多承擔與接手的委屈進入爭執，他把她的退讓當成和好；第十章才聽見退讓留下的傷害，兩人重新協商並做成餐桌安排。人物在此確實改善一件事，尚未看清整段關係。

本部同時走兩條進程：兩人處理共同生活的能力如何變化，以及兩人是否仍想靠近、分享、回應彼此的靠近。第二條採用「週五晚餐」貫穿：第八章協商出來、確實讓兩人靠近；第九章仍照常，她卻不再提自己想要的；第十章開頭交代搬家忙亂與加班讓它停了幾週，沒有人提起，章末在新餐桌上重新開始。讀者到第十一章能理解她的變化，但不從每個動作找分手證據。

收入差距、花費偏好與未說出的期待分開呈現。收入差距是能負擔多少：薪資、存款、預算的具體數字，主要在第八、十章。第九章他為自己的存款目標取消演唱會，她原本保留用私人餘額支付的朋友聚餐，後來在爭執中取消；這呈現未協商的目標如何進入要求，不能證明她不願為未來存錢。第十章讓兩人對餐桌價格、尺寸與使用方式的偏好進入實際決定。不從她降低支出推到她不想共同承擔，也不把他想存錢讀成比較成熟；兩人都想過買房與結婚，但沒有共同談過計畫。

## 第八章｜想像之外

**核心困境**：一方暫時沒有收入時，支持怎麼真正變成她能使用的時間；工時錯位之後，兩人要怎麼保住相處。

**處境與入口**：第一晚行李還攤在地上，兩人已開始安排共同生活。她為同居離開原有工作與熟悉的生活搬到台北，想完成自己選的學習並保留轉職空間；同居起房租與生活費全由他負擔，她以待業存款支付課程材料、交通與自己的選擇。她搬來的代價要在本章可見，後來他的帳本可以漏算，敘事不跟著漏算，也不把她的搬遷換成永遠不必重談分工的理由。

**素材起點（可改編）**：同居後有生活習慣與價值觀的磨合，爭吵、流淚，也曾撐過來，生活變得有默契；支出長期由自己負擔較多；2022 年 黑糖加入。

**時間錨點（2026-09-22）**：三月同居、六月底成果展，夏季行政到職與主角轉遠端，週五晚餐持續數月，十二月二十四日撿到黑糖。撿貓日期為作者確認，其餘月份為本輪後設安排；不再綁定寒流或星期五。

**採用設定**：她轉職學習期間沒有兼職；同居起由主角負擔房租與生活費，沒有金額上限，也沒有談定期限，實際到她找到正職並領到第一份薪水為止（這是後來發生的結束點，不是事前條款）。領薪後她每月固定轉一萬元進共同生活費，房租仍由主角負擔。學習的產業機會少，她後來回到行政職，責任制常加班。他跳槽到遠端工作，工時彈性、收入較好。雙方收入與工時差異擴大。買房與結婚是兩人都曾想過、卻沒有人說出口的事；他從這時開始默默存錢準備，打算等存夠頭期款再給她驚喜，沒有告訴她。她也曾想過的部分由第十一章她的話帶出，不提前寫成主角當時已知的事。

**場次**：她主動提出維持低固定支出的套房與工時容許的家務；衣櫃不夠放，她提出收納需求，兩人重新分配。主角明說房租與生活費由自己負擔，她把房租寫進共同備忘錄；他刪掉並說這本只記共同的，她再寫一次。她另以待業存款負擔材料與交通 → 她一邊上課一邊投履歷、跑面試，待業存款持續下降；她在花材清單刪項目、把貴的換成便宜的，他看見卻沒有問。求職使一份配置圖與成果展準備一再延誤 → 他看見的多半是行政職的面試通知，先以為她不想做這一行；談開後由她說出存款一直在少、又不知道這樣的支持會到什麼時候 → 他沒有再增加一筆錢，而是承受她暫時沒有收入的未知，請她先把課上完、工作等成果展之後再找；她自己決定暫停求職，條件是材料與交通仍由自己付，雙方實際負擔都記在備忘錄上。兩人不訂金額、上限或結束日期 → 她重排作業與展覽準備，補完延誤，完成課程與成果展，現場能說明作品、自己判斷取捨 → 成果展後她自己恢復找正職，最後進入行政職；領到第一份薪水時，主角全額負擔的狀態結束，她每月固定轉一萬元進共同生活費，房租仍由他付 → 主角轉為遠端，她的行政職常加班；他等到十點，她只想洗澡睡覺。疲憊此時就是疲憊，不等於不愛 → 兩人協商出週五晚餐，確實持續並恢復親密 → 黑糖加入，兩人談妥最初的照顧與費用安排。

**本章要成立的理解**：支持確實有用，這是後面判斷的對照；不在本章預告它會變成代辦。

**停點與交接**：她領到第一份薪水後，全額負擔結束，兩人進入新的共同費用安排；週五晚餐與黑糖讓生活看起來能協商、能運作。那段沒有金額、沒有期限的負擔從未被算過，也沒有人替它命名。她答應的是共同生活；買房與結婚兩人都想過、都沒說，他默默存錢，仍以為等生活穩定就會自然走到同一個未來。
