# Chapter 3｜十一點的默契

她是夜校生。
每次下課回到家，差不多都要十點多，還得盥洗、吃點東西、整理一下房間。

我不知道是什麼時候開始的。
反正某一天，我的手機在晚上十一點準時響起。

沒有約好，沒有規定，也沒有誰先說「以後都這個時間」。
但她的來電就這樣一天一天出現，十一點慢慢變成我們的默契。

電話裡其實也沒有什麼驚天動地的內容。
更多時候，是她講今天夜校發生了什麼事，哪個同學又做了什麼很荒謬的事，老師上課講話有多好笑，早餐店今天多忙，妹妹又在上鋪偷聽還突然插嘴。
那些都是很小很小的日常。
小到如果寫成摘要，大概只剩下一句「今天也差不多」。

但我很愛聽。

我那時候還不懂，原來喜歡一個人，不一定是因為她說了多了不起的話。
有時候只是她的聲音一出現，你就覺得今天終於有了收尾。
她講學校裡的瑣事，我就嗯嗯啊啊地聽著；她抱怨，我就陪她罵兩句；她笑，我也跟著笑。
我不需要給什麼厲害的建議，也不需要把每件事都解決。
我只要在電話這頭，讓她知道我有聽見。

每天，每天，我們都會講到凌晨兩點、三點。
偶爾也會沉默。
但那種沉默不尷尬，反而像兩個人各自躺在自己的房間裡，卻共享同一片夜晚。

我明明五點半就要起床搭校車去學校，她也要早起到家裡的早餐店幫忙。
我們都在耗損睡眠與日常，去維繫一種沒有人定義的關係。
不是情侶，不是親人，卻比誰都更重要。

那樣的電話時期，大概持續了六到八個月。

那時候真的好年輕啊。

某天我看到電話帳單差點眼睛掉出來——六千塊，整整六千。

2008 年的六千，在一個便當六十塊的世界裡，是一百個便當。
是一個高中生一整個月的生活費。

但我沒有後悔。
那是我用來確認「她真的存在」的六千塊。
是用聲音灌溉出來的關係，是青春裡一場毫無理智、但毫不浪費的花費。
