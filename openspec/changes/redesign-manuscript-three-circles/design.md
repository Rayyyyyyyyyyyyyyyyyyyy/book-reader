## Context

第一批人工閱讀反饋要求增加三圈示意圖、精簡第一章及移除章節預告。現有工作樹已完成該輪修訂，但圖示改為交疊後暴露分類矛盾：能直接決定、能影響但不能決定、幾乎無法影響，不能以交集命名。使用者接受三層套圈方向，並明確要求本文一併修改。

內容來源是 `book-reader/book/`，寫作依據是 `docs/chapter.md`。目前三圈引用涉及第 01、02、03、04、08、10、11、12 章及 P1–P4，結語保留三圈泛稱。`site/scripts/manuscript-reader.mjs` 產出閱讀器，段落依原稿區塊順序配對註解行號；SVG 已包在單一 `<p>` 區塊內，須保留此相容性。

## Goals / Non-Goals

**Goals:**
- 圖、定義、案例及練習採同一套包含關係。
- 讀者能把一件掛心的事拆成可選行動、可影響結果、目前無法影響的部分。
- 延續精簡後的正式寫作聲音，不用多輪同義解釋補救模型。

**Non-Goals:**
- 不改成「想要／能做／該負責」的動機或義務模型。
- 不引入四圈、生涯意義模型或為交集虛構新概念。
- 不重寫無關章節，不新增作者經歷，不修改既有人工註解紀錄。
- 不部署網站，不改寫歷史 review、既有 change 或日期修訂紀錄以掩蓋舊版本。

## Decisions

### 1. 三個完整範圍，三個操作區域

圖為同心套圈。先限定這張圖處理「這次掛心的事情」，不宣稱所有可行動之事都一定令人感興趣；必要責任也須納入盤點，不能以不喜歡或不想理會排除。

| 圖形 | 完整範圍 | 寫作與練習中的操作區域 |
| --- | --- | --- |
| 最外圈 | 我在意的事情，包含內部兩圈 | 最外圈：仍在意，但目前幾乎無法影響的部分 |
| 中圈 | 我能影響的範圍，包含內圈 | 中間環：能影響、不能獨自決定的結果 |
| 內圈 | 我能直接決定的行動 | 內圈：自己有權決定，也能執行的具體動作 |

正文以「我在意的，比我能影響的多；我能影響的，又比我能決定的多」引出圖形。這是幫助盤點的示意，不代表面積、能力比例或每件事必須填滿三區。三區用語統一為內圈／中間環／最外圈，避免編號掩蓋整圈與環帶的差異。

替代方案：分離三圈可表達分類，但沒有呈現注意力與能力的落差；交疊圖暗示互斥定義存在交集；另換三個主題則偏離本章內耗問題，因此採套圈。

### 2. 用同一件事的不同部分示範

第一章沿用已有談話場景：寫下問題或決定怎麼開口在內圈；能否增進理解在中間環；已經發生的那次爭執在最外圈。過去事件不能撤回，但後續理解仍可能改變，不把整件事或整個人固定放進某區。

在意是一張圖的入口，不是必須採取行動的命令。感受本身不歸為可以直接控制的動作。制度、資源、權責及當下能力限制內圈；不能決定不等於不能影響，尚有方法不等於必須耗盡方法。

### 3. 主章教一次，後文用案例承接

第一章按「掛心的事 → 圖的包含關係 → 同一場景拆解 → 行動與停止判準 → 凌晨三點收尾」推進。保留目前已精簡的段落功能，避免新增一整輪分類教學。

後續章節與練習依上下文改寫，不機械替換詞語。第四部引言及練習須移除「第三圈等於無法影響」的舊總定義；第十一章標題須改成自然語句。`docs/chapter.md` 的復用工具、第四部說明同步更新。歷史文件保留原貌，新修訂證據記在本 change。

### 4. 圖與閱讀器相容

使用內嵌 SVG 繪製三個同心圓，保留可縮放 viewBox、文字、title/desc 及 currentColor。完整圈標籤與環帶說明須可辨別；避免把「我在意的事情」只標為無法影響區的同義詞。採清楚的引線或分層標籤，實際檢查 390px 手機寬度與桌面閱讀寬度。

SVG 保持單一 `<p>` 原稿區塊，不為此改動閱讀器的定位演算法。驗證圖後第一段及章尾段落的 `data-source-line-start/end` 對應實際原稿。舊 note 的原始行號、quote 與 ID 不重寫；這次驗證的是新版新增註解的位置。

## Risks / Trade-offs

- 把外圈誤認成只能接納的事 → 明示外圈包含其他兩圈，只有最外圈對應當下影響有限。
- 把控制自己的動作誤讀成控制情緒或共同資源 → 保留能執行、有權決定及必要責任限定。
- 用「沒有影響力」合理化放棄照顧，或用「仍能影響」強迫無限投入 → 保留責任、風險、能力、承接與額外投入的區分。
- 跨章機械更名導致長句與重教 → 逐段核讀，使用 Rui-Xuan V2 及 humanizer 潤飾，驗收時閱讀相鄰段落。
- 套圈字多導致手機難讀或定位偏移 → 桌面與手機截圖、SVG 文字檢查及段落定位核對。

## Migration Plan

先盤點當前引用並記錄本次基線，再改寫寫作依據與第一章，接著同步其他章節。完成閱讀與圖示檢查後建置閱讀器及網站；驗證記在本 change。回退只還原本次模型修改，不覆蓋工作樹中已存在的第一批潤稿。生成檔不納入提交。
