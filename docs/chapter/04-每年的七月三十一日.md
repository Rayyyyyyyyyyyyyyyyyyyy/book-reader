# 第二部｜等待曾經有過結果

## 第四章｜每年的七月三十一日

**核心困境**：重逢的親密訊號都是真的，他卻把它們當成她打算重新選擇自己的證據。

**處境與入口**：交往結束，主角仍會在紀念日回淡水，表面隨意，實際在找一個人。

**素材起點（可改編）**：分開後每年七月三十一日去淡水，希望碰見她；畢業後透過妹妹拿到電話，猶豫三天才打；更新近況、恢復社群聯繫，她說看過自己的 Facebook；溜直排輪牽手，她說也會回淡水，之後得知她已有交往多年的伴侶（原素材為四年；本作依時間線改為兩年多，見場次）。

**場次**：選一次回訪承載多年的等待 → 畢業後取得電話，猶豫三天才聯絡 → 熟悉的談話、溜直排輪時牽手，以及她也記得那個日期，讓他再次抱有希望 → 得知她已有交往兩年多的伴侶。這項資訊在本章說出。交往時間依時間線決定：她在高三下學期與主角分手，到主角大學畢業後重聯約兩年多，不能長到與第三章的交往重疊。

**回看（可選）**：牽手、記得日期、願意赴約都是真的，有希望也不全然荒謬；問題在於這些能不能證明她要結束現有關係、重新選擇他。

**停點與交接**：知道現況之後，他仍答應下一次見面，下一章承接這個選擇。
