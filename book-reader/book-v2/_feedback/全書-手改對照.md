## 這份檔案怎麼讀

`docs/book-v2-workflow.md` 的偏好條目負責提醒「要檢查什麼」；本檔負責回答「作者實際怎麼改」與「作者自己怎麼寫」。兩者衝突時，先回到同章、同情境的原句，再看整段閱讀體驗，不拿摘要條文否決原句

要改某一章正文前，先到「按章索引」找到該章，再核對章卡、該章 audit 的舊版作者手改保護、直接管到的偏好條目與人物弧線分層。`NN-author-lines.md` 若存在，只是 Git 抽取的來源候選，不再是逐字保護名單。各章後續校閱依該章本輪紀錄核實親筆修改與模型提議的歸屬

本檔有三種材料，不能混用：

1. **手改對照：** 看 before 的問題與 after 的修改方向，可以歸納判準
2. **作者親筆句樣本：** 只讀作者加號側的完整句子，不配對、不歸納成規則
3. **來源不確定：** 分不清作者手改或流水線產出的內容，只留案，不拿來立規則

表中的 `∅` 表示作者整句或整段刪除。所有引文均逐字抄自 git diff 或 `_feedback/` 的既有紀錄，未改寫、補字或美化

## 證據等級與收錄界線

| 等級 | 可做什麼 | 例子 |
|---|---|---|
| A｜回饋明確認證 | 可進對照、索引；若能在加號側找到完整句，可進親筆句樣本 | `04-audit.md` 明列「日子來到那天」「感情狀態」「其實我也有去」；`13-scenes.md` 明列作者最後改句 |
| B｜純手改 commit | 清楚替換可進對照；完整加號句可進親筆句樣本 | `65c8ed2`、`a30595b`、`1de6a4b` |
| C｜混合 commit | 只有被 A 級來源點名的句子可解鎖；其餘列來源不確定 | `8d650f0` 第十三章、`acbb1d9` 第十二章 |
| D｜只有核准、沒有逐句歸屬 | 可證明版本被作者看過，不能反推每一行都是作者親筆 | 首次入版控、整章重寫、只刪「等待人工校閱」 |

「Claude 人工核對補修」可證明句子經查核或補修，卻不自動等於作者親筆；除非同一處另有作者手改標記，否則不進「作者親筆句樣本」

## Claude 反覆犯的錯：動筆前自查

1. **對白後自動補身體小動作。** 搜尋伸手、換手、靠、擋、推、碰、移開、低頭、肩膀、膝蓋；只是替一句話配動作就刪
2. **把「不放事後評價」誤讀成「不准寫神情與感覺」。** 一臉得意、遲疑、舒服、感動與天南地北可以寫；不能寫的是事後旁白替場景判決
3. **把「不說白潛台詞」誤讀成「不必回應人」。** 謝謝、道歉、回答邀請、接住關心不是解釋潛台詞
4. **先用否定句或反問句保護角色。** 「不是我」「妳不是」「我沒有」會讓回合像辯論；先試寫角色要做、承認、看見什麼
5. **用外在動作取代所有內在質地。** 人物若只剩手、肩膀、視線與位置，檢查是否清掉神情、感覺、語氣和主觀副詞
6. **同一場多補一拍。** 物件已有作用時，再補搶、擋、靠、藏，通常只是重複證明親密
7. **替角色分析自己的行為。** 出現「這代表」「我是在」「有限的下一步」時，先改回當下會說的具體事
8. **在畫面後補翻譯。** 特別檢查每場、每段、每個回扣的最後一句；只是在說剛才那幕的意思就刪
9. **把精確當成具體。** 器物規格、錯誤介面、無根數字與多餘位置描述都要核實
10. **把規則做成配額。** 不要求每場有身體細節、每句對白有下一拍、每個人物面向平均出現
11. **把句子修得太乾淨。** 不要順手刪掉「可是」「其實」「耶」「一下」「...」等真正承擔語氣的字
12. **偷換主詞。** 「我決定不再這樣見面」不能寫成「我們不要再見面」
13. **只讀減號，不讀加號。** 看完問題句後，至少讀同章三個「作者親筆句樣本」，讓判斷不只剩禁令
14. **把核准版本當成逐句作者親筆。** 整章經校閱，不等於每個加號都是作者寫的；親筆樣本仍須 hand-edit commit 或回饋認證

## 對四十條仍應補上的三個偏好

### A. 優先寫肯定內容，不用否定句繞進去

「是風，不是我」改成「好，我騎慢一點」、「空間大不是比較好嗎」改成「真的大了很多」、「我沒有要趕妳」改成「妳不用為了這件事改時間」。數量不是禁令，但高密度處要逐句檢查是否在辯解

### B. 語氣詞與不整齊停頓是人物聲音

「我不想少講」改成「可是我不想少講...」不是只多四個符號；它讓回答從標語變成一個人臨場承認需求。不要把最短句誤認成最自然的句子

### C. 神情與感覺不是事後評價

「一臉得意」「天南地北」「遲疑地」「嘴角還有著餘波盪漾」都直接進入作者版本。偏好第 31 條只刪旁白判決與主題句，不刪人物當下的感受、神情或對氣氛的準確命名

## 後續更新方式

1. 每次作者校閱完成後，先讀該章 audit、editor、scenes 與 hand-edit commit
2. before／after 能逐字確認才進十個分類；整句刪除用 `∅`
3. 親筆句樣本只抄加號側完整句，標章號與 commit 或 feedback 來源；不配對、不歸納
4. 同一句若有多輪作者修改，保留最後版本，並列最後裁定檔；舊版只留歷史對照
5. 分不清歸屬就放「來源不確定」，不因 commit 名稱含 `hand edit` 而放寬
6. 更新分類後同步更新按章索引，讓下一個改稿者不用重新搜尋全庫
7. 最後裁定仍以人物當下、整段功能與閱讀體驗為準；這份庫不是 KPI，也不能凌駕作者當次手改
