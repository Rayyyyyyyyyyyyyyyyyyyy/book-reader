# 《第一章｜十一點的電話》編輯判讀

## 字數與總體判斷

依指定算法：

```bash
sed 1d book-reader/book-v2/01-十一點的電話.md | tr -d '[:space:]' | wc -m
```

全書目標為 **10–12 萬字**；本章目前為 **6,132 字**，已落在單章目標 **6,000–7,000 字**，位置接近下緣。這表示本輪不能把「精簡」當成主要方向，也不需要為達標灌入描寫。應採取交換式修訂：刪掉約 80–120 字的同義解釋，補入約 350–540 字的必要場景；若再補可選的離場動作，增加 40–70 字。必做項目完成後預估約 **6,360–6,600 字**，連可選項全做約 **6,400–6,670 字**。

本章的結構任務已成立。密語受上線時間限制，電話突破媒介限制，六千元帳單帶來實際成本，亞太手機又把兩人推到第一次見面；最後停在尚未說出口的告白，符合章卡，也能銜接第二章。最有效的部分，是親密並非由旁白宣布，而是由回電、延後五分鐘、一起沉默寫作業、赴約與路口放慢等選擇形成。

目前要處理的不是主線不足，而是三種局部落差：

1. 兩處動作或句法使讀者無法把場景演出來
2. 少數已經演出的意義又被旁白說一次
3. 三個主要場次已有骨架，但關鍵轉折仍比周邊摘要薄

本輪只有一份讀者回饋。以下的「共通障礙」不是多數票，而是指同一訊號在逐段反應、總結、章卡或場景表之間互相印證；「個人偏好」則是可以理解，但未必符合本章視角與任務的要求。

## 兩種問題分開處理

### 應刪：同義反覆與過度解釋

1. **索取電話前的風險說明（正文 131–141 行）**
   「沒有別的地方遇見」「可以從生活裡消失」「關係會停在這裡」連續說了同一後果。保留「遊戲關掉……一個人真的可以就這樣……消失」與打字又刪的動作；送出後直接等回覆。第 141 行可刪，約省 20 字。

2. **熬夜後的總結（正文 307–311 行）**
   她的長呵欠、兩人隔天差點睡著，已經使疲累可見。「我們都知道……」不再新增資訊。刪或壓成一句，保留「那晚還是講到兩點多」的反差，約省 25–35 字。

3. **六千元後的第二個量化尾巴（正文 327–331 行）**
   一百個便當是貼近學生的尺度，飲料取消與零用錢減少則是實際後果；「算出來的結果比任何一次段考倒數都長」又用一個漂亮比較重說時間很久。保留前兩者，刪最後一個比喻，約省 20 字。

4. **真人比電話多出的事（正文 529–531 行）**
   保留低頭、移開視線與走路速度，刪「這些都是電話裡聽不見的事」，約省 15 字。

5. **視修後節奏再決定的微調**
   「原來不只我在等」雖有替讀者命名之嫌，但它也是主角第一次改變判斷，功能高於一般尾隨解釋，暫不列必刪。「兩支手機已經可以互相找到對方／接下來只差讓我們也站到同一個地方」負責從技術問題轉到空間問題，也應保留。

### 應補：場景質地與被摘要帶過的時刻

1. **第一次電話真正聊開（正文 177–207 行，補 120–180 字）**
   補一輪從遊戲話題滑進白天生活的對話，讓其中一人意外多透露一件事，另一人沒有急著換題。需要的不是更多「我們很聊得來」例子，而是一次關係位置改變：他第一次不是請教她，或她第一次主動追問他的生活。以聽筒雜音、房門、桌燈或課本擇一作錨點，不在同一段堆多種感官。

2. **借機的信任與限制（正文 353–391 行，補 150–220 字）**
   在公會提出方案或騎樓交接時，讓大學生情侶問一個會影響是否出借的問題，主角回答，再由對方說明試借、歸還或停用條件。這段要同時完成兩件事：他們不是臨時出現的功能角色；主角不是只聽見免費便立刻拿走。不要寫資費史，也不要把風險講成成年教材。

3. **六號出口第一眼（正文 431–451 行，補 80–140 字）**
   讓等待中的位置與她出現的動作更精確。可用電子鐘、出口熱氣、人群流向與一個她身上的功能性細節擇一至二項；該細節最好能支持辨認、緊張或下一個動作。她一開口就回到現有「名字、停頓和眼前的人接在一起」，不要在前面先解釋這一刻的重要。

4. **帳單告別句法（正文 333–351 行，補／移動不超過 20 字）**
   這不是擴寫額度，而是把「她問」移到實際問句之前，使沉默、補話題與十三分四十七秒按時間發生。

5. **西門場景離場（可選，補 40–70 字）**
   現稿已有「分開前」及當晚十一點新手機響起，基本上已完成離場。若修完出口後仍覺得場景突然切斷，只補兩人在哪裡分開、她帶著借用機往哪個方向離開，以及主角何時確定晚上還會再聽見她；不要另寫第二次告別。

## 讀者未提、編輯另見

### 1. 「耳機」是未建立的物件

**判斷：建議處理**

正文 527 行寫「第一次不是透過耳機聽她的腳步聲」，本章當年的通話一直以手機、聽筒與枕頭呈現，場景表及連續性紀錄也沒有耳機。序章雖有成年主角線上面試時戴耳機，不能據此推定高中通話也使用耳機。若耳機不承擔後續作用，改回已建立的「電話」即可；若要保留耳機，必須在前面的十一點通話中先讓它出現，但為一個比喻增加物件並不划算。

### 2. 借機方案的事實已一致，動機仍不足

**判斷：事實通過，因果須補**

正文與 `_continuity.md` 對兩支手機、有效門號、兩顆電池、兩組充電器、月租由情侶負擔、只准網內互打、主角取回並各自保管等設定一致。問題不是資費資訊缺漏，而是情侶為何願意承擔這份責任；修訂時不要再加一輪方案說明，應補信任與退出條件。

### 3. 章卡與連續性核對

**判斷：整體一致**

- 已完成「公會與密語累積熟悉 → 她不能玩後索取電話 → 十一點日常及六千元成本 → 基隆取機 → 西門見面 → 準備告白」的章卡順序
- 序章末尾停在「遊戲裡一個忽然亮起來的名字」與「只有一個密語視窗」，本章以「我最早認得她的方式，是一個遊戲角色」直接接回，沒有重複交代分手，也沒有與前文衝突
- 她給號碼、回電、掛掉後再打、赴約及主動問十一點是否通話，足以完成「共同建立親密」，不需要進入她的內心
- 六千元明確是其中一期的單月帳單，家裡先繳並影響後續零用錢，已與連續性紀錄一致
- 本章結束時告白尚未說出口，沒有提前塞入第二章「等暑假過完」的答案
- 「家裡有事」的原因、她答應見面的完整衡量、她如何定義關係均維持未知，符合資訊邊界
- 場景表五個主要場次都已出現；需要補的是場內轉折厚度，不是新增第六場

### 4. 視角與事後理解

**判斷：目前無明確越界，修訂時須守住**

正文沒有直接寫她未說出口的內心。她房間、早餐店及疲憊的資訊，均由電話聲音或她說出的內容進入；見面後的低頭、移開視線與步速則是主角可見的動作。新增內容不可為了補女方厚度而切入她的房間或早餐店，也不可把笑聲翻譯成感動、期待或信任。

少量成年敘事聲音，如「既暴露了我不會聊天，也正好示範了……」，只是在回看少年笨拙，沒有把後來分開的理解提前塞入，現階段可留。本章不應新增「原來我從那時就想靠解決問題保住關係」之類句子；這個呼應可以由讀者先看見，交給後文累積證據。

### 5. 聲音與格式

**判斷：形式通過，尾隨解釋局部減量**

- 全章未使用破折號
- 正式敘述與引語行末未留句號、逗號、問號或驚嘆號，符合聲音規則
- 「再五分鐘／真的最後五分鐘」、「我說喔／她也說喔」、「十二點就睡／好」是行為反覆，會增加關係與代價，不屬同義贅句
- 需減量的是畫面後再命名意義的句子，而不是所有獨立短句
- 新增場景仍應一個時刻只選一個最有作用的細節，不用衣著、聲音、氣味與光線一起堆滿

## 必須保留的有效段落與句子

- 「我最早認得她的方式，是一個遊戲角色」：接住序章，也立起從角色到真人的全章距離
- 公會頻道的吵雜，對照她把角色停在自由市場角落：她不靠外貌或解釋就先被辨認
- 「你現在不就在跟我聊天」：第一個關係位置改變，讓讀者自己發現他真正想聊的人已經換了
- 平台任務沒過、主角角色半步沒動，以及「我打字很快」：用代價和嘴硬呈現喜歡，不用宣布
- 「再五分鐘／真的最後五分鐘」：重複就是兩人共同延後離線的行動
- 「遊戲關掉，角色下線，一個人真的可以就這樣從另一個人的生活裡消失」：索取電話的風險落在當時資訊，不改寫成成年後的關係理論
- 她給號碼後說「不要太早打，我晚上才有空」：同時是同意與條件
- 第一次通話的「喂／吃了／喔」到一起笑，以及「密語裡那一排『哈哈哈』真的有聲音」：完成文字轉聲音
- 安靜寫作業、第六分鐘先破功、妹妹插話及掛掉十秒後回電：完整呈現日常親密與雙向投入
