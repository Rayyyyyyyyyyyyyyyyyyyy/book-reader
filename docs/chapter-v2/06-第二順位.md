# 第二部｜等待曾經有過結果

## 第六章｜第二順位

**本輪迭代（2026-09-25，待作者校閱）**：本章為新的第六章。正文改以得知男友後暫停聯絡、隔週重新開口，再進入服役期間逐步靠近；第二輪生日移到這些選擇之後。

**核心困境**：他明知她有伴侶，又因重新獲得回應而捨不得離開；他要在一連串仍可停下的選擇裡，逐漸把自己放進第二順位。

**住處（2026-09-22 作者補充）**：家裡在主角大二單身後已由台北搬到中壢。服役時另租營區附近的小房間；休假回家是回中壢家中。退伍後退租，在家裡整理赴日行李，不能寫成回台北或在租屋收行李。

**處境與入口**：淡水那天得知她有男友，他沒有立刻把下一次見面排進日曆。先承接前章的震動與遲疑，再讓服役生活的孤單、她重新給的回應，使他一次次選擇繼續聯絡；孤單是條件，不替他免除明知現況仍靠近的責任。

**素材起點（可改編）**：2015 入伍不適應、缺乏歸屬感，透過 Instagram 聯繫；2016 熱絡、晚餐出遊、牽手擁抱；她仍有伴侶，節日生日自己排在後面；她抱怨關係、說沒有未來，自己向流星許願；2019 螢火蟲夜談及分手拉扯又換話題，此後未再見面。

**場次**：不要直接以第二輪生日作讀者看見的第一個知情選擇。先從淡水之後他幾次打開對話卻沒有約、最後仍主動回到聯絡開始；讓讀者知道中間過了多久，以及他是如何說服自己「只是敘舊」 → 服役初期的孤單與零星 Instagram 回應逐漸變成彼此報告日常，她仍有伴侶這項事實一路在場 → 她與伴侶爭吵後打來，他聽她說到睡著；他可以在這裡停下、拉開距離，卻選擇繼續成為深夜可找的人。以一次普通見面及他為此改動休假，讓第一次實際把她排在其他關係前面的代價成立；不復原已刪的完整晚餐場景，只補目前缺少的決定與時間 → 第二輪生日再作主場景：蛋糕已準備好，他卻要等她與伴侶過完生日；親密發生，節日順位沒有改變。生日成為前面選擇的結果，而不是他突然跨界的入口 → 花燈牽手、伴侶來電與私藏合照；她抱怨原關係，他把抱怨當成繼續等的理由 → 螢火蟲夜談到分手拉扯，他終於說不再像現在這樣見面，之後仍有一次回覆，最後停止見面。每一段都要保留他還能選擇退出、卻沒有退出的時刻。

**第三者**：不由旁白命名，也不安排朋友訓話或由她替他定性。前章得知男友後的痛與本章仍選擇聯絡要分別成立；不能把失去過她當成介入的充分理由。等待、赴約、親密與試著抽離又退回，逐步承載他的受傷、依賴、慾望及責任；她已有伴侶、他仍準備蛋糕的動作，是後段知情參與的證據。不寫成自我羞辱，不替未出場的伴侶編造痛苦反應，也不把對方只當成擋在兩人之間的障礙。後來她單身、兩人交往，不能倒回來證明這段介入是對的；後來分開，也不寫成報應。

**本章要成立的理解**：他不是在聽到「有男友」的下一刻就接受第二順位，而是先受傷、猶豫，再在被需要的感覺與真實的親密裡一次次降低自己的界線。她對原關係的抱怨不能直接當作她會離開的承諾；他把它當作希望，才持續挪動休假與生活。

**停點與交接**：他試著提出停止等待，之後仍回覆過一次訊息，最後才停止見面。退伍後赴日，生活開始有別的內容；抽離保留退回與代價。
