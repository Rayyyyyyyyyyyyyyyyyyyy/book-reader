# _feedback 目錄索引

book-v2 每一章的流程產出與跨章諮詢都放這裡。流程說明見 `docs/book-v2-workflow.md`，一章一檔的規則見 `AGENTS.md`。

## 命名慣例

| 形式 | 用途 |
|---|---|
| `NN-scenes.md` | 場景表：地點與配備、時間天氣、在場人物、物件歸屬、各自知道的事 |
| `NN-reader.md` | 讀者回饋（`ai-reader`，刻意盲讀，不看章卡與場景表） |
| `NN-editor.md` | 編輯判讀與修訂清單，末尾附潤飾紀錄與 Claude 通讀紀錄 |
| `NN-audit.md` | 一致性稽核帳本與修正清單 |
| `NN-<議題>-{reader,editor}.md` | 單章的臨時諮詢，例如 `07-restructure-*` |
| `全書-<議題>[-{reader,editor}].md` | 跨章檢查，範圍是整本書 |
| `history/<批次>/` | 已被取代或機制已取消的回饋，保留原貌不再更新 |

## 逐章四檔

序章到結語、後記全部到位，只有兩處空缺，都是刻意的：

- **第六章沒有 `scenes` 與 `audit`**。場景表與獨立稽核這兩步是第六章寫完、讀出八處前後矛盾之後才加進流程的，所以第六章沒有跑過。原因見 `docs/book-v2-workflow.md`「為什麼加入場景表與稽核」。
- **後記沒有 `14-scenes.md`**。後記不是敘事場景，章卡載明沒有場景表可核；`review` 的稽核那步也確認過不需要新建。

第十三章跑過三輪：第一輪在 `history/13-2026-09-21/`，現行的 `13-*.md` 記第二輪重寫，末尾附第三輪（新增七月三十一日與收碗兩場）的處理結果。
