# 《把自己的部分做完》男主角人物弧線分層

日期：2026-09-23

## 判讀範圍與結論

本檔只讀取 `book-reader/is-me/Rui-Xuan.md:13-88` 的十二面向人物分析；第 89 行以後的逐段對話分析未讀取，也不引用。另對照 `Rui-Xuan-生命素材.md`、`story-base.txt`、`docs/my-story/`、book-v2 序章至後記，以及 `_feedback/全書-男主角人物覆蓋率.md`。

原十二面向不是故事開場時的人物設定，而是從分手後的對話歸納出的成熟版本。它混合了三種東西：

1. 他一直都有的底色，例如敏感、反應快、照顧人、重視互惠、用規劃抵抗失控
2. 關係後期才被代價逼出來的能力，例如第一次退出第二順位、開始重問、承認自願付出不能事後變成帳
3. 分手、獨處、獨旅與重新生活後才形成的自我理解，例如課題分離、把安全感收回自己、允許情緒存在、不再以對方回來驗收自己的成長

因此，人物弧線不該寫成「年輕時沒有深度，後來才變深」。比較準確的是：

> 他一直都敏感、深情、會觀察，也一直很會把事情做完；後來長出的不是能力，而是能力的邊界。他終於知道哪些事可以靠自己完成，哪些事少了另一個人的參與，做得再完整也不算共同生活

另外，A、B、C 是時間層，不是價值高低：

- A 層可以很有魅力，也可以很不成熟
- B 層可以做出成熟的單一動作，但還沒有穩定成一套理解
- C 層不是「痊癒」或「不再需要人」，而是能帶著需要、難過與不確定，仍把自己的生活繼續下去

家庭衝突、慢性病、法律事件、家族財務、後來的新關係與具體 AI 工作轉型雖出現在十二面向來源裡，但不屬於本書主線。它們是「本書外」，不是 C 層，也不應為了證明人物完整而補進來。

## 一、十二面向逐面向分層

### 1. 基本處境

**A 層｜故事時間內就有**

- **對科技、遊戲、音樂、旅行與生活成本有具體感。** 高中時已會把六千元電話費換算成一百個便當，為了維持通話去基隆借兩支手機（`01-十一點的電話.md:325-427`）；原始敘述也保留了「亞太真的很神」、電話費與便當價格的直覺（`story-base.txt:20-50`）。這不是分手後才有的知識工作者氣質，而是很早就存在的注意方式。
- **人生階段會變，但那是履歷事實，不是成熟度。** 第一章是高中生，第三章進入大學與打工，第五章是志願役，第六章開始外地工作，第七章後成為遠端知識工作者。不能因十二面向描述的是成年軟體工作者，就把成人的語彙、判斷密度和生活經驗倒灌給高中時的他。

**B 層｜關係後期才萌芽**

- **建立關係外的成人生活。** 退伍後赴日工作，第一次讓日子不必先看她有沒有空（`06-這一次，我們真的在一起了.md:29-57`）；回台後再去澎湖換宿，也顯示他開始有不由關係決定的移動能力（`06:309-349`）。這是主體性的預演，不等於他已完成自我重建。
- **專業自我開始能承受挫敗與求助。** 裁撤後整理履歷、接受朋友指出自己說得太長，再反覆練習（`10-白天有好消息，晚上沒有.md:261-305`）。此時他能修正工作方法，卻仍想用同一套方法修復感情，因此只是分化的起點。

**C 層｜分手之後才長出來**

- **把工作、住處、貓、朋友、興趣與金錢重新組成「一個人的生活」，而不是把一個人的生活當成兩人生活的殘版。** 第十二章開始按一位旅客、一人的口味與自己的興趣做選擇（`12-一個人也能出發.md:3-81`）；第十三章則把新工作、朋友聚餐、演唱會與日常照顧並列（`13-結語-把自己的部分做完.md:3-73`）。這才是十二面向所說「有感覺、有選擇、有創造力的成人生活」在本書裡的成熟形態。

### 2. 人生經歷

**A 層｜故事時間內就有**

- **關係、失聯、重逢、等待與高投入本身。** 這些經歷構成他的依附史，也很早就教會他把「對方還在不在」看得很重；但經歷過第一次失聯，不代表他已經理解自己的模式。第三章關係一縮短，他仍會把對方的忙碌聽成不想見自己（`03-藍白拖.md:569-665`）。
- **把痛苦轉成可處理材料的傾向。** 他從高中就會核對號碼、看時間、重排班表、替空白找理由（`01:147-155,325-361`；`02-那個沒有回答的暑假.md:87-165`）。這是早期防衛與能力，不是成熟反思。

**B 層｜關係後期才萌芽**

- **第一次主動離開錯的位置。** 第五章他說不再以第三者方式見面，刪掉「那下次」，赴日以前不再替她空出休假（`05-第二順位.md:469-525`）。但他也承認，說要走時心裡仍在等她因此選他（`05:491-497`），所以這是停損的萌芽，不是完成。
- **第一次獨自生活與旅行。** 第六章的日本工作使他看見生活可以不圍著她轉（`06:29-95`），但他回來後仍避開關係狀態、寧可不知道（`06:129-135,177-275`）。這段經歷提供 C 層日後會用到的肌肉，尚未產生 C 層結論。

**C 層｜分手之後才長出來**

- **失去不再只是需要排除的故障，而成為必須經過的生活。** 他安排貓的照顧、獨自出發、搭錯車、坐著看河、在鼓聲裡哭，旅行沒有消除失落，只讓他重新對世界起反應（`12:11-27,91-129,169-209`）。
- **能把經歷說成故事，而不是仍站在故事裡求改寫結局。** 後記明確寫出多次重寫記憶後，才逐漸站到鏡頭外面（`14-後記.md:55-75`）。這一層必須晚於失去、獨處與書寫，不能提前成為前段旁白的全知視角。

### 3. 性格與氣質

**A 層｜故事時間內就有**

- **喜歡日本、慢步調，對世界好奇、喜歡到處看看與湊熱鬧。** 2026-10-01 作者直接裁定為原有底色；交往時自以為配合而縮小，第十三章的旅行逐漸找回。能重新辨認壓抑自己的習慣屬於後段理解，好奇與慢步調本身不能分類成分手後才獲得的特質。

- **敏感、觀察快、反應快。** 他很早就能分辨訊息用字、笑聲、停頓與對方的小動作（`01:187-223,575-597`；`03-藍白拖.md:25-35`）。
- **安全時可愛、直接、黏人、會撒嬌。** 「再五分鐘」、反覆叫女朋友、小茶坊的「再十分鐘」都在高中與初次交往時已存在（`01:117-123`；`03:237-287,339-347`）。這不是成熟後才有，也不應因怕把人物寫得太會說而刪掉。
- **會照顧人，也有高標準與效率感。** 借手機、買藍白拖、織圍巾、接送與準備蛋糕都早於最終分手（`01:363-427`；`03:151-175,463-527`；`05-第二順位.md:3-137`）。高標準同時使他容易把「我能處理」變成「應該照我的方法處理」。
- **幽默與自嘲本來就有。** 原始素材的 `XD`、`呵呵` 與正文前半的互相吐槽，都證明他不是分手後才會幽默（`story-base.txt:1-84`；`01:227-287`；`03:93-189`）。

**B 層｜關係後期才萌芽**

- **壓力下的尖銳和切割開始有代價。** 第八章他把自願取消的演唱會、房租、照顧與聚餐綁在一起（`08-原定出發的時間.md:361-489`）；第五章則第一次把投入收回（`05:469-509`）。前者仍是攻擊性防衛，後者仍夾帶「希望她因此選我」，兩者都還沒有變成穩定界線。
- **能在少數時刻收住第一反應。** 第九章察覺「兩千會不會太少」重演舊問法，當場重問（`09-搬進空屋.md:367-383`）。這是成熟動作，但一次做對不能改寫前面已形成的模式。

**C 層｜分手之後才長出來**

- **敏感仍在，但不再每一次都用來監測對方。** 第十二章注意陌生人的笑、河裡的鳥、舊雜誌與街頭鼓聲（`12:91-193`），觀察力重新朝向世界，而不是只朝向關係是否安全。
- **能對自己保留溫度。** 後記不急著替過去的自己辯解，也不再只批判他，承認自己仍內耗、仍有話說不出口（`14:69-85`）。這種與不完美共處的能力，是 C 層的新質地；前段的他只有修正、辯解或再試一次。

### 4. 核心需求

**A 層｜故事時間內就有**

- **高品質連結、被選擇、被理解、被放在心上。** 從等待十一點的電話、確認明天還有沒有電話，到不願再當第二順位，主需求一直沒有變（`01:221-223,341-361`；`05:15-23,375-395`）。
- **日常親密、觸碰、陪伴與明確身分。** 他不只要浪漫事件，也要一起吃飯、說日常、牽手、確認「現在算什麼」（`03:93-253`；`06:619-709,743-781`）。
- **自主、尊重與空間也是原有需求，但他早期只對自己被控制敏感，還不穩定地承認別人的自主。** 因此「需要自主」屬 A，「能把雙方自主放在同一張桌上」不屬 A。

**B 層｜關係後期才萌芽**

- **開始把需求從追問改成可協商的安排。** 固定週五晚餐、照顧分工與共同費用都有實際協商（`07-住在一起以後.md:465-531`；`08:281-359`）。但他仍會把未說出口的買房計畫與自願犧牲帶進協商，顯示需求和控制尚未分開。
- **開始知道直接說一個需要，不等於對方必須照做。** 第九章重問對方能固定負擔多少，是重要萌芽（`09:353-399`）；但他仍沒有說出買房計畫（`09:599-609`）。

**C 層｜分手之後才長出來**

- **仍想要陪伴，但不再把想要陪伴等同於今天的時間必須由另一個人安排。** 第十三章他承認仍想有人一起吃飯、旅行、分享日常，同時知道那和今天幾點回家是兩件事（`13:43-51`）。這不是需求變少，而是需求不再自動變成別人的責任。
- **開始把自己的喜好也視為正當需求。** 一個人點自己想吃的、留下無用但喜歡的扭蛋、看想看的演出（`12:71-81,135-167`；`13:53-67`），都是過去長期被共同未來吞掉的部分重新取得位置。

### 5. 核心恐懼

**A 層｜故事時間內就有**

- **怕不確定、被忽視、被取代與沒有答案。** 沒回訊息時反覆確認、替空白找理由、看見對方另有伴侶仍不敢問清楚，都是早期即有（`02:87-205`；`04-每年的七月三十一日.md:123-205,387-465`）。
- **怕付出沒有被同等珍惜。** 第二順位的生日、節日與等待把這份恐懼具體化（`05:3-137,375-395`）。
- **怕失控，會用規劃恢復秩序。** 行程、帳本、地圖、時間、備忘錄和存款都是早期就有的回應，不應寫成分手後才獲得的能力。

**B 層｜關係後期才萌芽**

- **開始能承受一個答案不照自己要的方向走。** 第十章終於不能再把「不想往那裡走」改寫成速度差（`10-白天有好消息，晚上沒有.md:495-521`）；第十一章則能把道歉送出後停在「我收到了」，不再追問（`11-空下來的衣櫃.md:367-397`）。此時恐懼仍強，只是行為第一次不完全服從它。

**C 層｜分手之後才長出來**

- **安全不是「從此不怕失去」，而是害怕出現時，仍不把別人的回來當成唯一出口。** 第十二章仍會以為手機是她的訊息、回家仍會哭（`12:121-129,203-229`）；第十三章也仍會夢見她（`13:93-107`）。成熟的證據是他照樣吃飯、工作、赴約、出發，而不是恐懼消失。
- **能容許不知道。** 他不知道她現在會不會去淡水，也不再需要知道（`13:143-153`）；後記承認對方的選擇本來就不歸自己管（`14:83-85`）。

### 6. 關係模式

**A 層｜故事時間內就有**

- **先觀察、等待、試探，一旦確認便快速高投入。** 從等上線、借手機、織圍巾，到多年後把休假留白，模式很早就成形（`01:103-147,363-427`；`03:463-527`；`05:239-265,355-381`）。
- **愛人的方式非常具體。** 交通、查資料、做飯、記喜好、陪伴、身體接觸、處理瑣事都屬 A；問題從來不是他不會付出，而是他會不會先確認那份付出是不是共同決定。
- **安全後需求量上升。** 第三章關係一確認，他便反覆確認名分、想延長見面；同居後則期待共餐、共同支出與共同未來。這是原有模式，不是後期才長出的缺陷。

**B 層｜關係後期才萌芽**

- **第一次設界線，但仍把界線當成可能換來選擇的手段。** 第五章「不再這樣見面」是必要轉折，後文也明說他心裡仍在等她因此選他（`05:469-497`）。
- **第一次尊重對方的考慮期。** 邀請同居後，他把地址、支出與課程資料交給她，沒有隔天換一種方式再問（`06:839-915`）。這是他能尊重節奏的證據，卻尚未成為每次都做得到的習慣。
- **第一次把平均分攤改成可持續的比例。** 第九章讓對方先說能固定負擔的數字，再重算共同費用（`09:353-399`）。這是成熟關係能力的萌芽。

**C 層｜分手之後才長出來**

- **關係不再是填補空缺的人，而是兩個有各自生活的人共同決定是否同行。** 第十三章保留對陪伴的渴望，同時維持自己的時間（`13:43-51`）；後記把「自己的責任」與「必須邀請對方參與的共同安排」分開（`14:25-53`）。
- **停止額外挽回，不等於撤銷照顧與責任。** 他仍完成帳務、照顧黑糖、處理工作與生活，但不再用這些交換她回來（`11:367-409`；`14:35-53`）。這才是停損與承諾能同時存在的 C 層。

### 7. 自我認同

**A 層｜故事時間內就有**

- **覺得自己會想、能做、願意負責，也重視品味和真心。** 這些多半透過行為出現，而不是一套完整自我定義：他能解題、照顧人、挑選有意義的禮物、對喜歡的音樂和旅行有反應。
- **不能接受自己成為逃避責任或無腦執行的人。** 分手當天仍回吧台重做飲料（`03:707-781`），成年後遇到裁撤也先處理交接與求職（`10:175-213`）。這份責任感一直都在。

**B 層｜關係後期才萌芽**

- **發現自己在關係外也能生活。** 第一次日本生活、澎湖換宿與後來的求職，都讓他的能力不只服務於關係（`06:3-97,309-349`；`10:261-305`）。但他仍會把生活重新綁回她，因此只是擴張，不是整合。
- **把原本為共同未來準備的資源重新命名為當下自己的備用。** 頭期款改成待業與搬家備用（`10:549-587`）是重要轉折：不是不再想要家，而是先承認現在的自己也值得被資源保護。

**C 層｜分手之後才長出來**

- **自我不再只由「能不能被她留下」驗證。** 他可以是新同事、朋友、旅人、演唱會觀眾、黑糖的照顧者，也可以是一個仍想被陪伴的人（`12:131-193,211-243`；`13:3-67`）。
- **「自由但不孤獨」不再是一句人設。** 第十三章承認一個人有時會無聊、仍想有人一起，卻不因此取消一個人出發的能力（`13:25-51`）。
- **正向自我感開始落在小事。** 後記寫到晚餐調味、鏡子與貓吃乾淨的碗（`14:77-85`），對應生命素材中「喜歡現在的自己」與「不再急著否定自己」（`Rui-Xuan-生命素材.md:26,53`）。

### 8. 價值觀與道德邏輯

**A 層｜故事時間內就有**

- **責任、互惠、公平、能力、清楚與生活品質。** 他很早就願意承擔成本，也在意別人是否同樣把關係放在心上。金錢不是最高價值，但會被他拿來判斷投入比例（`01:325-427`；`05:3-137`；`07:387-427`）。
- **尊重與自主是價值，不代表他早期已能一致實作。** 第三章他把對方的「不要」換成下一個方案（`03:605-665`）；第八章也用自己的犧牲壓縮她的選擇（`08:387-489`）。價值與行為之間的落差正是故事代價。

**B 層｜關係後期才萌芽**

- **公平從每次對半，改成長期可持續。** 第九章按雙方收入與固定支出重算比例（`09:367-399`），開始理解互惠不等於每一筆五五分。
- **承認自願付出不能事後變成對方的債。** 第十一章看見演唱會是自己不買、邀約是自己拒絕，卻曾把它們放進「為了我們」底下（`11:241-261`）。這是具體事件的現場辨認，尚不是一套已完全內化的原則。

**C 層｜分手之後才長出來**

- **課題分離與責任分界。** 後記將「自己答應的責任與造成的影響」和「需要雙方參與的共同安排」分開（`14:25-33`），也承認對方是否回來不歸自己管（`14:83-85`）。
- **界線不是把所有彈性丟掉。** `14:45-53` 保留補救、協商與交接，避免把成長寫成冷漠撤退。這正是生命素材中「停損不是冷漠」與「相互依靠也各自負責」的成熟版本（`Rui-Xuan-生命素材.md:21,30-31`）。

### 9. 行為模式

**A 層｜故事時間內就有**

- **用記錄、核對、表格、地圖、行程與清單恢復秩序。** 從電話號碼、通話時間、班表，到共同支出、行程與求職試算表，這是全書最穩定的行為標記（`01:147-155,325-361`；`08:77-125`；`10:261-329`）。
- **用食物、移動、音樂與照顧承接情緒。** 早期已會一起吃、走、聽歌、旅行和做具體照顧；這些行為不應全部歸到分手後療癒。

**B 層｜關係後期才萌芽**

- **撤退與節能。** 第五章刪掉「那下次」、停止主動聯絡（`05:499-525`）；第十一章把共同試算表封存、暫停非必要聯絡（`11:391-409`）。前者仍帶期待，後者才開始不以挽回為目的。
- **使用結構，但第一次不讓結構只服務於挽回。** 第十一章把「真的發生的／我以為的／我自己決定的」分開（`11:313-327`），又把長訊息刪到只剩具體行為與道歉（`11:333-383`）。這是從理智化轉向辨識責任的橋段。

**C 層｜分手之後才長出來**

- **結構仍在，控制對象變了。** 第十二章只安排來回日期與黑糖照顧，不做完整行程表（`12:11-27`）；第十三章用預算替活動留位置，而不是用預算取消自己（`13:53-67`）。他仍會規劃，但只規劃自己可決定的部分。
- **允許無目的、低效率與停留。** 搭錯車後坐在月台、河邊不急著走、買無用的扭蛋、在舊雜誌前讀到忘記時間（`12:91-167`），都是過去「必要／划算／有沒有用」邏輯鬆動後才可能出現的行為。

### 10. 內在矛盾

**A 層｜故事時間內就有**

- **自由與歸屬、空間與觸碰、理性與濃烈、邊界與高需求同時存在。** 這些不是成熟後才有的深度，而是故事從一開始就在推動他的力量。
- **要求公平與清楚，卻會替灰色關係找理由；討厭被控制，卻用確定感壓縮對方。** 第二順位時他明知位置不對仍留下（`05:15-23,297-359`）；同居後他沒有說買房計畫，卻希望她按那個未公開的方向節制（`08:387-465`）。

**B 層｜關係後期才萌芽**

- **開始看見矛盾造成的結果。** 他能承認自己喜歡先想到、先做完，也承認那些自願行動後來變成帳（`08:451-465`；`11:249-261`）。但看見一次，不表示下次已不會再做。
- **開始同時保留兩個真相。** 她曾經想一起買房是真的，她現在不想繼續也是真的（`10:467-521`）。這是 C 層認知彈性的前身。

**C 層｜分手之後才長出來**

- **不再逼其中一邊消失。** 他可以想有人一起，也可以一個人回家；可以後悔，也可以不再挽回；可以承認兩人真心想過共同未來，也承認方向沒有被共同確認（`13:43-51,75-99`）。
- **修復不等於復原。** 回淡水不是等她，換掉裂掉的貓碗也沒有丟掉舊碗（`13:109-175`）。過去留下痕跡，但生活不必回到原樣才能繼續，對應生命素材的車廂與痕跡意象（`Rui-Xuan-生命素材.md:33-34`）。

### 11. 防衛機制

**A 層｜故事時間內就有**

- **理智化、合理化與控制感。** 他會把痛苦拆成時間、方法、金額和方案，讓事情看起來仍能處理（`02:121-165`；`08:77-125`；`10:89-145,325-389`）。
- **幽默與吐槽。** 早期常用玩笑擋尷尬、維持連結；這是人格底色，不是成熟成果（`01:227-287`；`03:159-189,443-451`）。
- **受傷時先說沒事、先把用心證明成合理。** `02:249-255` 的「沒事」和第八章的帳本都是同一個防衛在不同年齡的形狀。

**B 層｜關係後期才萌芽**

- **防衛仍啟動，但不再完全掌舵。** 第十一章寫了長篇說明後，發現每一段都朝「可不可以再想一次」靠過去，最後刪到只剩具體承認（`11:333-383`）。這不是沒有合理化，而是第一次能看見它正在做什麼。
- **開始向朋友求助，而不是只向清單求答案。** 急性失落中主動找朋友吃飯，讓朋友只問一件事、也接受對方不知道全部（`11:185-291`）。

**C 層｜分手之後才長出來**

- **允許情緒存在，不急著整理成已經想通。** 在鼓聲裡哭仍留在現場，旅行回家仍哭，後來仍夢見她（`12:169-229`；`13:93-107`）。
- **對念頭保留距離。** 他能說自己不知道、記憶會被重寫，也不急著替過去的自己辯護或定罪（`13:93-99`；`14:57-75`）。這是生命素材中《我可能錯了》所代表的認知彈性（`Rui-Xuan-生命素材.md:48`），不能提前變成早期人物的自我解說。

### 12. 變化可能

**A 層｜故事時間內就有**

- **有自省、學習與修正能力。** 他會把失敗記下、重做，也能在被指出問題後修改方法（`00-序章-白天與晚上.md:19-45`；`01:39-61`）。這是他能改變的條件，不等於他已經完成改變。
- **安全時會柔軟、會照顧；不確定時會焦慮、變尖或過度分析。** 這套狀態切換從高中就已存在，是人物弧線的起點，不是結論。

**B 層｜關係後期才萌芽**

- **改變以多次不完整的嘗試發生。** 第五章第一次退出、第一次日本生活、第六章尊重考慮期、第九章重問、第十章把存款改作自保、第十一章停止以挽回指揮所有動作，都是局部前進（`05:469-525`；`06:29-95,839-915`；`09:367-399`；`10:549-587`；`11:333-409`）。
- **這些前進都會反覆。** 第六章已有一人生活，回台後仍選擇不問；第九章能重問金額，仍把買房計畫藏到分手後才說。反覆不是漏洞，而是 B 層的必要形狀。

**C 層｜分手之後才長出來**

- **成長不再以變成完美的人驗收。** 後記明說沒有突然和解、沒有變得很厲害，仍內耗、仍有話說不出口（`14:69-85`）。這對應生命素材「一年後仍不厲害，但不再急著否定自己」（`Rui-Xuan-生命素材.md:53`）。
- **成長方向變成：保留深情與敏銳，同時分散歸屬來源、清楚表達、尊重對方節奏、照顧自己的生活。** 第十二至十四章已呈現其中多數，但「從更多人際連結得到被看見」和「主動喜歡自己的外在與存在」仍偏薄，詳見後段反查。

## 二、第一至十一章「不能提早出現」清單

這份清單是本輪最重要的寫作護欄。禁止的主要不是動作，而是**完成式的自我理解**。第一至十一章可以有偶發的成熟動作、模糊的預感和 B 層轉折；不能讓當時的他已經能穩定說出分手後才長出的答案。

| 不准提早出現的說法／自我理解 | 為什麼不能寫進第一至十一章 | 前段可以保留的萌芽 |

| 「我的安全感來自自己」「我不再依附誰，也不怕失去陪伴」 | 這是失去共同生活、獨處與第二次獨旅後才可能形成的理解；第六章第一次赴日後，他仍選擇不問關係狀態，證明尚未完成（`06:129-135,177-275,579-605`） | 可以寫一個人在日本把生活過下去、暫時不等訊息（`06:29-57`），不能讓他替這段經驗下最終結論 |

### 對現稿幾個容易誤判的位置

- `06:29-57` 的一人生活是 B 層預演，不是「安全感已來自自己」；後面仍避問關係狀態，已替這個預演保留反覆
- `06:741-767` 能看著她離開而不立刻理解成失去，是一次新反應，不代表依附模式已改寫
- `09:367-383` 當場重問是 B 層的成熟動作，不應回頭替前面所有控制行為漂白
- `10:549-587` 把頭期款改作自己的備用，是被現實逼出的關鍵轉向，尚未等於完整自我安定
- `11:313-397` 已可以有具體辨認、道歉與停止聯絡，因為分手已發生；但本章仍在急性失落，不能升格成後記式的普遍教訓

## 三、反向檢查：第十二至十四章有沒有長出 C 層

這裡不要求把生命素材裡每一件後期事件都塞進書中。timeleft、朋友慶生、形象照、《我可能錯了》、集體活動與分享閱讀是 C 層質地的來源，不是必須逐項改編的場景。要檢查的是：它們底下代表的成熟能力，有沒有透過本書既有事件成立。

| C 層質地 | 第十二章｜獨旅 | 第十三章｜結語 | 第十四章｜後記 | 判斷 |
|---|---|---|---|---|
| **把決定權收回自己，同時完成責任** | 先安排黑糖照顧再買票，只規劃來回與照顧時段（`12:3-27`） | 新工作、朋友、買票與照顧黑糖並行（`13:3-73`） | 把可處理的責任與共同決定分開（`14:25-53`） | **足夠。** 不是任性出走，而是先把自己的部分做完再出發 |
| **一個人有選擇，不等於不再需要人** | 一個人點餐、迷路、停留，也仍會想起她（`12:55-129`） | 明說仍想有人陪，但那和今天幾點回家是兩件事（`13:43-51`） | 承認對方是否回來不歸自己管（`14:83-85`） | **足夠，而且是全書最清楚的 C 層主軸** |
| **允許情緒存在，不急著修好** | 在鼓聲裡哭而不離場，返家仍哭（`12:169-229`） | 仍會夢見她，難過不因理解就消失（`13:93-107`） | 不宣稱和解，只說慢慢代謝（`14:69-79`） | **足夠。** 已避開「一趟旅行治好失戀」 |
| **停損、課題分離與不再額外挽回** | 遵守只處理物品帳務的約定，照片沒有傳給她（`12:35-63`） | 七月三十一日不再找她，也不需知道她有沒有來（`13:109-153`） | 明說停止額外挽回，對方回不回來不由自己決定（`14:35-53,83-85`） | **足夠。** B 層的「停止聯絡」在這裡終於成為穩定原則 |

### 後段總判斷

第十二至十四章的 C 層主骨架是成立的：

- 他重新做自己的選擇
- 不再用選擇逼對方回來
- 能帶著情緒生活，而不是用旅行把情緒消滅
- 能區分個人責任與共同決定
- 能承認仍想被陪伴，而不把陪伴變成別人的義務
- 能把過去當成發生過的事，而不是還在等待翻案的案件

真正偏薄的有兩處：

1. **歸屬來源仍不夠分散。** 朋友有出現，公共世界也重新亮起來，但「我可以被不同的人接住、也能主動接近世界」的重量仍遠小於前十一章把歸屬押在她身上的重量
2. **正向自我喜歡仍多半是結論。** 他找回喜好與決定權很清楚，卻仍較少讓讀者感到他喜歡自己的存在，而不只是重新成為能工作、能旅行、能照顧生活的人

這兩個缺口都不能反向靠把成熟語句塞回前段解決；那只會讓弧線更平。它們屬於後段的厚度問題，而且在「不新增場景、人物或故事線」的界線下，只能先記錄，不在本輪提出加戲方案。

## 最後的弧線護欄

後續若要把本檔寫進正式寫作規則，最需要保留的是以下五句判斷：

1. **早期人物可以有能力、魅力、幽默與深情，不能有後期才形成的完成式自我理解**
2. **B 層允許偶爾做對，但不能因一次做對，就把他寫成已經知道整套道理**
3. **第六章第一次獨立生活是預演，第十二章失去共同生活後再次獨旅，才是 C 層真正開始穩定的地方**
4. **第十一章可以辨認具體錯誤、道歉與停止聯絡，但不能提前擁有第十四章的普遍原則與敘事距離**
5. **後段成熟的證據不是他不再痛、不再想被愛，而是痛和需要都還在時，他仍不替別人做決定，也沒有停掉自己的生活**
