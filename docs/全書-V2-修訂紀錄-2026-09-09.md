## 修訂範圍

| Review 問題 | 實際修訂結果 |
|---|---|
| 三圈定義前後不同 | 統一動作、可影響結果、已發生或目前幾乎無法影響的結果；情緒與理解不當成可直接控制 |
| 現場檔真實程度過度宣稱 | 第一、十二章改為開場明示的假設獨白，後文回指維持同一身分；第十一章恢復素材支持的帳戶事件時序 |
| 「做完」變成能力耗盡 | 必要責任完成或安排承接，與額外努力分開；修復可能不自動產生繼續投入義務 |
| 絕對判準靠後文補救 | 初次定義即寫準，不以答案快慢、提醒次數、獨立能力增長或能否睡著判定成敗 |
| 同義反覆與跨章重複 | 各章保留自己的因果與新條件，合併重複教學、比喻與防守式補充 |
| 人物被長篇講解隔開 | 第六、七、八、十二章提早回到主場景，讓新資訊帶出下一個理解 |
| 每句獨立換行 | 普通分析合成能承接因果的段落，保留反駁、關鍵停頓與假設獨白的碎句 |
| 多次收尾 | 工具與限制放在主要落點前，部小結與結語減少重教，讓最後畫面停留 |

## 驗收結果

- 18 份稿件均完成全文編輯與主 session 潤飾；序章、十二章、四部引言／練習／小結及結語齊全，每檔保留一個一級標題
- 三圈統一為自己的具體動作、仍可影響但不能決定的結果、已發生或目前幾乎無法影響的結果；不能決定不等於第三圈，努力次數不決定圈別
- 必要責任與額外投入分開；照護與協助不以最終獨立為唯一成果，修復可能不自動產生繼續投入的義務
- 第一、十二章共兩處明示的假設獨白，零處宣稱已核對的原始現場檔；第十一章帳戶事件與既有素材核對，後續建議不冒充已發生的作者行動
- 核心命題與七、八章的鏡頭銜接保留；第四、十二章已刪除對第一章舊「放映機／機器」的失效回指
