# 素材取用與真實性邊界

## 動筆前先讀

寫之前先讀使用者指定的材料，核對書中內容與作者真實素材

1. 讀 `book-reader/is-me/Rui-Xuan-生命素材.md`
   - 寫隨筆時，場景、記憶、經歷優先從這裡取
   - 寫心得需要落地時，也可從這裡找真實經驗

2. 寫讀書心得時，再讀 `book-reader/讀書心得/` 內相關心得 `.md`
   - 檔名即書名
   - 跨書串連只能使用實際存在、實際讀過的內容


紀實寫作中，沒有素材支持的經歷不要補。同一故事有原始敘述、整理稿與補完規劃時，分清原有事實、補述與推測；衍生稿的台詞、動機、日期與場景不因完整就成為已確認，回憶也不自動等於逐字紀錄
