# Chapter 14｜終於，不只是曖昧的人

2019 年，我準備退伍。

我們第二次置身在山裡的螢火蟲海裡，站在黑暗中看著那些一閃一閃的光。
她突然說：「我跟他提分手了。但對方不肯放手，還在拉扯。」

我沒有插話，只是靜靜等她繼續說。
但她很快就轉開話題，像剛剛那句話從沒出現過。

那時候我其實已經很累了。
她不是沒有靠近我。
也不是沒有給我希望。
可她一直沒有做決定。

她在精神上越界，卻又兩邊都放不下。
我站在那個位置太久，久到連自己都開始看不起自己。

那天之後，我們沒有再見面。

退伍後，我買了一張單程機票。
沒有預設歸期，也沒有把每一步都安排好。
我只是知道，如果我再留在原地，我會繼續等她，繼續把自己的生活卡在她的選擇裡。

所以我把那段旅程當成放逐。

不是瀟灑。
更不是我突然看開。
只是我想離開那個一直等不到名分的自己。

我們成了網友。
只透過限動或偶爾的訊息知道彼此還存在。
我在陌生的地方慢慢練習一個人生活，練習不再把每一天的情緒交給她決定。
有時候還是會想她，但那種想念不再立刻變成行動。

後來疫情爆發，一切被打亂。
我被推回台灣。

那陣子，台灣正流行豪華懶人露營。
我一時興起，傳訊問她：

「兩天一夜，去試試看懶人露營好不好？」

我沒預期她會答應。
但她答應了。

那一次很奇怪。
我們像情侶一樣出遊、拍照、煮咖啡、躺在帳篷裡聽風聲。
沒有過去那種必須躲起來的感覺，也沒有誰的名字卡在中間。

可是我其實還是不敢問。
我不知道她現在到底是什麼狀態。
也怕一問，眼前這種好不容易重新靠近的平靜又碎掉。

後來，我去了澎湖。
那時剛好有花火節。
我問她要不要來找我，一起看煙火。

她又答應了。

她一個人搭飛機到澎湖。
她說那是她人生第一次獨自坐飛機，下飛機時興奮得像第一次出遠門的小孩，嘰哩呱啦地講個不停。

我們 check in、吃飯、逛街、看海，也一起在人群裡仰望煙火綻放。
那天晚上，在民宿房間裡，我們喝了點酒。

我看著她紅著臉笑著講話，忍不住吻了她。
她沒有退縮，也沒有逃避。

隔天早上醒來後，我再次問她：

「所以現在，我們是什麼關係？妳要跟我在一起嗎？」

她靜了一下，說：

「我願意跟你過夜，是因為我真的分手了。」

那一刻，我才真的知道。
這一次，如果我們要靠近，就不用再站在陰影裡。

這一次，她不是回來看看。
她是真的留下來了。
