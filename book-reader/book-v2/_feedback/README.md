# book-v2 回饋索引

整理日期：2026-09-28。

這裡保存場景表、逐章流程回饋、作者校閱、局部修訂與跨章診斷。書稿現況看 [交接文件](../../../docs/book-v2-handoff.md)，操作規則看 [寫作流程](../../../docs/book-v2-workflow.md)，文件總入口見 [docs 索引](../../../docs/README.md)。

## 按問題找材料

| 要找什麼 | 入口 |
|---|---|
| 某章的事件、物件與人物知情 | 下方「逐章檔案」的場景表，並核對 [跨章連續性](../_continuity.md) 與當前正文 |
| 作者已校閱什麼、哪些句子由作者親寫 | [作者校閱紀錄](#作者校閱紀錄) 與 [全書手改對照](全書-手改對照.md) |
| 最新試改、尚未整章確認的修改 | [局部修訂與待選清單](#局部修訂與待選清單) |
| 人物聲音與成熟度 | 先讀 [人物弧線](全書-人物弧線.md)，再查 [手改樣本](全書-手改對照.md)；覆蓋率與補寫清單須連同檔首更正閱讀 |
| 拆章前的讀者、編輯與稽核結論 | [history 索引](history/README.md)，按當時章號查找 |

回饋記錄的是某一輪正文。舊核准不自動涵蓋後續修改；局部採納不等於整章定稿。文內行號與字數按產出當時版本解讀，修改前仍須回到現稿核對。

## 目錄與命名

| 位置／形式 | 用途 |
|---|---|
| `NN-scenes.md` | 現行章號的場景表；隨正文同步時間、地點、人物、物件與資訊邊界 |
| `NN-reader.md` | 該輪讀者盲讀回饋，不讀章卡與場景表 |
| `NN-editor.md` | 編輯判讀、修訂清單及該輪潤飾、通讀紀錄 |
| `NN-audit.md` | 該輪一致性稽核帳本與修正清單 |
| `author-review/NN[-NN]-作者校閱-YYYY-MM-DD.md` | 作者校閱、確認範圍、手改來源與採納紀錄 |
| `revisions/NN[-NN]-<議題>-YYYY-MM-DD.md` | 局部試改、修訂的原句、改後句、來源與狀態 |
| `NN-<議題>-{reader,editor}.md` | 單章臨時諮詢；版本被取代後移入相應歷史批次 |
| `全書-<議題>[-{reader,editor}][-YYYY-MM-DD].md` | 全書診斷、裁定或來源庫；依各檔日期與狀態使用 |
| `history/<批次>/` | 已被取代或機制已取消的回饋，保留原始內容、章號與判斷 |

流水線仍將 `scenes`／`reader`／`editor`／`audit` 寫在本層；人物弧線與手改對照也保留固定路徑。日期紀錄不覆寫前一輪；若只是模型試稿，不登錄為作者親筆或整章核准。
