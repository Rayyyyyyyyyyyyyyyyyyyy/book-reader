# 第一部｜我們怎麼走到一起，又失去彼此

## 第三章｜藍白拖

**核心困境**：失聯近一年後，他仍想靠近她；兩人都願意重新聯絡，這次能否把熟悉感變成眼前真正的交往。

**固定學年（2026-09-22 作者確認）**：七月三十一日為主角即將升大一、她即將升夜校高三的暑假，主角大一開學後才開始咖啡廳打工。淡水當天僅能談之後想找的工作，不能已有咖啡廳班表。她高三下備考時，主角仍是大一。

**處境與入口**：失聯後近一年，主角在 Facebook 好友建議裡再次看見她，仍想聯繫，卻記得九月電話裡的「你是誰」。兩人重新以訊息聊天後，她寫明前段關係已結束、目前單身；他仍不知道當年失聯的完整原因，帶著這份不確定赴淡水之約。

**素材起點（可改編）**：七月三十一日淡水八里、踏浪、藍白拖、捷運確認交往；茶坊相處、她探班、五月天專輯與手織圍巾。

**場次**：Facebook 好友邀請後，兩人只靠訊息恢復熟悉感；她以訊息說明目前單身，兩人在訊息裡約定七月三十一日去淡水，見面前沒有通話 → 淡水老街上，他問起那年暑假，只問了一半；她說「那時候不知道要怎麼回你」，他沒再追問那句「你是誰」，怕問下去會失去眼前這一天 → 淡水八里踏浪，藍白拖讓狼狽變成親密，捷運上確認交往 → 她當晚先打來；茶坊裡各自做事又忍不住靠近、她探班送來專輯、他陪她搭車又折返、生日織的圍巾，讓兩人持續互相挪時間與記住對方。相處快樂不預告分手，也不把「正式交往」當成唯一高潮。

**本章要成立的理解**：兩人真的相愛過，重聯、赴約與交往都有她的主動回應；讀者能完整停留在這段迅速升溫的甜蜜裡。沒追問「你是誰」的選擇仍在，但不讓那個未解問題搶走本章的主感受；留待第七章同樣的不問回收。

**停點與交接**：冬天她仍會圍著他織的圍巾來見他。新第四章從高三下開始，讓課業、跨城距離與排班逐漸改變兩人的相處條件。
