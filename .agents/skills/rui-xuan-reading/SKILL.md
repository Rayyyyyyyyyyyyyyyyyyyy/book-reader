# Rui-Xuan 讀書心得與隨筆

先辨認使用者要整理素材、提供回饋，還是寫作；貼上隨筆不等於要求改寫。作者已要求寫、改寫或整理成心得時，在既有授權內動筆。

用 Rui-Xuan 的聲音，寫一篇會往前走的文章。紀實寫作的優先順序是：真實 → 推進 → 準確 → 聲音 → 漂亮。

## 按任務取材

| 任務 | 必讀 reference |
|---|---|
| 整理生命素材 | [life-material.md](references/life-material.md)，再讀素材表的既有條目 |
| 讀書心得 | [source-grounding.md](references/source-grounding.md)、[common-voice.md](references/common-voice.md)、[structure-and-revision.md](references/structure-and-revision.md)、[book-review.md](references/book-review.md) |
| 反思隨筆 | source-grounding、common-voice、structure-and-revision，以及 [reflective-essay.md](references/reflective-essay.md) |
| 只提供閱讀反應 | 使用 [ai-reader](../ai-reader/SKILL.md)，不自行改稿 |
| 判讀回饋採納價值 | 使用 [ai-editor](../ai-editor/SKILL.md)，不因評讀就直接改稿 |

只讀本次任務需要的材料。心得草稿在 `book-reader/讀書心得/`，已發布心得以 `site/src/content/books/` 為真實來源；作者經驗與聲音參考在 `book-reader/is-me/`。跨書串連限實際提供、存在且讀過的內容，不用書名代替閱讀證據。

## 局部修稿

先讀現稿與相關 diff，辨認作者已手改的語氣和意思；按引文及前後文定位，不只照行號。刪改後接好相鄰段落，已套用的修改不重複做。若替換改變原意、增加抽象度或把可能說成必然，先指出差異。

修後按問題回讀，確認理解、節奏、現場感與有效的聲音仍在。不把單一篇的取捨升格成所有文章必須遵守的禁令；作者明確確認、可跨情境延用的偏好才整理入規則。

生命素材不是人物傳記。抽象概念需要落地時只取這篇需要的一塊，不虛構作者經歷、不推定未提供的心理動機，也不在尚未消化時假裝豁達。
