# 《第四章｜每年的七月三十一日》編輯判讀

## 篇幅與總體判斷

依指定算法：

```bash
sed '1d' book-reader/book-v2/04-每年的七月三十一日.md | tr -d '[:space:]' | wc -m
```

目前為 **5,474 字**，已落在本章 **5,000–6,000 字**的目標內。全書目標為 10–12 萬字；僅憑本章無法判斷全書總量，但本章不需要為了配額灌字。修訂應以「刪除收束的重複解釋，換入一小段真正欠缺的場景」為原則，最後仍維持約 5,500–5,800 字。

本章的事件功能已成立。它承接第三章行事曆上的「淡水」，讓主角連續兩次獨自赴約；畢業後取得她同意才聯絡，經由回電、社群、見面、牽手與共同日期升高希望，再由伴侶資訊改寫前述訊號，最後停在主角知情後仍答應下一次。這與章卡的核心困境、停點及場景表一致。

主要問題有三個。第一，「交往三年」與前三章學籍、分手及兩次七月三十一日的順序可能構成實質時間衝突。第二，男友揭露後，同一個「在意不等於準備復合」被畫面、結晶句與回看連說數次。第三，晚間兩小時電話以摘要跳過她的生活，導致最該讓兩人重新認識彼此的場次，具體內容仍偏向主角的報告與兩人的舊笑話。

本輪只有一份讀者回饋。下列「共通障礙」指讀者在不同段落反覆遇到，且能由正文、章卡、前文或連續性獨立驗證的問題，不代表多位讀者投票；需要更多後文才可判斷、或主要涉及口味的意見，另列為個人偏好與待觀察項目。

## 分開處理：該刪的與該補的

### 同義反覆與過度解釋：刪

1. 第 463–481 行只保留一次理解。最有效的順序是：共同日期變義 → 腳踏車迫使兩人拉開距離 → 主角沒有問見面與現任的界線 → 「不是兩個人都回到同一個地方，就代表在等同一件事」 → 繼續走。第 477–481 行不必再列「回電、邀約、日期」並重述誤讀。
2. 第 377–385 行的第二輪試滑可縮成一個動作單位：她要求自己試、比剛才多滑幾步、快撞欄杆時抓回他的手。保留關係變化，刪掉第二次成績對話與同功能的步數說明。
3. 不刪開頭兩次認錯。第一次有跟錯背影後以價目表掩飾，第二次由綁頭髮與船風勾回前一年，情緒與記憶都有遞進。
4. 不刪三天猶豫。怕不接、怕再聽見「你是誰」、怕多年不撥而持續想像，三天各自改變恐懼對象，並非同義重播。

### 場景質地不足與摘要過快：補

1. **需展開成場景：第 221 行晚間電話的工作近況。** 讓她講一件有起點、變化與小結果的工作插曲；主角先搶話，後來因某個具體內容停住，第一次把問題問完或讓她講完。可用電話裡能聽見的抽屜、腳步、環境聲作錨，但一個時刻只留一個有作用的細節。這段的工作是讓讀者遇見「現在的她」，不是暗示她一定還愛主角。
2. **需補一個可觀察事實：第 237–251 行社群頁面。** 主角接受好友邀請後，短暫查看她的頁面；交代頁面沒有可辨認的伴侶資訊，隨即回到她看過他的 Facebook。約 40–80 字即可，不展開成網路偵查。
3. **不需展開第二次淡水回訪。** 場景表已明定它只承載重複與時間推進。陌生背影、替情侶拍照、離開前不再告訴自己明年會遇見，已構成進場、變化與離場；再完整走一次老街與渡船只會複製第一場。
4. **不需替她補「妹妹問她時的反應」。** 主角不在場，場景表也明定他只知道她同意提供號碼。現在「妹妹隔夜回覆、確認她說可以」已足以交代同意鏈。

## 讀者未提、編輯另見的問題

### 1. 「三年」是章卡、正文與連續性的共同設定衝突

這不是正文單點筆誤。章卡、場景表與 `_continuity.md` 都沿用「交往三年」，同時又把主角的交往起點、女方高三下分手、兩次獨自赴約及大學畢業後重聯固定下來。兩組設定目前不能自然同時成立。

若作品不打算加入重疊，最低成本方案是把伴侶年數改為能容納於約兩年多間隔的說法，並同步三份設定文件。若保留三年，就等於新增「她在前一段關係結束前已開始這段關係」或大幅延後重聯時間；前者會改寫第三章及主角對分手的理解，後者又會撞到第五章大學畢業後不久服役的時間。應先做設定決策，再潤句。

### 2. 有一處輕微視角越界，其餘推論多有邊界

第 377 行「她每往前一點，就抬頭確認我還在不在」把「確認」寫成她的目的。主角能看見的是她反覆抬頭看他；建議改回可觀察動作，不替她定義為確認安全感。

以下不算越界，不宜為了保守而削弱：

- 「我知道她牽我是因為怕跌倒」有她扶欄、怕摔、要求不要放手與手汗等現場證據，且下一句立即承認主角自己的願望
- 「她的語氣沒有閃躲，像在說一件原本以為我已經知道的事」以「像」標明這是主角的感受，不是她的內心事實
- 她為何回電、看動態、赴約與再約仍未被旁白代答，符合第一人稱資訊邊界

### 3. 回看聲音沒有越時偷塞答案，但份量過多

第 477 行以「現在回頭看」清楚標出事後理解，因此問題不是把成熟認知冒充當時想法，而是前面的場景與第 465 行已經完成同一辨認。章卡明定回看可縮短或整段不寫；此處刪掉大部分回看，不會損失事件、資訊或停點。

### 4. 章卡與前文的其他核對結果

- 開頭精準兌現第三章「淡水」未劃掉、她明確說不會赴約的停點
- 兩次獨自回訪、取得本人同意後拿到新號碼、猶豫三天、首通十五分鐘及當晚由她回電，均與場景表及 `_continuity.md` 相容
- 直排輪的租借、置鞋、兒童課程、腳踝磨紅、歸還設備與離場路線一致，沒有物件歸屬或空間跳接問題
- 她說「也有去」並未被正文寫成她為主角而去；主角的擦身想像與「如果她也在等呢」清楚屬於他的推測
- 章末在已知伴侶存在後仍答應吃飯，正好交給第五章處理「知道後如何參與」，沒有提前完成第三者責任的頓悟

### 5. 聲音與技術規則

- 全章未使用破折號
- 正式敘述段落句尾未留逗號、句號、問號、驚嘆號或分號；對白引號內的標點不構成違規
- 「這些年又像只是一段太長的通話空檔」是會被後文翻轉的當時感受，不是客觀定論，應保留
- 「我不是每天都在等她」雖像辯解，但後面以仍上課、打工、赴約的選擇具體化，能呈現人物如何理解自己，不宜刪成純粹的「我放不下」

## 修訂清單

以下依影響範圍、問題嚴重度與修改成本排序。

1. **決定伴侶年數與是否重疊｜最高影響、中成本**
   先用前三章學籍順序固定時間，再在「改年數／設定重疊／延後重聯」中選一個。首選是調整年數，因為不會改寫第三章分手因果，也不會撞到第五章畢業後不久服役。決定後需同步正文、章卡、場景表與連續性；本輪只在編輯稿記錄，不改其他檔案。

2. **重整第 463–481 行翻轉與收束｜高影響、低成本，預計刪 100–180 字**
   保留腳踏車造成的距離、主角未問出口及一次結晶。刪除第二輪事實清單與誤讀解釋，讓讀者從她的新邀約及「好」判斷他接下來的選擇。

3. **把第 221 行的晚間電話展開為短場景｜高影響、中成本，預計增 250–350 字**
   選她工作中的一件具體小事，讓對話有一次轉向，也讓主角從搶話變成聽完。場景需有電話裡可知的聲音或停頓、她自己的判斷或幽默、以及話題離場；不寫她的內心，不把插曲寫成戀愛暗示。

4. **補社群頁面的可見資訊｜高影響、低成本，預計增 40–80 字**
   在重新加回社群後交代頁面上沒有可辨認的感情狀態或伴侶照片，排除主角理應早已知道的疑問。只寫看見什麼，不解釋她為何這樣經營頁面。

5. **收短直排輪第二輪試滑｜中影響、低成本，預計刪 80–150 字**
   合併第 377–385 行，保留她要求自己滑、確實進步、最後因失衡抓回手。同步把「確認我還在不在」改成可觀察的「抬頭看我」。

6. **把模糊複數改成精確次數｜中影響、低成本**
   已定兩次回訪，就檢查第 407 行「每年」與第 437 行「這幾年」是否讓讀者誤以為更多年；至少將擦身想像錨定為「那兩年」。不要另加年表或第三次淡水場景。
