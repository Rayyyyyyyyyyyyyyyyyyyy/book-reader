# 第一部｜我們怎麼走到一起，又失去彼此

## 第四章｜等妳考完

**核心困境**：她要準備升學，也想維持關係；他嘴上說能等，聯絡與見面一少，卻反覆要求更多確認。她每次說明「現在不行」，都得再次應付他換一種方式提出的靠近。

**固定時間**：第三章停在交往後第一個冬天；本章從過年後、她準備升上夜校高三下學期前後寫起。她白天仍幫早餐店、晚上上夜校，後來還須回家補備考進度；他在台北讀大一並於咖啡廳打工。兩人住不同城市，每次見面須搭車、喬課與排班。分手發生在下一個七月三十一日之前，兩人原本約好那天再去淡水。

**處境與入口**：第三章停在兩人仍真心相愛；本章先讓穩定交往繼續一段時間。他們隔一兩週見面，會主動關心、配合對方的課業和排班；主角曾因自己的報告改約，她也提出替代時間並真的赴約。等她高三下學期的備考加重，原本幾天內能排出的見面逐漸往後挪。她沒有突然消失，仍主動告知課業、打電話、問他的生活；他被第二章留下的不安觸發，將時間變少讀成感情變少。

**場次**：過年後圍巾仍在，她來台北、主角去她的城市；一次在文具店挑筆記本與小茶坊待到傍晚的約會，由她主動排下次時間 → 主角因大學報告先提出改約，她問他的排班、改到隔週，真的到台北和他吃飯；這時短暫錯開仍能由兩人一起接回 → 高三下學期，兩人好不容易在小茶坊見一個短暫的下午，來回車程比能好好說話的時間長，她仍主動問他的課業與返家 → 她第一次因老師加進度取消約會，他已換好班卻說沒有，自己把班換回來；隱瞞讓他留下無人知道的委屈 → 通話縮短時她仍會先打來、分享當天的事，他卻在掛斷後立刻再問下週能不能見 → 她拒絕陪讀，他換成坐遠一點、送晚餐、開著電話等方案，使她每次都要再說一次不要 → 她先試過短通話與告知進度，最後說自己連打電話前都得先想能講多久才不讓他失望，選擇分手。男主角抓住「等妳考完」與已約好的七月三十一日，她明確說不會赴約；他想翹班去找她，最後仍回到吧台完成工作。

**人物與資訊邊界**：她有自己的升學目標，且曾積極維持關係；分手是她對這段相處已無法承受所做的決定，不由考試替她決定。主角知道她忙，也聽得見她說的限制，但不知道她何時決定分手；她不知道他每次都把聯絡減少接回那個暑假，也不知道第一次取消時他其實已換班。敘事只寫他當下的委屈與不安，不由後來的主角提早說完「想幫忙」與「想被需要」的差別。

**本章要成立的理解**：距離與課業使相處難安排，卻不是唯一的分手原因。她曾提出可行的聯絡方式與清楚的拒絕；男主角的真心與他反覆協商同時存在，前者不能抹去後者讓她付出的代價。

**停點與交接**：分手電話之後，他仍看著寫有「淡水」的七月三十一日，沒有劃掉。第五章先承接分手後不願接受的日子，再到第一次獨自赴約。
