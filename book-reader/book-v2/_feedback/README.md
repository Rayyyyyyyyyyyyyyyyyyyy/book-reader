# book-v2 回饋索引

本書正式書名為《喔！這裡還有一點》（[2026-10-05 作者定案](../../../docs/book-v2-titles.md#正式書名定案2026-10-05)）。歷史報告使用的《把自己的部分做完》是當時工作書名；各輪原文與結語篇名保留。

整理日期：2026-10-05。最新作者核准紀錄：2026-10-01，全書十六篇合計 88,896 字；第十三至十五篇為 5,350／2,694／1,046 字。這是已記錄的核准版本，後續工作區是否有變更仍須查正文與 diff。

書稿現況見 [交接文件](../../../docs/book-v2-handoff.md)，操作規則見 [寫作流程](../../../docs/book-v2-workflow.md)。本目錄按用途保存資料，各輪引文、行號、字數與「待校閱」均是產出當時的紀錄；舊報告不自動成為現稿待辦，整章核准也不代表每個歷史提案都獲採納。

## 目錄與命名

| 位置／形式 | 用途 |
|---|---|
| 本層 `NN-{scenes,reader,editor,audit}.md` | 流水線固定產出；場景表依現稿同步，其餘為該輪流程快照 |
| 本層五份 `全書-*.md` 固定來源檔 | 人物判讀與手改來源；保留既有 skill、流程與腳本引用路徑 |
| `author-review/NN[-NN]-作者校閱-YYYY-MM-DD.md` | 作者校閱、確認範圍、來源與採納紀錄；對話局部核准另依原檔名保存 |
| `revisions/NN[-NN]-<議題>-YYYY-MM-DD.md` | 局部／跨章試改與修訂；日期紀錄不覆寫前輪 |
| `diagnostics/全書-<議題>[-{reader,editor}][-YYYY-MM-DD].md` | 跨章診斷與研究；`09-13-流水帳.md` 保留原章號與檔名 |
| `history/<批次>/` | 已被取代或所屬機制已取消的流程回饋，保留原章號 |

單章臨時諮詢仍可用 `NN-<議題>-{reader,editor}.md`；版本被取代後移入對應歷史批次。新增紀錄時同步更新所屬目錄的 README，總索引只保留現況與入口。
