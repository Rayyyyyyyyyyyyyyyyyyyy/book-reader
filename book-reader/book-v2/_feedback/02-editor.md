# 《第二章｜那個沒有回答的暑假》編輯判讀

## 字數與總體判斷

依指定算法計算：

```bash
sed 1d book-reader/book-v2/02-那個沒有回答的暑假.md | tr -d '[:space:]' | wc -m
```

目前為 **5,030 字**，位於本章目標 **5,000–6,000 字**的下緣

本章的主要事件與章卡功能都已成立：第一章留下的告白立刻兌現；「等暑假過完」使等待有真實依據；失聯、「你是誰」與妹妹提供的消息依序改變主角掌握的資訊；快兩年後由主角發出好友邀請，她接受、交代自己當下單身並答應淡水之約，完成第三章所需的交接

真正的修訂問題不是單純太長或太短，而是篇幅分配失衡。前半段有幾處畫面已經成立，旁白又把意思說一次；後半段兩個應讓讀者親身經過的轉折，「你是誰」之後的退縮，以及重聯電話如何重新聊近、如何聽見她說單身，反而很快被帶過。若只依讀者的「重複感」刪減，正文會跌破目標，也會讓關係重新靠近更像情節指令。修訂應先刪約 **230–360 字**的重複、倒帶與重複問答，再把約 **500–750 字**放回兩個主要場景，完成後預估落在 **5,300–5,650 字**

本輪只有一份讀者回饋。以下所稱「共通障礙」，不是多位讀者投票，而是同一問題在逐段反應、畫面感、人物或連續性整理中反覆出現，且能由正文、場景表、章卡或連續性紀錄獨立核對。只涉及想多知道她的內心、想增加更多暑假日常或希望日期立刻獲得解釋者，另列為個人偏好或待後文兌現

## 兩種問題分開處理

### 應刪：同義反覆與過度解釋

1. **距離說明重播（正文 51–53 行）**  
   兩段都在說見面不只需要車票。保留一段必要現實，把其中一項交回她的台詞，約減 40–70 字；不要把限制全部刪成她只說「太遠」

2. **等待功能重說（正文 157–171 行）**  
   「是不是被收手機／早餐店太忙」、測試門號、「每一種猜測讓等待有意義」與回看段落共同指向他如何用理由延後求證。保留測試手機的可見行動、約定確有期限與責任不全在他三項；壓縮猜測清單和尾隨結論，約減 90–150 字

3. **九月撥號倒帶（正文 173–181 行）**  
   不是補寫問題，直接合併兩個起點，約減 20–35 字

4. **通話邀請重複（正文 321–333 行）**  
   保留她先傳號碼與實際問答，刪第 321 行已提前交代的答案，約減 20–35 字

5. **單身資訊後的三重註解（正文 381–393 行）**  
   她說單身、第 389 行區分當下與當年已足夠。第 391 行逐項重列未知，第 393 行替人物宣布「至少沒有再猜」都可壓縮；保留一個必要界線，把其餘空間交還沉默與邀約，約減 70–110 字

6. **章末未知再重列（正文 431–433 行）**  
   章末需要「明知風險仍去」，但前面已多次說暑假沒有答案。保留「一句『等我』後整個暑假不再出現」與「日期有地點、有兩個人」的對照，不再補第三種說法。此處只微調，不刪掉赴約的風險

### 應補：場景質地與被摘要帶過的時刻

1. **「你是誰」到掛斷的幾秒（正文 185–205 行，增加 140–220 字）**  
   這是必須展開的場景。讓主角先帶著準備了一整個暑假的問句進場；她問完後，寫他的身體或手上動作如何停止、電話裡還剩什麼聲音、原本的句子怎麼卡住，最後才退成「我打錯了」。新增細節必須服務「從求證變成否認自己」，不要堆汗、燈光、心跳與回憶，也不要推測她的神情

2. **重聯電話真正聊近的一段（正文 361–369 行，增加 260–380 字）**  
   從「剛開始會同時停下來」進場，選一個近況話題完整走完：誰先問、另一人如何回答、答案和高中時有何差異、哪一句讓兩人又接回原來的節奏。對話之間用主角可感知的聲音、自己房內的動作或時間變化作錨，不寫她在電話另一端未說出的表情與動作。離場時再用時間已過兩小時收束，這樣「不知不覺」才由讀者經歷過

3. **她交代單身後的停頓（正文 371–395 行，增加 90–140 字，同時刪減說理）**  
   她提到前任、明說當下單身後，保留主角坐直，讓他有一個差點問到舊事、最後仍沒問的可見動作或斷掉的開頭。這一拍不是替她的話定義成邀請，而是讓「新資訊到了，舊問題還在」發生在現場。接著由主角提出淡水，場景才真正改變關係

4. **距離限制從說明落回電話（正文 49–61 行，替換式補寫，淨增 40–100 字）**  
   讓她說出一項具體限制，主角回應後仍發現「我可以去」解決不了她那一端的時間。這段的目的不是替女方辯護，而是使「不是只有你去不去」有可感受的前因。只用一項當時物件或聲音承接，例如課本、風扇或上舖的聲響，不另堆年代陳設
