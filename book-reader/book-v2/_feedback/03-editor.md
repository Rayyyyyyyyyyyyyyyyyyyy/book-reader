## 分開處理：該刪的解釋與該補的場景

### 同義反覆與過度解釋：刪

1. **陪讀爭執後的四層命名（第 621–665 行）**
   對話已讓「想自己念書」與「不想見我」的落差成立；她又明說「你做的那些，還是你要待在我旁邊」。保留一次誤讀與「我必須在場」即可。第 665 行「我已經願意什麼都不做了……」與前面的委屈段落功能重複，可刪或縮成場景內反應

2. **十分鐘電話後的雙重總結（第 699–701 行）**
   第 699 行以「多出來的幾分鐘」寫出他如何把越界讀成關係仍在，已經同時包含解讀與代價。第 701 行再總結電話變成每天交代沒有錯，但會形成第二次講義式收束；兩者擇一，優先保留較貼著剛才動作的第 699 行

3. **探班等待的重複證明（第 403–487 行）**
   不是刪專輯，而是刪第二次「她回靠牆位置等我收完最後一張桌子」的同功能收束。把專輯移入第一個探班日，讓它改變那一幕，而不是另開一幕重播等待

4. **少量可直接收緊的說明**
   第 295 行「各自挪出位置」後已有茶坊完整兌現，可以保留作跨時轉場，不需再加一句解釋；第 537–539 行則只留「常圍著它」與最短的理解落點，勿再追加她確實愛過、所以後來更痛等事後說理

### 場景質地不足與摘要帶過：補

1. **生日交付圍巾（第 505 行前後）**
   補約 200–300 字。寫清十二月生日當天、車站周邊的碰面入口、冷造成的一個動作、圍巾如何交到她手上，再接回她找凸起、戴上、不讓他拿回與月台離場。細節的工作是讓禮物被接住並改變兩人的距離，不是展示冬季風景

2. **第一次取消約會（第 547–565 行）**
   補約 160–230 字。把主角這端落在具體時刻：他何時換好班、排班表或訊息如何留在眼前、電話打來時他正做什麼；她那端只用聽得見或她說出口的內容。讓他說「還沒有換班」成為一個現場選擇，而不是摘要中的資訊點

3. **高三下負荷由聲音進入，而非代演她的一天（第 567–595 行）**
   補約 80–140 字，並與上一項合看，避免堆細節。可在一次通話裡讓時間限制、翻頁、呵欠、回答被題目打斷或她重申下一步進度彼此作用。只選一至兩個最有用的聲音或停頓，不同時塞滿紙張、鐘聲、早餐店氣味與房間光線

4. **探班、專輯與折返整併為完整的一天（第 403–487 行）**
   以重排為主，淨增減控制在約負 50 至正 50 字。進場是她帶著紙袋進咖啡廳；中段是主角工作的限制、延後讀訊息與她等待；工作結束後才讓專輯被看見，再進入小店、車站、她靠肩睡與主角折返。這會使專輯不再只是第二份投入證據，而是這一天距離逐步靠近的一部分

以上補寫都必須守住第一人稱：主角可寫自己看到、聽到、記得、猜測或後來理解的事，不能切入她白天獨處的行程、購買專輯時的想法、房間裡的動作或形成分手決定的時刻。

## 讀者未提、編輯另見的問題

### 1. 第一人稱視角有兩處輕微滑動

**判斷：建議處理**

- 第 279 行「她不知道我其實在等另一個答案」可由事實推出，並非嚴重越界，但仍以她的知情狀態落筆。更穩的角度是回到主角沒有說出口的事，不替她宣告知道或不知道
- 第 339 行「她想把同學的表情做給我看」替她命名了意圖。前文已有她要模仿同學的對話脈絡，讀者補得起來；仍可改成主角看見的起手動作，避免攝影機短暫進入她的意圖

除此之外，正文沒有直接寫她的內心。第 559 行「我聽得出來她鬆了一口氣」明確標成主角的聽覺判斷；第 721 行「她的聲音很平」只記錄可聽見的狀態，也沒有把平靜等同於不在乎，均可保留。

### 2. 場景三與場景表的差異應收回

**判斷：建議處理**

場景表把探班、專輯、下班吃東西、送她回家與獨自折返設為同一個秋季週末。正文拆成至少兩次探班，不構成硬性事實衝突，但讓主要場次散成兩個功能相似的片段，也正好觸發讀者的重複感。合併能同時改善結構與篇幅使用，修改價值高。

### 3. 圍巾場景目前只有製作與離場，中間入口消失

**判斷：必須處理**

這不是單純「多寫冬天」。場景表要求一個從主角獨自拆織進場、到生日見面、她戴走圍巾離場的完整場次。正文在「第一段織得忽寬忽窄」後直接寫「她收到時」，跳過兩人相遇。補入口後，現有「真正戴到她身上」「到月台」「常圍著它」才會形成完整時間與空間。

### 4. 章卡要求的當時認知仍守得住，修訂時不可提前補答案

**判斷：不建議修改現有理解邊界；列為硬限制**

第 659 行用「很多年後回頭看」清楚標出回看聲音，第 663 行又承認當時還不會問自己為何慌，沒有把「想陪伴」直接定案成「想被需要」。這與章卡一致。精簡時可減量，但不能把少年主角改成當場理解界線、控制與需求的成熟分析者，也不能由現在的敘事者宣布整段關係只有單一原因。

### 5. 章卡、前文與連續性核對

**判斷：除上述鞋子動線與場景完整度外，沒有新的硬衝突**

- 第二章末由她提出七月三十一日並約淡水，本章開場立即赴約，hook 已兌現
- 主角知道她當下單身，但仍不知道舊失聯與「你是誰」的原因，資訊邊界一致
- 主角大一學年剛結束、她將升夜校高三，與第一章高二準備告白、第二章九月失聯後近兩年重聯的先後可相容；現版不再有年級衝突
- 兩雙藍白拖由主角購買、兩人各自持有，捷運上由她親口答應，回家後由她先打電話，均與連續性一致
- 她送五月天新專輯、主角在十二月送手織圍巾、高三下要求暫停見面、主角仍提出同處讀書／送晚餐／開電話，均符合章卡

### 6. 聲音與技術規則核對

**判斷：破折號與句尾格式通過；視角及回看密度需小修**

- 全章未使用破折號
- 正式敘述與對話段落行末未留句號、逗號、問號、驚嘆號或分號；第 623 行訊息內容的句中冒號與句號不屬行末違規
- 長短句、分行及「我必須在場」的獨立落點有效，不需為了像某種文風再增加碎句
- 「一天沒有訊息／兩天沒有通話／到了第三天」每一拍都有時間與反應升級，不是應刪的字面重複
- 主要聲音問題不是用詞 AI 化，而是少數場景後連續命名同一機制。先刪回看重複，再判斷是否需要逐句潤飾
- 修稿不可新增她的內心、診斷式心理因果、破折號或關鍵句後的尾隨解釋

- 渡船上撥頭髮、她綁起來問好不好看、地瓜條遞到嘴邊與主角先躲：用動作讓雙方的試探成立
- 「她低頭看了一眼我們的手，也沒有抽回去」與「她就翻過掌心，讓我牽住」：她的同意由可見動作完成，不需補內心
- 藍白拖作為從狼狽長出的禮物，尤其「第一次約會就送這個喔」、停兩秒才回答與鞋底「啪啪」聲；修的是走位，不是刪道具
- 捷運上的第二次告白、「好是什麼意思」「你再問就沒有了」，以及當晚她主動說「晚安，男朋友」：明確關係由雙方行動成立
- 小茶坊從進包廂、各自做事又分心，到送她進校門、回家補完作業：是本章最完整的甜蜜日常之一
- 探班時店長在旁、圍裙口袋震動、她不催他及搭車折返；重排後仍要保留工作的限制與兩人想延長一天的動作
- 「那趟折返沒有任何效率／我們只是想把一天再拉長一點」：前面已演完手麻、閘門與回頭，這兩行有場景支撐，不是空泛金句
- 專輯紙袋、圍巾凸起與她後來常圍著：分別證明她記得他的喜好、他願意投入不熟悉的手作，以及禮物真的進入生活
- 第一次取消時主角隱瞞已換班、她鬆一口氣而他感到刺：兩人都避免讓對方承受反應，卻也因此沒有交換真實成本
- 「她這次沒有突然消失……可是聯絡一少，我還是會想起那個沒有回答的暑假」：把眼前事實與舊經驗分開，不能改成她再次失聯
- 「一天沒有訊息／兩天沒有通話／到了第三天」：排比帶出警報升高與時間推進
- 從陪讀、不同桌到送晚餐的對話，以及「為什麼我每說一個不要，你就要再換一個方法問」：界線由互動自然長出來
- 「我明明已經一退再退」與後續電話爭執：保留主角當時真實的委屈，不把他改成用來示範錯誤的紙片人
- 「我必須在場」及「那時候的我還不會問」：一個負責回看，一個保留理解未完成；前後不再加同義句
- 十分鐘電話中「我其實沒有新的事」及「沒有去想那幾分鐘是怎麼留下來的」：把確認需求與她承受的時間代價落在具體行動
- 分手電話的「不是考完就會好的問題」「我現在沒有力氣一直回答這件事」：分手來自累積，不是一次取消約會
- 「我最後沒有翹班」、重新綁好圍裙、重做融冰飲料與同事換回杯子：責任由動作呈現，不可補成他已完成成長
- 「那一格還寫著淡水／日期沒有取消，只是原本要和我一起去的人不會來了」：最準確的章末停點，讓畫面成立後停止解釋

## 修訂清單

以下依影響範圍、閱讀阻礙與修改成本排序。字數是控制方向，不是配額；完成後仍以指定指令實測。

1. **修正藍白拖動線與兩雙鞋的狀態｜高影響、低至中成本、字數約持平**
   鎖定第 121–177 行。畫出「脫鞋位置 → 踏浪 → 原鞋如何濕 → 誰去便利商店 → 拖鞋與塑膠袋回到哪裡 → 原鞋在哪裡裝袋 → 坐回哪裡」的單一路徑，再重寫必要連接。兩人必須各自把自己的原鞋裝袋並帶走，不讓主角瞬移，也不讓鞋子無故變濕

2. **補完整十二月生日與圍巾交付｜高影響、中成本、增加約 200–300 字**
   鎖定第 489–537 行。保留獨自拆織與電話藏針，補生日當天在車站周邊碰面的入口、冷所造成的一個有用動作、禮物交付，再接現有她找凸起、戴上、月台離場。不要新增購物過程、旁人或多個冬季景物

3. **讓第一次取消約會成為完整場景｜高影響、中成本、增加約 160–230 字**
   鎖定第 541–565 行。以主角已換好的班或圈起的日期作進場物件，確定前一晚的時間與他所在位置；對話之間加入能改變理解的停頓和動作，讓他說謊、她鬆一口氣、他取消換班成為同一段時間裡的選擇與後果。她那端只寫聽見與她親口說的內容

   鎖定第 567–595 行，與上一項合併執行。選一通電話補通話上限、翻頁、呵欠、回答被進度打斷等一至兩個證據，不另寫她未被看見的一天。新增細節必須推動他從理解變成不安，而不是只營造辛苦氣氛

5. **整併探班、專輯與送她回家的同一天｜中高影響、中成本、淨字數負 50 至正 50**

7. **收掉十分鐘電話後的第二次總結｜中影響、低成本、減少約 30–60 字**

    場景一修正便利商店動線；場景二現有茶坊外至校門的進出可保留；場景三整併成探班的一天；場景四補生日進場並讓第一次取消電話落地；場景五現有陪讀提議、限時通話、倉庫分手與打烊後行事曆已完整。每次時間跳接後兩段內回到一個具體時刻

這份清單的取捨原則是：先修會讓讀者重建空間或資訊的硬傷，再用新增篇幅補足場景四的時間、位置與身體感；最後才刪去已由事件證明的解釋。若只執行刪減，本章會掉出字數下限，也會讓前半的相愛與後半的耗損都變薄。
