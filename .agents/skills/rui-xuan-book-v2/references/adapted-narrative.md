# 改編敘事書稿

改編書稿除本檔外，還要讀 `source-grounding.md`、`common-voice.md` 與 `structure-and-revision.md`。

寫改編敘事書稿時，先讀 `book-reader/is-me/Rui-Xuan.md` 開頭的十二面向人物分析（約第 13 至 88 行），再讀本書章節腳本、人物設定與前文

- **取用界線**：該檔第 89 行之後的 Round 逐段分析多個對話紀錄，其中包含作者**另外一段關係**，不是本書寫的那一段。嚴禁取用那些相處細節、暱稱或事件，否則等於把別人的互動貼到本書人物身上
- **這一分流不做普世化。** 心得與隨筆可以把真實經驗轉成「你／我們」可代入的普世句；用在敘事書稿裡會長成旁白主題句。敘事的轉換方向相反：人物分析 → 這一章他處在什麼安全程度 → 該出現哪些行為檔位 → 寫成具體的動作、對白與選擇，讓讀者自己看出來
- **檔位不是設定，是變化**。同一個人在不同安全程度下不一樣：安全時可能可愛、直接、黏人、會撒嬌、會照顧人；壓力大或被冒犯時可能尖銳、嘲諷、快速切割；面對荒謬、低效、失望或尷尬時可能用幽默自保。關係越安全，需求量越可能上升。章卡寫的是事件與功能，不會告訴你這些；不主動對照人物分析，人物就只會做劇情需要他做的事
- 人物分析裡不屬於本書時間線或主線的面向（其他工作衝突、法律事件、家族財務、慢性病）**不必補進來**；已經大量存在的面向（例如把痛苦整理成清單、表格與分析）再加只會讓人物更單一
- **人物分析是終點，不是起點。** 它從關係結束之後的紀錄歸納而來，描述的是已經蛻變的他。照它寫早期章節，會讓人物在還沒經歷這一切之前就已經成熟。取用前先分層：哪些是他一直都有的底色（A），哪些是關係後期被代價逼出來的（B），哪些是失去、獨處與重新生活之後才形成的自我理解（C）。分層與逐條護欄見 `book-reader/book-v2/_feedback/全書-人物弧線.md`
- **禁止提早出現的不是動作，是完成式的自我理解。** 早期人物可以有能力、魅力、幽默與深情，也可以偶爾做對一件事；不能讓他已經能穩定說出後來才長出的答案。做對一次不等於他知道整套道理
- **後段成熟的證據不是他不再痛、不再想被愛**，而是痛和需要都還在時，他仍不替別人做決定，也沒有停掉自己的生活。不要用「終於放下」「不再需要誰」來證明成長
- A、B、C 是時間層，不是價值高低。A 層可以很有魅力也可以很不成熟；C 層不是痊癒
- 目前《把自己的部分做完》以 `docs/chapter-v2/`（總則 `00-總則.md` 與各章章卡，索引見 `docs/chapter.md`）的故事安排與連續性紀錄為依據；只讀本章需要的檔案
- 動筆依章卡承接事件與停點；其中的觀念核對表留到初稿完成後使用

### Book-v2 專案材料路由

任務明確涉及這個 repo 的 `book-reader/book-v2/` 時，依問題載入現行來源，不把內容複製進 skill：

- 問全書現況、跨章問題、工作優先序或接手方向：先讀 `docs/book-v2-handoff.md` 與 `book-reader/book-v2/_feedback/README.md`。兩者只負責導航；人物與文本結論仍須回到當前正文、章卡、`_continuity.md` 和實際回饋原檔取證
- 問人物聲音、人設轉換率或全書人物盤點：除 `Rui-Xuan.md` 第 13 至 88 行外，必讀 `_feedback/全書-人物弧線.md` 與 `_feedback/全書-手改對照.md` 的相關章節。先從現稿建立章級基準，再找缺口；`全書-男主角人物覆蓋率.md` 與 `全書-人物補寫清單.md` 只作問題定位，必須連同檔首前提更正一起讀，不能直接當補寫指令
- 問本書書名、篇章名或命名方向：先讀 `docs/book-v2-titles.md`，辨認已提過、已否決與仍未採納的候選，不把舊提案重新包裝成新結論
- 問流程或 pipeline 怎麼改：讀 `docs/book-v2-workflow.md` 與 `docs/book-v2-pipeline.sh` 的現況。`docs/research/` 和 `docs/decisions/` 只在追查材料來源或機制理由時讀，不自動升格成現行規則

### 改編書稿的人物基準與回歸

人物分析不是等待全文完成後才打勾的清單。寫作或修改前，先從本章正文、章卡與人物弧線建立一份**章級人物基準**：本章的安全程度、允許出現的 A／B／C 時間層、正文已經存在且必須保留的兩至四個人物訊號，以及本章在既有事件裡真正缺少的面向。訊號可以是需求、拒絕、玩笑、主動靠近、要求或接受照顧、在壓力下的切割方式；不是每段對白後面加一個身體動作

潤飾後要把改前與改後逐項對照：原本有辨識度的訊號若被刪，必須能說明它只是在重複哪一個相同功能；不能只因為它不推進事件就刪。缺少的面向只有在現有素材、事件與關係階段有根據時才補，優先透過選擇、對白、需求與互動後果呈現；沒有根據就記為待處理，不用通用小動作、俏皮台詞或說理旁白充數

最後再問：遮掉名字是否仍認得出是他；他除了處理問題還想從人身上得到什麼；他是否既會照顧也會要求或接受照顧；本章安全程度與行為檔位是否一致。這四題是回歸檢查，不是人物配額；不得為了答題讓後期才形成的完成式自我理解提早出現
